## 摘要
静息态fMRI在脑部疾病分类中具有重要意义，但其具有高度多模态性，并表现出强烈的多中心异质性。现有方法融合图像、基于BOLD的功能连接以及表型数据模态。与其他医学影像数据集不同，rs-fMRI数据集很少包含文本模态，因此这些文本模态由表型数据或BOLD激活生成。这些文本生成方法依赖于对被试、站点、设备和协议的固定假设，导致跨数据集泛化能力较差。我们提出fMRI-TAMCL，一种文本锚定的多模态对比学习框架，该框架整合了fMRI图像、稀疏FC以及生成的被试特异性文本。其被试自适应阈值推导模块生成BOLD激活文本，而特征值序列化模块生成表型文本。所有三种模态均被编码为聚类图，投影到共享的单位超球面空间，使用成对的、文本锚定的监督对比学习进行对齐，并通过注意力进行融合。fMRI-TAMCL在五个数据集上证明了其泛化能力，在下游分类中以78.6%-86.4%的准确率优于29个基线。

## Abstract
Resting-state fMRI is important in the classification of brain disorders, but highly multimodal and exhibits strong multisite heterogeneity. Existing methods fuse images, BOLD-based functional connectivity, and phenotypic data modalities. Unlike other medical imaging datasets, rs-fMRI datasets rarely include a text modality, so they are generated from phenotypic data or BOLD activations. These text generation methods rely on fixed assumptions for subjects, sites, devices, and protocols, leading to poor generalization across datasets. We propose fMRI-TAMCL, a text-anchored multimodal contrastive learning framework that integrates fMRI images, sparse FC, and generated subject-specific text. Its Subject-Adaptive Threshold Derivation module generates BOLD activation text, while Feature-Value Serialization module generates phenotypic text. All three modalities are encoded as clustered graphs, projected onto a shared unit hypersphere space, aligned using pairwise, text-anchored supervised contrastive learning, and fused with attention. fMRI-TAMCL proves its generalization capability across five datasets outperforming 29 baselines with 78.6%-86.4% accuracy in downstream classification.

## 一、核心问题与整体含义（研究动机与背景）

- **rs-fMRI 诊断的价值与痛点**：静息态功能磁共振（rs-fMRI）对脑疾病的大规模自动分类具有重要意义，但存在两大障碍——**强多站点异质性**（不同站点、扫描仪厂商、成像协议、队列导致模型假设难以泛化）和**多模态性**（图像、功能连接矩阵 FC、表型记录三类异构模态）。
- **现有方法的局限**：
  - 多数模型是**单模态**的（CNN 用于图像、GNN 用于 FC、传统机器学习用于表型表格），无法利用跨模态互补信息。
  - 现有多模态策略主要融合 FC 与其他定量神经影像模态（MRI、PET、DTI、EEG），**几乎忽略文本数据**，错失了利用大语言模型（LLM）进展的机会。
- **关键矛盾（文本模态缺失）**：与其他医学影像数据集不同，rs-fMRI 数据集**很少包含受试者级文本**，因此现有方法需从 BOLD 激活中派生文本，通常采用**固定激活阈值**将 ROI 级 BOLD 激活映射为弱/中/强标签。
- **固定阈值的根本缺陷**：固定阈值假设不同受试者与站点的激活分布相似，但多站点数据中扫描仪与采集协议的个体/站点差异使固定阈值无法正确标注，引入**系统性标签噪声**，污染文本模态并损害下游融合，且难以跨数据集校准，泛化性差。
- **整体含义**：本文提出以**生成文本为语义锚点**的多模态对比学习框架，用受试者自适应阈值替代固定阈值，试图在跨站点、跨疾病场景下实现可泛化的 rs-fMRI 脑疾病分类。

## 二、方法论

### 2.1 核心思想
- 整合三种受试者级模态：**fMRI 图像、稀疏 FC、生成文本**；将三者统一编码为图、投影到共享单位超球面，通过**成对 + 文本锚定 + 监督**三重对比学习对齐，再用注意力融合做诊断分类。
- 整体架构分两阶段：**Stage 1 图基特征提取** 与 **Stage 2 对比学习驱动的诊断**。

### 2.2 文本生成模块（本文关键创新）

**（1）SATD：受试者自适应阈值推导（生成 BOLD 激活文本 T_brain）**
- 对每个受试者的 N 个 ROI BOLD 时序做 z-score 归一化，得到激活向量 z_i。
- 用 **Gamma–Gaussian 混合模型（GGMM）** 建模 ROI 激活分布：高斯项建模近零噪声（静息/被抑制区域），Gamma 项建模右偏的活跃响应，混合权重为 π：
  p(z_i; Θ) = (1−π)·N(z_i; μ, σ²) + π·Γ(z_i; k, θ)
- 用 **EM 算法**迭代估计参数：E 步计算活跃成分的后验责任度 r_i，M 步更新混合权重、高斯均值/方差（公式 2）以及 Gamma 的形状参数 k 和尺度参数 θ（基于加权统计量 μ̂_a、L̂_a 及充分统计量 s）。
- 收敛判据为 |ℓ(t+1) − ℓ(t)| < ε；为避开局部最优，运行 **n_init = 5 次随机重启**，保留最终对数似然最高者。
- 阈值由**高斯与 Gamma 分量的交点**给出，即差值函数 D(z_i) = (1−π̂)·N − π̂·Γ 的根，得到 τ1 < τ2，据此离散化为：
  - x < τ1 → **weak**（噪声主导）
  - τ1 ≤ x ≤ τ2 → **moderate**（两分量后验相等/重叠）
  - x ≥ τ2 → **strong**（活跃主导）
- **回退策略**：EM 不收敛时用 33/67 百分位阈值；只找到一个交点时用其作 τ1，上阈值设为 Gamma 理论均值 τ2 = 1.5k̂θ̂。

**（2）FVSerial：特征值序列化（生成表型文本 T_pheno）**
- 遵循 TabLLM 框架，将原始表格的「特征-值」对（如 SUB_ID = 50002, AGE_AT_SCAN = 16.77）转换为**人类可读的句子模板**（如 "The Age is 16.77."），按表格列顺序排列。
- 再用 **T0（T5 架构的编码器-解码器 LLM）** 将每个模板句独立改写为带有临床语境的简洁自然语言文本。
- T_pheno ⊕ T_brain 拼接为 T_fMRI，经 LLM 精炼为 T_refined，再由 **BERT** 编码为上下文 token 嵌入。

### 2.3 模态特定图特征提取
- **图像分支**：fMRI 体积经线性嵌入 + **ViT** 编码为 patch 特征，每个 patch 为图节点，边由余弦相似度的 **KNN 图**（K=10）给出，构建 G^(I)。
- **FC 分支**：原始 BOLD 时序用 **LLSFC（对数正则拉普拉斯稀疏功能连接）** 转为稀疏 FC 矩阵 L，目标函数 R(W) = −α[1]ᵀlog(W·1) + β‖W‖²_F，对数障碍项避免退化连接，Frobenius 项防止 FC 过密主导模型。
- **文本分支**：BERT token 嵌入为节点，边由语义相似度定义，构建 G^(T)。
- **统一的聚类图构建**：由于三类图均基于成对节点相似度构建，存在大量语义冗余节点，直接节点级融合次优。因此对每个图施加**基于模块度的聚类**：
  - 模块度矩阵 B = A − ddᵀ/(2e)，减去随机图基线以判断连接是实质相似还是随机。
  - 聚类目标（公式 6）最大化模块度 + 正则化均衡簇使用，防止簇塌缩。
  - 簇级节点特征由软分配矩阵 C 与 SELU 变换生成（公式 7），簇数满足 **N^(I) < N^(L) < N^(T)**（图像 32、FC 64、文本 128），反映信息密度假设。
- 对每个聚类图用 **3 层 GCN**（归一化邻接 + 自环，逐层图卷积、线性变换、批归一化、ReLU，公式 8），再经 dropout 与全局平均池化得到模态级图嵌入 g^(m)。

### 2.4 对比学习与融合
- 各模态嵌入经**模态特定 2 层 MLP 投影头**并 ℓ2 归一化到**单位超球面**，得 z^(m)_i。
- **方向性 InfoNCE 损失** L_{a→b}（公式 9）：同受试者跨模态为正对，其他受试者为负对；用对称损失 L_{a,b} = ½(L_{a→b} + L_{b→a}) 消除方向偏差。
- **成对损失** L_pair = L_{I,L} + L_{I,T} + L_{L,T}，构建共享嵌入空间。
- **文本锚定损失** L_text = ½(L_{T,I} + L_{T,L})，以文本为语义锚组织嵌入空间。
- **监督对比损失** L_supcon（公式 13）：按诊断标签定义正负对，将潜在空间划分为疾病/对照两个原型区域。
- **联合对比损失** L_con = λ_pair·L_pair + λ_text·L_text + λ_sup·L_supcon。
- **融合与分类**：对齐后的嵌入逐元素相加得 z_s 作为 query，各模态嵌入作为 key/value，计算多头注意力（n=10 头，公式 15–16，MMHSA），再经轻量级**三重多模态循环融合网络 TMCFN** 融合，最后 softmax 分类。
- **总目标**：L_total = L_cls + λ_con·L_con。

## 七、优点

- **问题定位精准**：清晰识别出 rs-fMRI 文本模态缺失 + 固定阈值导致标签噪声这一关键瓶颈，并给出系统性解决方案。
- **SATD 方法有理论依据**：用 GGMM（Gamma 建模活跃、Gaussian 建模噪声）替代固定阈值，通过 EM + 多随机重启 + 交点求根自适应确定受试者级阈值，并设计了完整的回退机制，鲁棒性有统计支撑（95.4% 收敛率）。
- **多源文本生成**：SATD（BOLD 激活

→ 弱/中/强标签）与 FVSerial（表型→自然语言）双路并行，形成"脑功能语义 + 临床表型语义"的互补文本视图，再由 T0 改写、BERT 编码，兼顾可读性与上下文表征。
- **图结构统一化处理巧妙**：将图像 patch、稀疏 FC、文本 token 三类异构数据统一抽象为"相似度建图 + 模块度聚类 + GCN"的同一范式，并通过簇数递增（32 < 64 < 128）显式编码"图像信息密度最低、文本最高"的先验假设，使跨模态对齐在簇级而非噪声节点级进行，降低了冗余与计算量。
- **对比学习目标层次分明**：成对损失（构建共享空间）→ 文本锚定损失（以语义为中心组织流形）→ 监督对比损失（按诊断标签划分原型区域），三者职责互补，而非简单叠加；消融结果也验证了三者贡献的递减顺序（7.0% > 5.5% > 3.9%），逻辑自洽。
- **融合机制轻量且有效**：多头注意力（10 头）+ TMCFN 三重循环融合仅带来 1.1% 的性能依赖，说明框架性能主要来自表征对齐而非融合模块堆叠，符合"对齐优于融合"的设计哲学。
- **实验证据链完整**：从主性能、跨站点泛化（LOSOCV）、模态缺失鲁棒性、超参数敏感性、收敛性统计到潜在空间质量指标与临床可解释性，形成"性能—鲁棒—机理—临床"的闭环，且所有指标均报告五次运行均值±标准差，透明度较高。
- **可解释性与神经科学先验高度吻合**：五个疾病的显著 ROI 分别对应后部 DMN（ASD）、扣带-纹状体环路（ADHD）、内侧颞叶-边缘系统（AD）、显著性网络（MDD）、分布式感觉运动网络（EP），这种"数据驱动结果与既有病理知识互证"增强了方法的可信度，也说明生成文本锚点确实捕捉到了疾病相关的功能语义。

## 八、局限性与可商榷之处

- **对上游 LLM 的依赖与误差传递**：文本质量同时受 T0 改写、BERT 编码、SATD 阈值三重影响。T0 改写可能引入与原始表型不符的"润色幻觉"，而论文未对改写文本做人工或自动的事实一致性校验（如与原始特征值比对）。
- **GGMM 的分布假设较强**：Gamma–Gaussian 混合隐含"激活成分右偏、噪声成分近零对称"的假设。对短扫描时长、低 SNR 或存在头动伪影的受试者，双峰结构可能不成立；虽有 1.5% 回退机制兜底，但回退样本的阈值质量及其对融合的影响未单独分析（仅报告剔除后 ACC 提升 1.1%）。
- **簇数为人工设定**：32/64/128 的配置虽经消融验证，但未给出自动确定簇数的方法（如基于模块度增益或肘部法则），也未报告簇数敏感性曲线，跨数据集迁移时该超参数可能需要重新调参。
- **算力报告不完整**：仅给出单 epoch 训练时间与单受试者推理时间，缺少总训练时长、总 GPU 小时数、五折/五次运行的累计开销，难以评估方法在大规模临床部署中的实际成本。
- **基线公平性存在结构性偏差**：文本基线 BERT-Text 直接使用本文 SATD + FVSerial 生成的文本，其质量本身即为本文贡献，因此该对比更多是"验证文本分支有效性"而非"与独立文本方法对比"；同理，RTGMFF 作为最接近基线使用固定阈值，二者差距部分归因于阈值策略而非全部架构差异，消融中"固定阈值"变体（−? %）才是更干净的对照。
- **部分实验条件不一致**：缺失模态实验中若干基线标注为 N/A，导致该表并非全矩阵对比，结论"优于所有可比基线"的适用范围需谨慎表述。
- **统计显著性未检验**：所有改进（如 1.6%–3.0% 的 ACC 提升）均以均值±标准差呈现，但未报告配对 t 检验或 Wilcoxon 检验的 p 值，无法判断增益是否显著超越运行间波动。
- **任务范围有限**：五个数据集均为二分类（疾病 vs 对照），未验证多疾病联合分类、疾病亚型细分或症状严重度回归；LOSOCV 仅在 ABIDE 内部进行，未做真正的跨数据集（如 ABIDE 训练 → ADHD 测试）零样本/少样本迁移，而"跨疾病泛化"的宣称主要依赖五个独立实验的并列结果。
- **可解释性验证深度不足**：ROI 显著性基于图梯度，属于归因方法，未与病灶掩膜、基因表达或纵向临床评分做定量关联，也未评估解释的稳定性（如多次运行间 ROI 排序一致性）。

## 九、总体评价与启示

- **核心贡献**：本文的价值不在于提出某个全新网络结构，而在于**把"文本模态从何而来"这一被忽视的前置问题转化为可建模对象**——用受试者自适应阈值（SATD）替代全局固定阈值，从源头抑制标签噪声，再以文本为语义锚点组织多模态对比学习空间。这一"先解决数据标注、再谈融合架构"的思路对 rs-fMRI 乃至更广泛的医学多模态学习具有方法论借鉴意义。
- **方法论层面的可迁移性**：GGMM + EM + 交点求根的自适应离散化框架不限于 BOLD 激活，原则上可迁移到任何"连续生理信号 → 有序语义标签"的转换场景（如 EEG 功率、PET SUVR），只要其分布近似"噪声 + 右偏信号"的混合结构。
- **实践层面的取舍**：21.2M 参数、81 秒/epoch 的规模使方法在单卡消费级 GPU 上可训练，兼顾了性能与可复现性；但引入了 T0/BERT 两个预训练模型，实际部署需权衡推理链长度与临床实时性需求。
- **未来可探索方向**：（1）端到端可微的阈值学习，替代 EM 的离线两阶段流程；（2）文本生成的自监督一致性约束，缓解 LLM 改写幻觉；（3）跨疾病、跨数据集的真正迁移与多任务联合训练；（4）与临床纵向指标（如 ADAS-Cog、ADOS 评分）关联，验证语义锚点是否携带预后信息；（5）报告统计显著性检验与完整的算力清单，提升可复现与可比性。
