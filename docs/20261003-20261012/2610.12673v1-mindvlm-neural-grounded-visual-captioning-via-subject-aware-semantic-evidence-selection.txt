MindVLM: Neural-Grounded Visual Captioning via
Subject-Aware Semantic Evidence Selection

Department of Computer Science, Tulane University

Abstract
Translating visual brain activity into natural language offers a powerful window into
human cognition and neural semantic representation. Most prior brain-captioning
approaches project fMRI signals into language space using paired supervision.
However, the widely used Natural Scenes Dataset (NSD) was built based only on
image-fMRI pairs, while existing methods rely on MS-COCO captions as indirect
textual supervision. Critically, during fMRI acquisition, participants observe only
cropped image regions, whereas the associated MS-COCO captions describe full
scenes. This mismatch creates a fundamental gap between neural representations
and textual supervision, introducing an inherent semantic loss in NSD-based brain
captioning. To mitigate this limitation, we reformulate brain captioning as Neural-
Grounded Visual Captioning, where language is generated directly from visually
grounded neural evidence rather than text supervision. We propose MindVLM, a
framework that maps fMRI signals into subject-aware visual tokens and leverages
a frozen vision language model (VLM) to produce interpretable and personalized
descriptions. Instead of point-wise regression, MindVLM focuses on extracting
semantically relevant visual cues from neural activity, naturally accommodating
partial observability and inter-subject variability. Extensive experiments on NSD
show that MindVLM consistently improves caption quality across multiple VLM
backbones, including LLaVA-v1.5, Qwen2.5-VL, and Gemma3, beyond intrinsic
model priors. Despite requiring neither text supervision nor an LLM during
training and operating under an image-grounded inference paradigm distinct from
conventional captioning methods, MindVLM remains competitive with supervised
approaches, suggesting that subject-specific neural grounding provides an efficient,
scalable, and interpretable path toward faithful brain-to-language generation.

Introduction
Understanding how the human brain encodes visual information is a central goal in cognitive
neuroscience, offering fundamental insights into how humans perceive, interpret, and interact with the
world [26]. Translating brain activity into natural language–commonly referred to as brain captioning–
provides a concrete and expressive interface for probing these neural representations and their
relationship to perception and language [34]. Recent progress in this line of work [5, 6, 7, 8, 25, 39, 48]
has demonstrated the feasibility of generating fluent descriptions from neural signals, largely driven
by advances in large language models (LLMs) [10, 19, 40, 50, 51, 52]. Despite this progress, existing
approaches implicitly assume that neural activity provides complete visual evidence for the target
description–an assumption that does not hold in realistic experimental settings.

In the widely used Natural Scenes Dataset (NSD) [1], participants view cropped regions of MS-
COCO images [29] during fMRI acquisition, while textual supervision is derived from captions
describing the full scenes. As illustrated in Figure 1, this design introduces a fundamental mismatch
between the visual evidence encoded in brain activity and the caption targets used for training,
leading to what is referred to as semantic loss in NSD. Directly using these captions as ground-
truth supervision for brain captioning is not only computationally inefficient, but also risks pushing
models to hallucinate visual content that was never actually observed in neural signals. Consequently,
methods that attempt to reconstruct or regress toward complete visual representations—for example
via point-wise alignment to image features or projection into LLM input space—may produce
semantically inflated captions that exceed the information truly supported by the brain.

These limitations highlight a critical gap in current methods and raise a central question:
How can we generate faithful, subject-aware captions by grounding descriptions only in the
visual content that are truly supported by neural activity?
To address this challenge, we introduce a new brain decoding paradigm: Neural-Grounded Visual
Captioning via semantic evidence selection. Instead of formulating brain captioning as direct fMRI-
to-language translation, we redefine the task as identifying which visual semantics in a stimulus
are supported by neural activity. Specifically, we leverage the image as an intermediate semantic
domain, treating spatial visual tokens as a structured semantic vocabulary over which neural evidence
is inferred. Brain responses are used to select subject-aligned visual semantics, which are then
composed into natural-language descriptions by a pretrained VLM. This image-grounded inference
paradigm fundamentally departs from conventional fMRI-to-text generation by reframing brain
decoding from text regression to semantic evidence grounding. As a result, it naturally handles partial
visual observability, removes the need for costly subject-specific text annotations, enables efficient
text-free training without LLM, and produces interpretable, subject-specific visual evidence maps
that reveal individual perceptual focus.
Building on this framework, we introduce MindVLM, a subject-aware neural visual captioning
model that captures the correspondence between brain responses and visual features. By learning
to identify which visual tokens are supported by each subject’s unique neural signals, MindVLM
constructs personalized visual evidence representations. These representations are then passed to
a frozen vision-language model at inference time to generate descriptions that faithfully reflect the
subject’s perceptual experience. Our contributions are summarized as follows:
• To the best of our knowledge, this is the first work to explicitly mitigate the semantic loss in
NSD-based brain decoding, challenging the practicality of direct fMRI-to-language captioning due
to the prohibitive cost of collecting reliable real-time subject-specific textual annotations.

2.2
Framework Overview
Our framework is driven by three key insights: (1) Semantic Loss: fMRI signals capture only the
visual content actually perceived by the subject, rather than the full semantic richness expressed
in crowd-sourced captions; (2) Personalization: perception is subjective, as different individuals
attend to different aspects of the same image, yet existing methods rely on subject-independent
captions, making personalized annotations difficult to collect and enforcing uniform descriptions
across subjects; and (3) Visual Grounding: pretrained VLMs provide structured, spatially grounded
visual tokens whose representations naturally align with cortical visual features, offering a cognitively
grounded and biologically plausible bridge for multimodal alignment.
For these reasons, we depart from conventional fMRI-to-text training pipelines. Instead, we construct
a shared latent space in which neural tokens derived from fMRI are aligned with visual tokens

2.3
Neural-Visual Mapping
Given an image-fMRI pair I ∈RH×W ×3 and v ∈RL, our goal is to learn a shared latent space that
captures the semantic correspondence between visual stimuli and brain activity patterns. We achieve
this by first extracting latent spatial representations from both modalities.
Visual Encoding. For the visual modality, we leverage the frozen image encoder Eimg : RH×W ×3 →
RNimg×dimg from the VLM of interest to obtain visual features X ∈RNimg×dimg, providing rich semantic
and spatial representations of the image:
X := Eimg(I) = (x1, x2, · · · , xNimg) ∈RNimg×dimg.
(2)
Neural Encoding. For the neural modality, we adopt a trainable multi-head ViT-based [13] encoder
Evox : RL →RNvox×dvox to transform voxel-level fMRI signals into neural tokens F ∈RNvox×dvox:
F := Evox(v) = (f1, f2, . . . , fNvox) ∈RNvox×dvox,
(3)
where Nvox is the number of functional voxel tokens and dvox their latent dimensionality. Each voxel
feature can be viewed as encoding activity patterns of local neuronal populations, reflecting the
distributed semantic representation of visual information across the cortex.
Learning Neural-Visual Shareable Space. Considering the fact that the fMRI signal reflects the
brain activity of the subject receiving visual stimulus at the image-level, it is important to align the
two modalities globally. We therefore derive global representations by applying average pooling
operation Pool(·) over spatial dimensions:
x = Pool(X) ∈Rdimg
and
f = Pool(F) ∈Rdvox.
(4)
This pooling operation mirrors the population-level coding observed in the visual cortex [21], where
distributed patterns of voxel activity collectively represent the semantics of the images being viewed.

2.4
Subject-Aware Captioning
Once the neural-visual alignment model is trained, it defines a shared embedding space that links
voxel-level latent neural responses with spatially structured visual representations. This shared space
naturally arises from the learning objective in Eq.(7), in which both neural and visual features are
locally pooled prior to alignment. Because the global token is obtained via average pooling over
local tokens, it resides in the same embedding space as the local representations. This local-to-global
design enables us to infer which image patches each subject attended to during perception, yielding
interpretable and subject-specific attention maps directly from neural activity.
Given a single test pair of visual tokens X ∈RNimg×dimg and fMRI tokens F ∈RNvox×dvox, both are
projected into the shared space using the learned projection heads Wimg ∈Rdimg×d and Wvox ∈
Rdvox×d similar to but slightly different from Eq.(5), producing aligned local tokens Zimg and Zvox:
Zimg = XWimg ∈RNimg×d

From a neuroscientific perspective [24, 44], the similarity between neural and visual tokens ap-
proximates subject-specific attentional tuning–that is, visual cortical voxels respond more strongly
to features or regions that attract perceptual attention or encode behaviorally relevant semantics.
However, neural responses are inherently distributed and overlapping: multiple voxels may encode
similar visual elements, while a single voxel may participate in multiple feature representations.

Experiments
3.1
Experimental Setup
We evaluate our MindVLM on the Natural Scenes Dataset (NSD) [1], the largest publicly available
fMRI dataset. NSD captures brain activity from 8 human subjects as they viewed natural scenes
from MS-COCO [29]. Each subject passively viewed a set of 10,000 images, each presented for 3
seconds and repeated three times. Among these images, 1,000 are shared across all subjects, while
the remaining 9,000 are unique to individual subjects. Due to data availability constraints, we only
train and test on four subjects: subj01, subj02, subj05, and subj07. Following standard protocols
established in prior NSD studies [22, 32, 42, 43, 47, 60], we used standardized train/test splits and
averaged fMRI activations over repetitions for each image within each subject. This pre-processing
resulted in 36,000 training samples (fMRI-image pairs) and 4,000 test samples. All models are then
trained and evaluated on a per-subject basis. Check Appendix A.2.2 for implementation details.
3.2
Neural-Guided Visual Captioning across VLM Architectures
We introduce Neural-Grounded Visual Captioning (NGVC) as a new paradigm for brain decoding
that explicitly mitigates the difficulty of collecting personalized fMRI-text pairs. Unlike traditional
brain captioning methods that directly map neural activity into language space, NGVC leverages
neural responses to identify semantically supported visual tokens from the test image, which are
then passed to a frozen VLM for caption generation. Crucially, the brain encoder is trained to align
with the VLM’s visual encoder space rather than its language space, eliminating the need for costly
subject-specific text supervision while enabling personalized and semantically grounded captioning.
To evaluate generality across architectures, we train separate brain encoders aligned with three
commonly-used VLMs featuring different visual backbones: LLaVA-v1.5-7B (CLIP), Qwen2.5-VL-
7B-Instruct (customized ViT), and Gemma3-4B (SigLIP). For each model, we compare MindVLM
against the base VLM operating on the full image, which serves as a strong baseline reflecting the
model’s inherent visual understanding without neural guidance. We report results on six standard
captioning metrics, including n-gram-based measures (BLEU-1/2 [36], ROUGE [28]) and semantic
metrics (METEOR [11], CIDEr [53], SPICE [2]). Results for subj01 are shown in Table 1, with q set
to 70, 60, and 50 for LLaVA, Qwen2.5, and Gemma3, respectively.

3.3
Semantic Decoding Quality: Reference to Brain Captioning Methods
To situate MindVLM within the broader brain captioning literature, we report the performance
of MindVLM-LLaVA at q = 35 on the standard NSD evaluation protocol alongside established
fMRI-to-text methods. Here, q = 35 is a conservative choice to maximize the fairness of reference.
See detailed analysis in Section 3.4 and A.4. We emphasize that this comparison is provided as a
reference point, not a direct benchmark. Traditional brain captioning methods perform pure fMRI-
to-text decoding with no image access at inference, whereas MindVLM operates under the NGVC
paradigm–using fMRI to select neural-supported visual tokens from the test image, which are then
passed to a frozen VLM. These are fundamentally different inference settings, and the comparison is
intended to characterize the semantic quality of neural grounding rather than to establish ranking.
Despite requiring no text supervision and operating under a different inference paradigm, MindVLM
achieves strong performance on semantic-oriented metrics in Table 2. On SPICE, we substantially
exceed all methods, including fully text-supervised ones, suggesting that grounding captions in
neural-supported visual evidence captures scene-level semantics, object relations, and compositional
meaning more faithfully than direct text regression. On ROUGE, MindVLM also leads across all
methods, indicating strong coverage of content-relevant words even without paired caption training.
On n-gram metrics, MindVLM trails text-supervised methods, which is expected, as they reward
lexical similarity to ground-truth captions, something inherently unattainable without text supervision.
One additional finding is worth noting. MindVLM-clean (evaluated on the subset of test samples
without semantic loss) consistently outperforms MindVLM on the full test set across all metrics, with
the gap most pronounced on CIDEr. This directly quantifies the partial visual observability issue:
when neural signals and caption targets are well-aligned, semantic grounding improves measurably,
confirming that the problem identified in Section 1 has real and measurable consequences for decoding
quality. Section A.6 analyzes this relationship in further detail. These results point to a broader
insight about what text supervision actually provides in brain captioning: (1) text-supervised models
excel at reproducing captions, but at the cost of learning dataset-level correlations that may exceed
what the subject actually perceived. (2) MindVLM, by grounding decoding in neural-supported visual
evidence rather than crowd-sourced text, trades lexical precision for semantic faithfulness–a trade-off
that favors the underlying goal of brain captioning as a window into individual perception.

3.5
Captioning by Subject-Specific Perception
Figure 5 illustrates how the same visual stimulus leads to distinct, subject-specific perceptual inter-
pretations that ultimately shape the generated captions. Although we use a fixed quantile threshold
q = 5, the proportion of preserved tokens (“XX% out”) varies across individuals, indicating differ-
ences in neural selectivity and revealing what their brain considers most relevant or salient percepts.
Importantly, captions generated from these subject-specific tokens do not resemble generic image
captions. Instead, they capture unique visual information encoded by each individual, highlighting
the well-documented inter-individual variability in high-level visual cortex [4].
Specifically, subj02 preserves very few tokens (85% masked), particularly around object boundaries.
This suggests a coarse, global percept lacking fine-grained object details. Correspondingly, the
generated caption–“a woman holding a plate of food.”–remains semantically broad and avoids
mentioning items such as “donuts” or “fork,” which are either absent from the subject’s neural
representation or not prioritized during perception. In contrast, subj05 retains the largest proportion
of tokens (only 61% masked), with preserved regions concentrated around the action and utensil. This
indicates a higher-fidelity perceptual representation. As a result, the generated caption becomes detail-
rich and action-specific (“eating ... with a fork in her hand”), showing that MindVLM reconstructs
the fine-grained semantics embedded in its neural patterns. Subj07 exhibits selective retention around
the pastries, preserving tokens that emphasize high-contrast texture regions. This subject-specific
attentional bias results in a caption that uniquely includes “frosting on top.” Others whose neural
encodings did not emphasize these texture cues do not mention this detail, further demonstrating that
the decoded text reflects personalized perceptual biases rather than a caption-driven ground truth.
Together, these results (more in Appendix A.8) demonstrate that the decoded captions are personalized
semantic reconstructions, grounded in each individual’s neural representation of the visual stimulus.
Differences in information retention, spatial focus, and feature selectivity translate directly into
systematically different linguistic outputs. Thus, unlike existing approaches that regress toward an
average or caption-conditioned description, our paradigm leverages subject-specific cortical encoding
to reconstruct what each person actually perceived. This supports the claim that neural-to-text
decoding should be framed as subject-dependent semantic reconstruction, rather than text prediction
based solely on crowd-sourced caption annotations.

3.6
Paradigm Efficiency
One key advantage of MindVLM over conventional captioning models lies in its data efficiency and
lightweight training design. Our approach eliminates the dependence on text-based supervision,
which is both scarce and difficult to obtain. Most competing approaches rely on using images as an
indirect bridge between brain signals and language, often leading to cross-modal misalignment.
In addition to reduced data requirements, MindVLM is significantly more computationally efficient.
Because our training objective involves only neural-visual contrastive alignment, no LLM is required
during optimization, resulting in dramatically lower resource consumption. To quantitatively assess
training efficiency, we benchmark MindVLM against the recent MindLLM model [39] across four

Conclusion
We presented MindVLM, a subject-aware framework for Neural-Guided Visual Captioning that
reframes brain decoding as semantic evidence selection under partial visual observability. Rather than
mapping fMRI signals directly to text, MindVLM aligns neural activity with spatial visual tokens and
uses a frozen VLM to generate captions grounded only in the neural-supported visual evidence of each
subject. MindVLM consistently improves over the base VLM across three architectures, and remains
competitive with text-supervised brain captioning methods on semantic metrics despite requiring no
text supervision–with remaining performance gaps concentrated on lexical-overlap metrics that favor
models trained to reproduce captions. These results indicate the promise of neural-guided visual
grounding as an efficient, interpretable, and cognitively faithful pathway for personalized decoding.

A.1
Related Works
Brain-to-language decoding spans a broad set of tasks and neural modalities. Early and ongoing lines
of work study how to decode fMRI or other neural signals during story listening [49, 55, 27, 3, 61, 31]
or reading visually presented text in a sentence-by-sentence manner [37, 15, 41, 59, 62]. Our work
focuses on a specific subproblem within this landscape: brain captioning, where the goal is to generate
natural-language descriptions of the semantic content of visual stimuli viewed by subjects inside the
scanner. This setting is enabled primarily by the Natural Scene Dataset (NSD) [1], with images from
MS-COCO [29], and thus provide rich human-written captions for evaluation.
A.1.1
Modality Alignment
A substantial body of prior work investigates how to align neural activity with visual or vision-
language representations as a foundation for downstream decoding. These efforts differ in motivation,
supervision, and target tasks, but generally aim to improve the fidelity or robustness of neural-visual
correspondence.
Several works focus on learning subject-unified representations that generalize across individuals.
UMBRAE [56] proposes a universal brain encoder that maps subject-specific fMRI signals into a
shared latent space corresponding to visual tokens of a multimodal model. Its design emphasizes
cross-subject consistency and supports weakly supervised adaptation to new subjects, enabling
scalable neural decoding without text supervision during training. BrainOT [58] addresses limitations
of point-wise regression by reformulating neural-visual alignment as a distribution-to-distribution
matching problem using optimal transport, improving robustness over traditional mean-squared-error
objectives when aligning fMRI signals with visual features.
Another line of work prioritizes neural-to-image reconstruction as the primary objective. MindEye2
[43] focuses on high-fidelity brain-to-image decoding under limited data conditions, proposing a
unified backbone that maps multi-subject fMRI signals into a shared latent space before projecting
them into image feature space. By combining contrastive objectives with reconstruction losses,
MindEye2 achieves strong image reconstruction quality with minimal per-subject data, particularly
in multi-subject scenarios. Similarly, VINDEX [57] emphasizes recovering essential visual details
from neural signals by introducing multi-granularity image features, enabling more precise neural
decoding across different semantic levels.
Other approaches aim to strengthen neural-visual correspondence through representation learning
techniques. MindBridge [54] constructs a unified fMRI-image-text manifold trained with a cyclic
consistency objective, encouraging bidirectional reconstruction between projected brain activity and
CLIP-based semantic embeddings. MindArtist [6] formulates alignment as an optimal transport prob-
lem with graph matching, decomposing neural representations into semantic content and contextual
style to enable controllable neural-to-image generation. Contrastive learning has also been widely
adopted: BrainCLIP [32] aligns fMRI embeddings with both CLIP visual and text features using a
dual contrastive objective, while MindTuner [20] introduces a visual pivot mechanism that anchors
neural signals to dense visual features before bridging them to language representations.
While these methods differ in supervision and architecture, they are primarily motivated by improving
alignment quality or reconstruction fidelity, often assuming access to complete visual information.
In contrast, our MindVLM is designed for brain captioning under partial visual observability,
where the goal is not to recover full image representations but to identify which visual concepts
are supported by neural activity. Rather than enforcing point-wise matching between fMRI signals
and global image embeddings, MindVLM derives global semantic representations from local visual
tokens and uses them to perform semantic evidence selection. This formulation preserves token-level
interpretability while avoiding over-constraining neural representations to visual details that may not
be neurally observed, enabling more faithful and subject-aware brain captioning.
A.1.2
Brain-to-LLM Integration
With the rapid advancement of Large Language Models (LLMs), recent work on brain-to-text
captioning has begun to directly inject fMRI signals into the token space of pretrained LLMs,
enabling the model to generate captions or answers without relying on an explicit visual encoder.
15


OneLLM [23] initiates this direction by introducing Universal Projection Modules that map fMRI
signals directly into the token embedding space of a frozen LLaMA2 [52]. This treats brain activity
as a new “language modality,” progressively aligned through instruction tuning without requiring
an intermediary visual representation. MindLLM [39] further advances this idea through Brain
Instruction Tuning, in which fMRI features are encoded as prefix tokens to an LLM. This subject-
agnostic encoder is optimized end-to-end, casting neural decoding as a pure language modeling task
applicable to captioning and VQA. However, these approaches overlook a key issue that the text
captions used as supervision are not naturally paired with the fMRI signals–the true pairing exists
between image and fMRI. As a result, training with text-only losses risks drifting away from the
actual perceptual semantics represented in the brain.
To address this, MindGPT [8] reintroduces a visual grounding mechanism by using a visually guided
neural encoder with cross-attention to map fMRI signals into the shared CLIP space. By distilling
CLIP’s joint vision-language semantics into the brain encoder, it allows the downstream GPT decoder
to produce captions that are more faithful to the viewed images. A related framework proposed by
(author?) [45] employs a 3D ViT [13] to extract fMRI features and hierarchically align them with
multi-level visual representations (low-level structure and high-level semantics) from a pretrained
vision encoder before projecting them into the LLM input space. This enables “brain-visual question
answering,” where neural activity functions as the model’s visual context. More recently, MindSA
[7] solves a different limitation that the inherent mismatch between entire images and the selective
perceptual content that subjects actually attend to. By dynamically masking out visual regions using
a differentiable semantic removal mechanism, it creates brain-compatible supervision for a frozen
GPT-2 decoder and ensures that generated captions reflect only the neurally processed semantics.
Despite their architectural diversity, all the models above share a critical constraint: they require a
frozen LLM during training, because the alignment or integration is optimized through text-based
supervision. This increases computational cost and risks introducing biases from textual priors
unrelated to the subject’s perceptual state. UMBRAE [56] mitigates this by training a universal brain
encoder that maps subject-specific fMRI signals into a shared space approximating the visual tokens
of a multi-modal LLM. This “Perceiver Encoder” enables brain signals to serve directly as visual
prompts, bypassing the need for explicit text decoding during training. Our MindVLM follows
this elegance of removing heavy LLMs from the training loop. However, instead of forcing fMRI
representations to exactly match frozen image/text features, which can over-constrain learning and
promote “over-imagining,” we perform adaptive alignment that preserves flexibility while maintaining
semantic fidelity. Moreover, by aligning at local-token derived global-level representations of visual
and neural modalities, our MindVLM naturally supports interpretable neural-to-language captioning,
enabling us to trace which visual tokens contribute to each part of the generated caption during
inference.
A.2
Dataset and Implementation
A.2.1
NSD Dataset
The Natural Scenes Dataset (NSD) [1] is a large-scale neuroimaging benchmark designed to capture
high-resolution fMRI responses during natural scene perception. It contains whole-brain 7T fMRI
recordings from eight participants at 1.8 mm isotropic resolution, collected while subjects viewed a
diverse set of real-world images. Each participant completed 30-40 scanning sessions and viewed
10,000 images (9,000 unique to each subject plus 1,000 shared across all subjects), for a total of 70,566
trials. All visual stimuli were selected from the Microsoft COCO (MS-COCO) [29] dataset [29],
a richly annotated corpus where each image is paired with five human-written captions describing
its semantic content. However, to accommodate the MRI display system and experimental design,
the original MS-COCO images–typically rectangular and much larger–were center-cropped and
resized to a 425×425 square resolution before being shown to participants. As a consequence, certain
objects mentioned in the captions may not appear in the cropped NSD stimulus, creating a systematic
semantic mismatch between the visual input that drives the neural responses and the full MS-COCO
caption set.
During the neural experiment, each image was presented for 3 seconds, accompanied by an object-
recognition task to ensure sustained attention and to probe recognition and memory processes. The
NSD pre-processing pipeline provides high-quality single-trial beta estimates obtained through
voxel-wise hemodynamic response modeling and advanced denoising, yielding exceptionally high
16


single-trial signal-to-noise ratios. In addition to the functional recordings, NSD includes anatomical
MRI, resting-state scans, and detailed behavioral performance measures. Functional data are delivered
in both subject-native cortical surface space and standardized volumetric spaces such as fsaverage
[18] and MNI152 [35], enabling flexible integration with popular neuro-imaging tools including
FreeSurfer [17] and FSL [46]. Furthermore, NSD provides manually annotated regions of interest
(ROIs), including retinotopic visual areas and high-level category-selective regions along the ventral
visual stream. In this paper, we adopt the nsdgeneral atlas, which yields various number of voxels:
15,724 (subj01), 14,278 (subj02), 13,039 (subj05), and 12,682 (subj07).
With its scale, annotation richness, and high spatial fidelity, NSD has become a central resource for
modeling human vision and advancing brain decoding methods that integrate neural, visual, and
linguistic information.
A.2.2
Implementation Details
In the main paper, we mainly report results using MindVLM with LLaVA [30] as the underlying
vision-language model. Specifically, we adopt the Stage-1 LLaVA-v1.5-7B configuration, where both
the language model and the visual encoder (OpenAI CLIP ViT-L/14-336) remain completely frozen
throughout training. To facilitate efficient contrastive alignment, we precompute visual features for
all images in the NSD dataset and load them directly during training. The fMRI encoder is a 4-layer
4-head Vision Transformer [13], following the architecture design of [9], and is trained from scratch
for our alignment task. We train the model for 150 epochs, including 10 warm-up epochs, using
a batch size of 1000. The learning rate is initialized at 7.5 × 10−3 and decayed to zero using a
cosine annealing schedule. Optimization is performed using AdamW with a weight decay of 0.05 and
gradient clipping set to 0.8. All hyperparameters are kept consistent across subjects unless otherwise
specified. Experiments are run on two NVIDIA RTX 6000 Ada GPUs. Training requires about 45
minutes per subject. During inference, we set the maximum number of new tokens VLM can generate
to 32 and use the system message as “You are a helpful assistant.” A fixed random seed of 2025 is set
for all experiments in both training and evaluation.

A.4
Visual Token Selection
The hyperparameter q controls the proportion of high-similarity neural-visual pairs retained (evidence)
during neural-visual matching and thus determines how many visual tokens are considered attended
by a subject. Figure 7 visualizes the distribution of the number of selected tokens across four subjects
for different q thresholds (5, 15, 35, and 50). As expected, the number of selected visual tokens
increases monotonically with q. At very low thresholds (e.g., q = 5), only a small subset of highly
confident neural-visual correspondences is preserved, resulting in a compact yet precise attentional
representation (typically 150-250 tokens). As q increases, more visual regions are included, gradually
expanding the perceptual coverage but also introducing greater variability across samples. This trade-
off between sparsity and completeness reflects how strict attention constraints (small q) emphasize
the most salient perceptual features, whereas larger q captures a broader, more diffuse perceptual field.
Across subjects, the token distributions are broadly consistent, indicating the robustness of our neural-
visual alignment mechanism. However, slight inter-subject variability can be observed–some subjects
(e.g., subj01) tend to yield higher token counts, suggesting individual differences in attentional spread
or representational granularity. These results confirm that q acts as a controllable knob for tuning the
balance between interpretability and perceptual coverage in subject-specific attention inference.

A.5
Brain-Vision Matching
The strong brain captioning performance in the previous section can be largely attributed to the
effectiveness of our proposed contrastive matching between brain and visual representations. In this
subsection, we turn our attention to directly evaluating this neural-visual mapping.
Distribution Analysis. To quantify the learned correspondence, we analyze the distribution of
similarity scores between fMRI and image embeddings across the 1,000 test samples. This results
in approximately one million fMRI-image pairs (including symmetric duplicates). We categorize
these pairs into two groups: correct pairs (the true image-fMRI pairs, 1,000 in total, shown in red)
and incorrect pairs (mismatched combinations, about 500k in total, shown in gray). According
to Figure 8, the similarity distribution reveals a clear separation between the two groups. The
incorrect pairs exhibit near-zero mean similarity, whereas the correct pairs show a significantly
higher mean similarity (greater than 0.4). This distinct margin indicates that the learned embedding
space effectively captures meaningful cross-modal correspondences between brain activity and visual
representations at a semantic level.
Retrieval Analysis. We further assess the learned neural-visual matching through N-way retrieval
tasks, a standard evaluation for cross-modal contrastive learning. As reported in Table 8, we conduct
retrieval under varying candidate pool sizes of 100, 200, 500, and 1,000, and measure performance
using Recall@K (R@1, R@5, and R@10). Both fMRI-to-image and image-to-fMRI retrieval
directions are evaluated. Across all settings, MindVLM achieves consistently strong results, showing
high retrieval accuracy even under large candidate pools. These results confirm that our model
learns a discriminative and semantically coherent shared space, where neural activity and visual
representations can be accurately matched in a bidirectional manner.

A.6
Semantic Loss & Decoding Consistency
To further examine the role of semantic selection in our paradigm, we compare performance between
fMRI-image pairs with and without semantic loss, across varying q thresholds. We report two
representative metrics–ROUGE (n-gram based) and METEOR (semantic-based)–and include the rest
in the Appendix A.7.2. As shown in Figure 9, the curves reveal a consistent trend: samples without
semantic loss outperform those with semantic loss across all q levels, indicating the robustness of
text-supervised fMRI-to-text decoding under well-aligned neural-visual-text triplets.
Quantitatively, the performance gap remains stable across thresholds: the no-semantic-loss group
achieves approximately 0.47 ROUGE and 0.28 SPICE at q = 95, compared to around 0.45 ROUGE
and 0.26 SPICE for the semantic-loss group. The monotonic improvement of both curves with q
suggests that while larger token pools improve decoding fidelity, semantic consistency in supervision
remains the dominant factor shaping model quality.
Overall, this result reinforces our central argument: accurate text supervision and semantically
aligned fMRI-image pairs are indispensable for reliable fMRI-to-text decoding. Rather than relying
on massive but noisy alignment sets, our paradigm advocates for selective and semantically consistent
training–a shift that bridges neural representation learning and grounded language modeling.

A.9
Limitations
MindVLM operates under an image-grounded inference paradigm, requiring access to the test image
at inference time. While this is a principled design choice that enables neural-guided semantic
evidence selection, it distinguishes NGVC from classic fMRI-to-text brain captioning and means
the two settings are not directly comparable. Second, MindVLM follows a per-subject training
paradigm, requiring a separate brain encoder for each subject due to neuro-anatomical variability
across individuals. While this enables subject-specific grounding, it does not benefit from multi-
subject data sharing, which has been shown to improve retrieval performance in other neural decoding
frameworks. Extending NGVC to a multi-subject or cross-subject setting is a promising direction
for future work. Third, because the brain encoder is aligned to a specific VLM’s visual encoder
space, separate encoders must be trained for VLMs with different visual backbones; a single trained
encoder does not transfer across architectures without retraining. Fourth, caption generation quality
is inherently bounded by the representational capacity of the frozen VLM–visual concepts absent
from the VLM’s token space cannot be recovered regardless of the quality of neural-visual alignment.
Finally, our evaluation is conducted exclusively on NSD, the largest publicly available fMRI dataset
for this task; generalization to other neural recording modalities such as EEG or MEG, or to datasets
with different cropping or annotation protocols, remains to be validated.

4. Experimental result reproducibility
Question: Does the paper fully disclose all the information needed to reproduce the main ex-
perimental results of the paper to the extent that it affects the main claims and/or conclusions
of the paper (regardless of whether the code and data are provided or not)?
Answer: [Yes]
Justification: All details necessary for reproducing the experimental results are fully de-
scribed in either the main paper or the appendix. The code will be released upon acceptance.
Guidelines:
• The answer [N/A] means that the paper does not include experiments.
• If the paper includes experiments, a [No] answer to this question will not be perceived
well by the reviewers: Making the paper reproducible is important, regardless of
whether the code and data are provided or not.
• If the contribution is a dataset and/or model, the authors should describe the steps taken
to make their results reproducible or verifiable.
• Depending on the contribution, reproducibility can be accomplished in various ways.
For example, if the contribution is a novel architecture, describing the architecture fully
might suffice, or if the contribution is a specific model and empirical evaluation, it may
be necessary to either make it possible for others to replicate the model with the same
dataset, or provide access to the model. In general. releasing code and data is often
one good way to accomplish this, but reproducibility can also be provided via detailed
instructions for how to replicate the results, access to a hosted model (e.g., in the case
of a large language model), releasing of a model checkpoint, or other means that are
appropriate to the research performed.
• While NeurIPS does not require releasing code, the conference does require all submis-
sions to provide some reasonable avenue for reproducibility, which may depend on the
nature of the contribution. For example
(a) If the contribution is primarily a new algorithm, the paper should make it clear how
to reproduce that algorithm.
(b) If the contribution is primarily a new model architecture, the paper should describe
the architecture clearly and fully.
(c) If the contribution is a new model (e.g., a large language model), then there should
either be a way to access this model for reproducing the results or a way to reproduce
the model (e.g., with an open-source dataset or instructions for how to construct
the dataset).
(d) We recognize that reproducibility may be tricky in some cases, in which case
authors are welcome to describe the particular way they provide for reproducibility.
In the case of closed-source models, it may be that access to the model is limited in
some way (e.g., to registered users), but it should be possible for other researchers
to have some path to reproducing or verifying the results.

Guidelines:
• The answer [N/A] means that the paper does not include experiments.

• The factors of variability that the error bars are capturing should be clearly stated (for
example, train/test split, initialization, random drawing of some parameter, or overall
run with given experimental conditions).
• The method for calculating the error bars should be explained (closed form formula,
call to a library function, bootstrap, etc.)
• The assumptions made should be given (e.g., Normally distributed errors).
• It should be clear whether the error bar is the standard deviation or the standard error

of Normality of errors is not verified.
• For asymmetric distributions, the authors should be careful not to show in tables or
figures symmetric error bars that would yield results that are out of range (e.g., negative
error rates).
• If error bars are reported in tables or plots, the authors should explain in the text how
they were calculated and reference the corresponding figures or tables in the text.
