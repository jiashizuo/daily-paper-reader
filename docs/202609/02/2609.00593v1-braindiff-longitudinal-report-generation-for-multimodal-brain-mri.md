## 摘要
神经放射科医生很少孤立地阅读脑部MRI，然而自动化脑部MRI报告生成几乎完全针对单次研究构建。时间分析已在胸部X光和胸部CT上得到探索，但据我们所知，针对脑部MRI的纵向报告——其中间隔变化通常细微且空间分布广泛——仍未得到解决。我们提出了BrainDiff，这是首个用于脑部MRI的纵向视觉-语言系统。在同一患者对上，BrainDiff优于前沿通用模型和单次研究神经影像模型。此外，BrainDiff在外部跨医院队列中保留了内部RadGraph-XL实体+关系F1（rg_er）的91%。除系统外，我们还贡献了三项分析。首先，我们识别出两个独立的接地杠杆：带有先前报告丢弃的反事实目标和分阶段课程，前者将测量的图像依赖提高了约47%。两者结合使图像依赖从基线提高了2.5倍。其次，我们对先前报告可用性和图像身份进行了因子分析，分离出+0.0387 rg_er的视觉贡献，当先前报告被隐藏时该贡献会增大。第三，对候选骨干网络的廉价变化可解码性测试表明，间隔变化比单次研究病理学更弱可解码（0.60 vs. 0.77 AUROC）。代码公开于https://github.com/jhuldr/BrainDiff。

## Abstract
Neuroradiologists rarely read a brain MRI in isolation, yet automated brain-MRI report generation has been built almost entirely for single studies. Temporal analysis has been explored on chest radiography and chest CT, but to our knowledge, longitudinal reporting for brain MRI, where interval change is often subtle and spatially distributed, remains unaddressed. We present BrainDiff, the first longitudinal vision-language system for brain MRI. BrainDiff outperforms both frontier general-purpose and single-study neuroimaging models on the same patient pairs. Moreover, BrainDiff retains 91% of internal RadGraph-XL entity+relation F1 (rg_er) on an external, cross-hospital cohort. Beyond the system, we contribute three analyses. First, we identify two independent grounding levers: a counterfactual objective with prior-report dropout, which increases measured image reliance by ~47%, and a staged curriculum. Together, these interventions raise image reliance 2.5-fold from the baseline. Second, we provide a factorial over prior-report availability and image identity, isolating a visual contribution of +0.0387 rg_er, which grows when the prior report is withheld. Third, a cheap change-decodability test for candidate backbones shows that interval change is decodable far more weakly than single-study pathology (0.60 vs. 0.77 AUROC). Code is publicly available at https://github.com/jhuldr/BrainDiff.

## 2. 论文提出的方法论

### 2.1 总体架构
BrainDiff（架构见图1）建立在NeuroVFM预训练权重基础上（ViT-B视觉编码器、Qwen3-14B解码器、Perceiver-IO重采样连接器），整体采用冻结骨干+LoRA适配的方式，可训练参数共约95.5M。

### 2.2 配对视觉前缀（Paired Visual Prefix）
- 每个时间点的每种（block, modality）序列**独立重采样**为64个视觉token，从而天然解决两次扫描携带不同模态集合的临床现实问题；
- 视觉分组按"block-major"顺序排列（先prior后current，如有delta通路则再加第三组），只有在某序列实际存在时才发射对应组；
- 每组添加可学习的**时间嵌入**以区分先验与当前时间点；
- 视觉前缀采用"左填充"策略，确保监督文本构成连续尾部，适配解码器上下文。

### 2.3 先验报告条件化与解码
- 先验时间点报告文本被放置于图像占位符之后、指令之前，作为模型生成当前比较报告的对比基线。

### 2.4 训练目标
- 主损失为逐token交叉熵（CE），分阶段引入加权CE（非样板token权重λ=1.2或1.5）、句子对比对齐损失；
- 为缓解脑部报告文本中45.1%的模板化正常描述问题，加权CE抑制了模板背诵。

### 2.5 反事实接地与先验报告丢弃（核心创新之一）
- **反事实目标（counterfactual grounding）**：要求"正确先验图像+报告"的负对数似然低于"被替换的他人先验图像+报告"，间隔设为0.5，增量约束模型必须真正参考图像基线；
- **先验报告dropout**：以p=0.3的概率在训练中丢弃先验报告文本，使"无先验"条件进入训练分布，抑制文本捷径，并让下游因子分析中的无先验条件保持一致分布。
- 该CE目标与评估指标（swap-based reliance）密切相关，作者另设了一个从未被优化的时间反转探针作为佐证。

### 2.6 分阶段课程（Staged Curriculum）
四个训练阶段各司其职：
- **S1**：在由公共病灶分割数据集程序化构建的grounding语料上训练（定位型引用、描述生成、反指定位、多标签病理分类），解码器冻结，安装空间接地与病理词汇；
- **S2**：在38,086份MR-RATE单次研究报告上学习单次研究报告撰写，让模型学会仅凭图像产出报告；
- **S3**：预训练差异路径（仅存在于delta-on配置中，重构对比+InfoNCE+显著性三项损失）；
- **S4**：在14,642对纵向上安装时间比较语言，激活解码器LoRA。
- 消融结果显示：移除S1/S2虽然几乎不影响最终rg_er分数，但会显著降低图像依赖度，说明课程不是数据效率工具而是一个"接地杠杆"。

### 2.7 差异通路（ChangeMapEncoder，最终被消融）
- 在重采样之前，让当前研究的每个token对先验研究的±1邻域（27-token）进行交叉注意力，产生配准校正后的残差，再经MLP映射后门控池化成4×4×4坐标标记的change map。
- 最终实验证明该通路无显著收益（+0.0009 rg_er），属于被否定验证的设计。

## 6. 论文的主要结论与发现

1. **BrainDiff全面超过现有基线**：在同一患者对上，BrainDiff rg_er 0.3837，超过NeuroVFM（0.3614，+0.0222），远胜Opus 5（0.2083，+0.1787）与GPT-5.6 Sol（0.2920，+0.0950）；方向判断平衡精度41.7%（NeuroVFM仅32.6%）。
2. **跨院泛化良好**：在BIND外部队列保留91%的rg_er性能（0.3506），且图像依赖不降反升（+0.0444 vs 内部+0.0387），说明格式化差异降低了文本捷径的可靠性。
3. **两个接地杠杆独立有效**：反事实目标+先验报告dropout使图像依赖从+0.0263升至+0.0387（相对提升约47%）；叠加分阶段课程后总计从+0.0156升至+0.0387（约2.5倍），报告质量仅以1.5%的微小代价换来47%接地增益。
4. **视觉贡献可分解且被低估**：因子分析显示最直观的0.3837分中有64%来自指标地板（0.2471），26%来自学习到的报告先验（+0.0979），仅10%（+0.0387）来自图像本身；当先验报告被隐藏时，图像贡献增长至+0.0544。
5. **骨干网络瓶颈的量化负结果**：显式差异编码器无帮助（+0.0009 rg_er，置信区间跨零），根本原因在于冻结的NeuroVFM特征中间隔变化可解码性（0.601 AUROC）远弱于单次病理（0.766）；但跨患者池化会虚增至0.702，说明此类探针必须做患者内配对设计。
6. **安全关键的错误方向**：模型将46%的真实恶化病例判为稳定——这与骨干的空间分辨率限制（token约覆盖16mm各向同性）预判吻合，界定了下一代编码器需达到的最低门槛。

- **代码开源**，且所有接地干预均标注为"架构无关"，可迁移至胸部等其他域。

## 8. 不足与局限

- **评估目标为LLM合成报告**：主指标的打分对象是GPT-5.4生成的合成比较报告，这天然有利于文本到文本的生成模型；虽然做了97%抽样人工审核与真实Impression排名验证（差异方向一致：+0.0075），但主要结论仍建立于合成基准之上，绝对分数不能等同于真实临床报告质量。
- **真实放射科文本验证仅限排名测试**（附录S2）：绝对分低（0.096 vs 0.089），整个真实文本对比也仅是一个方向保持性检验，

整个真实文本对比也仅是一个方向保持性检验，而非全面的质量评价，因此在“模型生成的真实报告是否达到临床可用水平”这一问题上，证据仍是间接的。

- **数据规模与多样性受限**：纵向训练对仅来自 MR-RATE 单一机构队列（14,642 对），外部验证虽在 BIND 上完成，但 S4 阶段的域间差异、扫描仪协议漂移、真实随访中的间隔长度不一等，均未显式建模。合成报告的间隔标签由 LLM 从文本推断，缺少像素级真实变化标注，限制了差异信号的学习上限。
- **骨干网络的冻结是双刃剑**：冻结 NeuroVFM 特征避免了灾难性遗忘和训练成本，但也封死了时间变化建模的上限。论文已证明骨干特征对间隔变化的可解码性远低于病理状态，而所有后续适配都未能绕过这一瓶颈，未来可能需要端到端微调或重新预训练。
- **评估粒度不足**：主要指标 rg_er 是实体+关系级别的 F1，虽优于 n-gram，但未细分实体类型（如“增强”“无变化”）的方向错误代价；间隔变化分类仅四类平衡准确率，未包含更细的定量变化（如前後体积变化百分比）。
- **未与真实临床报告者对比**：没有邀请放射科医生在盲测中比较 BrainDiff 输出与真实报告/其他基线的偏好，缺乏“临床可接受度”的最终验证。
- **资源与细节披露不全**：正如资源章节所指出的，算力配置、训练耗时、显存占用均未报告，影响复现效率和公平比较。
- **边界条件未充分探索**：当先验研究模态全部缺失、或只有单个序列时（如仅 T2-FLAIR），模型行为未单独分析；间隔变化方向的误判（46% 恶化判为稳定）虽被归因于空间分辨率，但未尝试通过 token 尺寸减半等简单反事实加以验证。

## 9. 总结性评价
BrainDiff 在任务选择、接地量化方法论和负结果解剖三方面具有较突出的贡献，为纵向神经影像报告生成确立了一个“不只看文本、更要看图像”的评估新基准。它清晰地告诉社区：此前纵向上报告的“增益”很大一部分来自文本捷径；只有通过反事实训练和有控制的因子分析，才能真正测量模型对视差信息的利用。该工作的局限性（合成标签、冻结骨干、单一机队数据）也同时指明了下一步最值得攻克的方向——更真实的纵向标注、更敏感的时间差异骨干，以及更贴近临床终点的评估协议。

尽管存在上述不足，BrainDiff 作为首个脑 MRI 纵向视觉语言系统，在问题设定、严谨消融和开源工具方面仍具高参考价值，值得作为后续纵向医学影像生成研究的标准比较对象和基线框架。
