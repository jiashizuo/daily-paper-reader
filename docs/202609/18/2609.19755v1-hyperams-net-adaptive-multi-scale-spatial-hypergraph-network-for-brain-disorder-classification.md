## 摘要
从神经影像数据中准确分类脑疾病仍然具有挑战性，因为受试者间存在显著异质性，并且功能连接和形态表征中呈现出复杂的多尺度模式。为了解决这些挑战，我们提出 HyperAMS-Net，一个使用源自静息态功能 MRI 或结构 MRI 的神经影像表征进行脑疾病分类的深度学习框架。HyperAMS-Net 集成了自适应多尺度卷积、超图注意力、空间-通道注意力以及自适应特征融合。具体而言，自适应多尺度卷积在多个感受野上学习数据驱动的权重，以捕获不同尺度上的互补模式。超图注意力通过节点—超边—节点消息传递来建模所学特征表征之间的高阶依赖关系，而空间-通道注意力增强判别性特征学习。自适应特征融合进一步聚合并行网络分支之间的互补信息。HyperAMS-Net 在涵盖不同脑疾病的三个基准数据集上进行评估：用于自闭症谱系障碍的 ABIDE、用于重性抑郁障碍的 REST-meta-MDD，以及用于阿尔茨海默病的 ADNI，采用 5 折分层交叉验证。HyperAMS-Net 在所有评估数据集上均取得了最先进的性能，在比较方法中获得了最高的准确率和 AUC。消融研究进一步证明了每个所提出组件的贡献，其中移除超图注意力时观察到最大的性能下降。

## Abstract
Accurate classification of brain disorders from neuroimaging data remains challenging because of substantial inter-subject heterogeneity and the complex multi-scale patterns present in functional connectivity and morphological representations. To address these challenges, we propose HyperAMS-Net, a deep learning framework for brain disorder classification using neuroimaging representations derived from resting-state functional MRI or structural MRI. HyperAMS-Net integrates adaptive multi-scale convolution, hypergraph attention, spatial-channel attention, and adaptive feature fusion. Specifically, adaptive multi-scale convolution learns data-driven weights over multiple receptive fields to capture complementary patterns at different scales. Hypergraph attention models higher-order dependencies among learned feature representations through node--hyperedge--node message passing, while spatial-channel attention enhances discriminative feature learning. Adaptive feature fusion further aggregates complementary information across parallel network branches. HyperAMS-Net is evaluated on three benchmark datasets spanning distinct brain disorders: ABIDE for autism spectrum disorder, REST-meta-MDD for major depressive disorder, and ADNI for Alzheimer's disease, using 5-fold stratified cross-validation. HyperAMS-Net achieves state-of-the-art performance across all evaluated datasets, attaining the highest accuracy and AUC among the compared methods. Ablation studies further demonstrate the contribution of each proposed component, with the largest performance degradation observed when hypergraph attention is removed.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究领域**：从神经影像数据（静息态 fMRI 功能连接、结构 MRI 形态学表征）中自动分类脑疾病（自闭症 ASD、重性抑郁障碍 MDD、阿尔茨海默病 AD）。
- **核心痛点**：
  - **受试者间异质性强**：跨站点、跨个体的脑影像数据差异显著，导致分类泛化困难。
  - **多尺度模式复杂**：功能连接与形态学表征中同时存在细粒度与全局性的判别模式，常规单尺度卷积难以同时捕获。
  - **高阶依赖建模不足**：传统图方法（BrainGNN、PopulationGCN、KMGCN、AGMGC）主要编码**成对（pairwise）**关系，无法刻画多个脑区之间的高阶群组交互。
- **整体含义**：论文尝试将 **自适应多尺度特征提取** 与 **超图高阶关系建模** 统一到一个深度框架中，为跨疾病、跨模态的脑影像分类提供通用解决方案。

## 2. 方法论

### 2.1 核心思想
构建一个多分支深度网络，输入统一表示为 `X ∈ R^{B×H×W×C}`（原始 FC 矩阵或 ROI 形态矩阵，缩放至 224×224，通过通道复制得到 C=3），依次经过 **AMSConv → HGA → SCA → AFF** 四个组件完成特征提取与融合。ROI 顺序在数据集内固定，保证受试者间矩阵位置对应。

### 2.2 关键技术细节

- **自适应多尺度卷积（AMSConv）**
  - 并行使用 3 个感受野尺度 `s ∈ {1,2,3}`，卷积核分别为 `3×3、5×5、7×7`，每个分支输出 64 个特征图。
  - 每个尺度特征经 `ReLU(BN(W_s * X̂))` 得到。
  - 用 **softmax 归一化的全局可学习权重** `α̃_s = exp(α_s) / Σ exp(α_j)` 对多尺度特征加权求和，`α_s` 初始化为 1，随网络联合优化。
  - 与样本级门控不同，权重是**全局学习**的，反映各尺度对整体分类任务的相对重要性。

- **超图注意力（HGA）**
  - 将特征图重塑为 token 序列 `T ∈ R^{B×N×C}`（N = h×w），计算 Q、K、V 投影。
  - 定义 **M = 8 个可学习的虚拟超边**，通过可学习投影 `W_E ∈ R^{C×M}` 并沿节点维度 softmax 得到节点—超边软关联矩阵 `I = softmax_N(T·W_E)`。
  - 节点到超边聚合：`U = I^T·V`；超边间亲和矩阵 `H ∈ R^{M×M}` 用于精炼：`Ũ = softmax(H)·U`。
  - 输出融合成对自注意力与高阶上下文：`T_out = softmax(A)V + I·Ũ`，其中 `A = QK^T/√C`。
  - 通过残差连接与输入相加后再 BN。

- **空间—通道注意力（SCA）**
  - 借鉴 CBAM，串行执行：
    - **通道注意力**：全局平均/最大池化 → 共享两层 MLP（压缩比 r=8）→ Sigmoid → 通道乘。
    - **空间注意力**：沿通道平均/最大池化 → 拼接 → 7×7 卷积 → Sigmoid → 空间乘。

- **多分支架构与自适应特征融合（AFF）**
  - AMSConv 输出后进入 3 个并行分支，每个分支输出 `b_i ∈ R^{h×w×128}`。
  - 用 **softmax 归一化的 128 维融合权重** `Φ` 进行逐元素加权求和后 BN，得到融合特征。

- **分类头与训练目标**
  - GAP → 全连接 → BN → ReLU → 全连接 → Sigmoid 输出概率。
  - 损失函数为 **类别加权二元交叉熵**，权重 `ω_0、ω_1` 由训练折的逆频率计算，缓解类别不平衡。

## 7. 优点

- **方法创新点明确**：
  - AMSConv 用**全局可学习 softmax 权重**替代手工设计或样本级门控，简洁且可端到端训练。
  - HGA 采用**可学习虚拟超边**，避免依赖预定义超图结构（如 k-NN 超边构造），提升灵活性。
  - 将超图高阶建模与成对自注意力并联（`softmax(A)V + I·Ũ`），兼顾两类关系。
- **架构整合度高**：AMSConv + HGA + SCA + AFF 形成完整的多尺度—高阶—注意力—融合链路。
- **实验设计相对严谨**：
  - 三个不同疾病、不同模态的数据集交叉验证，泛化性证据较强。
  - 类别加权 BCE 处理类别不平衡；预处理统计仅来自训练折，避免泄漏。
  - 引入配对 t 检验，超出多数同类工作仅报告均值的做法。
