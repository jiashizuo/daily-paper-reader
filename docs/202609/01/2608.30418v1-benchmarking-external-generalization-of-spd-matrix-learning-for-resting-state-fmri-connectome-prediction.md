## 摘要
静息态功能磁共振成像（rs-fMRI）功能连接（FC）矩阵广泛用于个体水平预测，但在一个队列中的强性能可能无法泛化到新队列。我们探讨当测试数据来自完全留出的rs-fMRI数据集时，数据集内性能是否仍然保持。每次扫描被表示为一个正则化的对称正定（SPD）相关连接组，这允许方法利用SPD流形的几何结构。我们引入了一个跨六个rs-fMRI数据集（COBRE、ADNIDOD、Cam-CAN、ABIDE、OASIS-3和ADNI）的可复现年龄预测基准。该基准在数据集内GroupKFold、合并GroupKFold和留一数据集（LODO）评估下，比较了向量化相关基线、切空间岭回归、SPDNet和分裂式黎曼协调。数据集内和合并GroupKFold的结果明显优于LODO结果。当整个数据集被留出时，预测误差增加，方法之间的差异缩小，性能受到年龄范围不匹配和队列异质性的强烈影响。该基准提供了通用输入、模型设置、数据划分和分析脚本，以便未来的SPD矩阵学习方法可以在相同的外部验证协议下进行评估。

## Abstract
Resting-state functional magnetic resonance imaging (rs-fMRI) functional connectivity (FC) matrices are widely used for individual-level prediction, but strong performance within one cohort may not generalize to a new cohort. We ask whether within-dataset performance remains when the test data come from an entirely held-out rs-fMRI dataset. Each scan is represented as a regularized symmetric positive definite (SPD) correlation connectome, which allows methods to use the geometry of the SPD manifold. We introduce a reproducible age-prediction benchmark across six rs-fMRI datasets: COBRE, ADNIDOD, Cam-CAN, ABIDE, OASIS-3, and ADNI. The benchmark compares a vectorized correlation baseline, Tangent-Space Ridge, SPDNet, and split-wise Riemannian harmonization under within-dataset GroupKFold, pooled GroupKFold, and leave-one-dataset-out (LODO) evaluation. Within-dataset and pooled GroupKFold results are substantially more favorable than LODO results. When an entire dataset is held out, prediction error increases, differences among methods narrow, and performance is strongly affected by age-range mismatch and cohort heterogeneity. The benchmark provides common inputs, model settings, data splits, and analysis scripts so that future SPD matrix learning methods can be evaluated under the same external-validation protocol.

- **意义**：本文将外部泛化问题从“次要检查”提升为核心评估标准，提出了一个可复现的跨数据集基准，尤其针对SPD（对称正定）矩阵学习方法在真实数据集偏移下的鲁棒性进行系统性评测。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想

以**年龄预测**为统一回归任务，将每次扫描表示为**正则化的SPD相关连接组矩阵**，利用SPD流形的黎曼几何结构建模，并评测不同方法在数据集内与跨数据集条件下的表现差异。

### 2.2 数据预处理与连接组构建

1. **时间序列提取**：使用 Schaefer-100 皮层图谱对大脑进行分区，提取各区域时间序列。
2. **协方差估计**：采用 **Oracle Approximating Shrinkage（OAS）** 估计器获得扫描级别的正则化协方差矩阵。
3. **相关归一化**：添加微小对角项（ε = 10⁻⁵）后，将协方差矩阵归一化为相关矩阵，确保正定性；再做矩阵对数运算前施加数值稳定化处理。

### 2.3 代表模型

- **Tangent-Space Ridge（切空间岭回归）**：
  - 以训练集上的 **Fr´echet 均值**为参考点，将SPD矩阵通过仿射不变黎曼度量映射到切空间；
  - 对切向量进行加权向量化（对角元素权重为1，非对角元素权重为√2）；
  - 使用 z-score 标准化后，采用岭回归进行预测，正则化参数 α 通过分组内部交叉验证选取。
- **SPDNet**：
  - 神经网络结构，包含 **BiMap**（可学习的双线性映射）、**ReEig**（特征值整流）和 **LogEig**（矩阵对数）层；
  - 最终将对数域矩阵展开为向量，通过多层回归头预测年龄；
  - 采用 Adam 优化器、MSE 损失、固定种子和早停策略。
- **基线方法**：
  - **Dummy**：始终预测训练集平均年龄的无信息参照；
  - **CorrVec**：将相关矩阵上三角（非对角项×√2）向量化后送入岭回归的欧几里得基线。

### 2.4 黎曼调和（Riemannian Harmonization）

- 将SPD矩阵映射到切空间，用 **ComBat 经验贝叶斯模型**校正数据集/站点效应，再映射回SPD流形；
- **站点（SITE）作为批次效应，年龄作为需保留的生物协变量**；
- 关键设计：**调和模型仅基于每个划分的训练数据拟合**，防止信息泄漏。

### 3.2 评估协议

1. **数据集内 GroupKFold（K=5）**：在每个数据集内部按被试分组划分；
2. **合并 GroupKFold**：六个数据集合并后按被试分组交叉验证；
3. **留一数据集（LODO）**：每次留下整个数据集作为测试，其余五个训练，严格模拟外部泛化场景。

- 指标：负平均绝对误差（NegMAE）、决定系数（R²）、LODO下的Spearman秩相关系数 ρ。

### 充分性评价

- **优点**：覆盖了不同年龄范围、诊断构成、纵向结构、站点数量的异质数据集；采用多种互补指标（误差、方差解释、秩相关）；固定随机种子确保可复现性；既有数据集内参照又有严格的外部验证。
- **不足**：所有结果基于**单一随机种子**，论文明确提醒不应推广为跨种子的鲁棒性结论；未进行运动敏感性分析、GSR敏感性分析、多随机种子扩展运行等辅助实验。

## 6. 主要结论与发现

1. **数据集内性能"有用但不完整"**：各方法在数据集内普遍优于Dummy基线，SPDNet在多数大数据集上表现最佳，但无法据此推断外部泛化能力。
2. **合并评估比LODO乐观得多**：合并GroupKFold下所有方法远超Dummy；而LODO下误差显著增大、R²常为负值、方法间差距缩小。
3. **ABIDE是最极端的留出折**：由于年龄分布（中位数≈14.9岁）与其余数据集的成人/老年分布严重不匹配，导致所有方法表现剧烈下降。
4. **秩相关保留信息**：即使绝对误差大、R²差，Tangent-Space Ridge和SPDNet仍能保持一定的年龄排序能力，说明外部偏移下仍有部分信号可保留。
5. **调和效果依赖协议**：切空间岭回归在调和后获益明确，SPDNet获益较小且不稳定；合并GroupKFold下的调和使用了真实测试年龄，LODO则未对留出数据做调和。
6. **更大SPDNet配置不保证更好迁移**：四种配置没有一种在全部指标上一致最优。

## 7. 优点

- **填补方法论空白**：首次为SPD矩阵学习构建了系统的**跨数据集外部泛化基准**；
- **严格的泄漏控制**：所有数据相关量（Fr´echet均值、标准化参数、调和模型、超参数）均仅从训练划分估计；
- **多维评估视角**：同时使用MAE、R²和Spearman ρ，区分绝对精度与排序保持力，全面反映外部迁移表现；
- **强调简单基线的重要性**：CorrVec和Dummy提供透明、可解释的参照系，防止夸大复杂模型的优势；
- **可复现性设计**：公开代码、固定随机种子、明确数据划分逻辑和文档化模型配置，并发布部分派生数据。
- **严谨的斯科普适性声明**：明确年龄仅是基准任务而非生物学完整的衰老度量，结果应视为方法学比较而非临床应用验证。

## 8. 不足与局限

- **单一目标任务的局限**：仅使用年龄作为预测目标，不能代表临床结局或完整生物衰老度量；
- **运动效应的未控制**：各数据集缺少统一的扫描级运动测量和运动排除日志，残留运动可能混杂功能连接特征并随年龄/数据集变化；
- **年龄范围不匹配的严重干扰**：尤其针对ABIDE，LODO结果更接近外推而非普通迁移，难以单独分离技术差异与人口学差异的贡献；
- **预测任务的信息泄漏风险**：合并GroupKFold中，数据集身份可能作为间接捷径被模型利用；另外，调和在合并评估中使用了真实测试年龄，不符合测试年龄未知的实际应用场景；
- **随机种子覆盖不足**：仅固定一组随机种子，无法评估结果的随机波动范围；
- **缺少消融分析**：未比较“含年龄”与“不含年龄”的ComBat方案，也未对运动、全局信号回归等预处理选择做敏感性分析；
- **混合因素不可分离**：数据集之间的差异同时包含人口结构、诊断构成、纵向结构、站点与技术参数等多重因素，无法单独归因。
