## 摘要
脑龄预测模型通常以预测准确性来评估，但仅凭准确的预测并不能证明模型依赖于可重复或具有神经生物学支持的机制。事后解释方法可以揭示这些机制，但现有工作流程通常止步于诊断，或要求在模型分析之前指定校正目标。我们提出 XAI-Refine，一种用于基于静息态功能连接的脑龄预测的自动化解释-知识循环。在每次迭代中，XAI-Refine 将跨重复训练运行的互补事后分析整合为可靠且结构化的模型解释。它将每个可靠解释转化为一个中性的神经生物学问题，检索并验证相关文献，并将经过验证的证据编译为同一类型化解释空间中的可容许集合。精化目标定义为当前模型解释在由适用且经验证的知识所诱导的可容许集合上的最小投影。随后，这一修订后的解释被转换为可微约束，同时保留其来源模型变量、测量算子和适用范围。仅当多种子验证确认出现目标导向的解释性变化、预测性能保持在预先设定的护栏范围内，且非目标解释漂移保持有界时，候选更新才会被采纳。在基于功能连接的脑龄预测上的实验评估了预测性能、解释可靠性、文献一致性以及针对特定目标的模型修正，展示了从事后分析到证据引导的模型精化的结构化路径。

## Abstract
Brain-age prediction models are commonly evaluated by predictive accuracy, yet accurate predictions alone do not establish that a model relies on reproducible or neurobiologically supported mechanisms. Post-hoc explanation methods can expose these mechanisms, but existing workflows typically stop at diagnosis or require correction targets to be specified before model analysis. We propose XAI-Refine, an automated explanation-knowledge loop for brain-age prediction from resting-state functional connectivity. At each iteration, XAI-Refine consolidates complementary post-hoc analyses across repeated training runs into reliable, structured model explanations. It converts each reliable explanation into a neutral neurobiological question, retrieves and verifies relevant literature, and compiles the verified evidence into an admissible set in the same typed explanation space. The target for refinement is defined as the minimal projection of the current model explanation onto the admissible set induced by applicable verified knowledge. This revised explanation is then translated into a differentiable constraint while preserving the originating model variable, measurement operator, and applicable scope. Candidate updates are promoted only when multi-seed validation confirms target-directed explanatory movement, predictive performance remains within a prespecified guardrail, and non-target explanatory drift remains bounded. Experiments on functional-connectivity-based brain-age prediction evaluate predictive performance, explanation reliability, literature alignment, and target-specific model revision, illustrating a structured route from post-hoc analysis to evidence-guided model refinement.

## 1. 核心问题与整体含义

- **研究动机**：脑龄预测（brain-age prediction）模型通常仅以预测精度（如 MAE、PCC）作为评价标准，但低预测误差并不能证明模型依赖了可复现或具有神经生物学支持的机制。
- **关键矛盾**：事后解释（post-hoc explanation）方法虽可揭示模型行为，但存在两类不足——（1）单一解释在不同训练运行间可能不稳定，或与底层预测器耦合薄弱；（2）现有 Explanation-Guided Learning（EGL）通常要求在模型分析之前预先指定校正目标。
- **核心问题**：如何在不预设修正目标的前提下，将模型自身的可靠解释与独立验证的科学文献证据连接起来，形成可审计、可迭代的模型精炼闭环？
- **整体含义**：论文将科学模型精炼从单向的事后诊断，重新表述为「预测–解释–知识」闭环，使验证过的知识能够约束预测器的解释行为，最终逼近一个「证据一致的解释均衡」。

## 2. 方法论

### 2.1 核心思想

XAI-Refine 通过迭代循环：

$$f_{\theta_t} \xrightarrow{E} z^M_t \xrightarrow{Q,V} \kappa_t \xrightarrow{P} z^R_t \xrightarrow{U} f_{\theta_{t+1}}$$

将解释发现（E）、文献验证（Q, V）、最小投影（P）与模型更新（U）串联为闭环。

### 2.2 关键技术细节

- **可靠事后解释发现（E）**：
  - 在 S 个随机种子下训练预测器，对每个分析 $j$（含模型量 $v_j$、测量算子 $\Phi_j$、评估范围 $\Omega_j$）做种子间聚合。
  - 用支持度、覆盖率、跨种子稳定性三者的最小值作为可复现性 $\rho_{t,j}$。
  - 额外计算忠实性分数 $\text{Fid}_{t,j}$（扰动响应、模型随机化、输入随机化等）。
  - 只有同时满足 $\rho \geq \tau_\rho$ 且 $\text{Fid} \geq \tau_F$ 的解释记录才进入验证循环。
  - 解释类型覆盖：预测行为、纵向一致性、特征响应、归因结构、表征几何。

- **文献验证与知识集编译（Q, V）**：
  - 将可靠解释转为**中性科学问题**：保留科学变量、关系类型、人群、测量设置与范围，但**不透露**模型观测到的方向、幅度与可靠性，以避免检索确认偏差。
  - 验证算子执行文献检索、书目验证、证据抽取与范围评估，输出结构化知识记录 $\kappa_{t,j} = (v_j, \Omega^K_{t,j}, r^K_{t,j}, c_{t,j}, s_{t,j}, B_{t,j})$。
  - 通过范围对齐 $\Omega^\cap_{t,j} = \text{Align}(\Omega_j, \Omega^K_{t,j})$ 确定模型侧与知识侧可比较的部分。
  - 确定性编译器将验证关系映射到同一类型化解释空间，得到可采纳集 $C_{K,t,j} \subseteq Z_j$（如方向标量约束、区间约束、排序/几何约束；无适用证据时返回 $Z_j$，即不产生文献驱动修正）。

- **最小解释投影与模型精炼（P, U）**：
  - 精炼目标定义为当前模型关系在可采纳集上的**最小变化投影**：
    $$r^R_{t,j} = \text{Proj}_{C_{K,t,j}}(r^M_{t,j}) = \arg\min_{r \in C_{K,t,j}} D_j(r, r^M_{t,j})$$
  - 投影只改变知识一致性所必需的部分；若 $r^M \in C_K$ 则保持不变。
  - 可执行修正筛选：投影差距 $g^{\text{proj}} > \varepsilon_{\text{eq}}$、置信度 $w \geq \tau_w$、对齐范围非空。
  - 将修订解释转为可微约束（保留原始 $v_j$ 与 $\Phi_j$）：
    $$\tilde{\theta}_{t+1} \in \arg\min_\theta \left[ \mathcal{L}_{\text{pred}} + \lambda \sum_{j \in A_t} \alpha(w_{t,j}) [\delta_{t,j}(\theta) - \varepsilon_{R,j}]_+ \right]$$
  - 非可微算子使用可微代理训练，但优化后必须用原始算子重新测量。
  - **验证门控晋升**：预测退化在护栏内、目标解释差距下降、非目标解释漂移有界，三者同时满足才晋升；否则保留父模型。
  - 达到证据一致均衡（所有合格关系已属于可采纳集）或满足终止条件时停止。

## 6. 主要结论与发现

- **预测与解释联合提升**：完整 XAI-Refine 相对父模型 $f_0$，MAE 从 4.5360 降至 4.3813，PCC 从 0.4788 升至 0.5274，Confirmation 从 0.4000 升至 0.6500，AEA 从 0.3646 升至 0.5722。
- **目标修正高特异性**：实现 84.44% 的预设目标方向，Drift 仅 0.0286（几乎无超出普通重训练波动的非目标变化）；TRS、PPR、DPR 均为对比策略中最高或次高。
- **多种子聚合 + 忠实性过滤有效**：单次运行 Confirmation 仅 0.1091，多种子聚合升至 0.4500，完整可靠发现协议进一步升至 0.6500，Faithfulness 升至 0.8455。
- **文献验证审计结果**：证据状态一致率 83.8%，精确弃权一致率 89.2%，可采纳修订 86.5%，变量保留 100%、算子保留 97.3%、修订范围保留 94.6%；严格范围一致率较低（69.7%），主要错误是把宽泛/连接族证据过度编译为具体强化约束。
- **消融结论**：可靠性过滤决定「什么可被修订」，类型化投影决定「如何定义修订」，响应探测与稀疏组合选择控制「能否在不必要模型改变下实现修订」；移除任一组件均导致确认度、Progress 或 Drift 恶化。
- **迭代价值**：Loop 1–6 为主轨迹，Loop 7–9 探索未超越 Loop-6 验证结果，说明闭环能持续生成候选但需验证门控防止无效更新。
- **案例发现**：对后扣带回/楔前叶相关 FC 家族，文献仅支持「与正常老化相关」而未确立方向，XAI-Refine 因此只做**方向中性的相对重要性修订**，体现证据特异性与修订粒度匹配的设计原则。

## 7. 优点

- **闭环范式创新**：将事后解释从诊断终点变为可迭代的科学假设生成器，与文献验证、最小投影、可微约束形成完整闭环。
- **类型化最小修订**：把「证据验证」与「优化损失」分离，LLM/验证器不直接输出数值目标，而由投影在可采纳集上确定最小变化，避免 LLM 凭空编造训练目标。
- **模型盲问题生成**：生成中性科学问题时隐藏模型观测方向与幅度，有效抑制文献检索的确认偏差。
- **变量–算子–范围保持**：修订始终作用于产生原始假设的同一模型量与测量算子，保证语义对应与可审计性。
- **验证门控与响应探测**：候选更新需通过预测护栏、目标移动、非目标漂移三重验证；响应探测区分「约束诱导移动」与「普通训练延续」。
- **评估维度全面**：不仅看预测精度，还评估解释确认、忠实性、领域对齐、目标修正特异性与漂移，并区分「证据一致均衡」与「无可行更新」两种终止状态。
- **审计透明度高**：附录详细给出问题构造、检索、验证、编译、投影、晋升、终止的全部操作定义与公式，可复现性强。

## 8. 不足与局限

- **证据依赖风险**：框架依赖事后解释可靠性、文献检索与证据验证质量；不完整、冲突或范围错配的证据可能导致不当弃权或过度修订。
- **非因果/非临床验证**：知识一致性不等于因果或临床验证，脑龄预测与解释可能反映人口统计学或数据集偏差，不适用于个体临床决策。
- **单模态与单队列**：仅限静息态功能连接，仅使用 EHBS 一个队列，缺少跨人群、跨采集站点、跨成像协议的外部验证。
- **审计方法学局限**：
  - 仅一名评审员，无法计算评审员间一致性。
  - 37 条记录为**目的性分层诊断
