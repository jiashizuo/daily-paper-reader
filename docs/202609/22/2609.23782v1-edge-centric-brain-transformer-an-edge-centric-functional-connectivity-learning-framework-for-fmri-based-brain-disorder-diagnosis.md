## 摘要
静息态功能磁共振成像（rs-fMRI）能够刻画分布式脑区之间的功能交互，并在脑疾病诊断中展现出潜力。然而，现有深度学习方法主要依赖以节点为中心的表示，将脑区作为主要学习单元，可能忽略功能连接中蕴含的具有判别性的改变。为此，我们提出一种以边为中心的脑Transformer（EBT）框架，将rs-fMRI分析重新表述为功能连接表示学习。EBT并非独立地对脑区建模，而是构建边时间序列表示，以捕捉功能连接的动态共波动模式，并将具有判别性的连接组织为线图，从而进行显式的连接-连接建模。我们开发了一种结构感知Transformer，以学习解剖学相关连接之间的局部依赖关系以及分布式功能网络之间的全局交互。此外，引入边级正交聚类读出模块，以导出被试级表示并识别与脑疾病相关的潜在连接模块。在多个神经影像数据集上的评估表明，EBT始终优于代表性的图神经网络、脑Transformer以及传统的基于连接的方法。可解释性分析进一步揭示了稳定的疾病相关功能连接和连接模块，其与已知的病理网络改变相一致。这些发现为基于rs-fMRI的脑疾病诊断建立了以边为中心的视角，并为发现可解释的连接生物标志物提供了一个有前景的框架。源代码已公开于：https://github.com/Zdy12/Edge-centric-Brain-Transformer。

## Abstract
Resting-state functional magnetic resonance imaging (rs-fMRI) enables the characterization of functional interactions among distributed brain regions and has shown promise for brain disorder diagnosis. However, existing deep learning methods predominantly rely on node-centric representations, where brain regions serve as the primary learning units, potentially overlooking discriminative alterations embedded in functional connections. Here, we propose an edge-centric brain transformer (EBT) framework that reformulates rs-fMRI analysis as functional connection representation learning. Instead of modeling brain regions independently, EBT constructs edge time-series representations to capture dynamic co-fluctuation patterns of functional connections and organizes discriminative connections into a line graph for explicit connection-to-connection modeling. A structure-aware transformer is developed to learn both local dependencies among anatomically related connections and global interactions across distributed functional networks. Furthermore, an edge-level orthogonal clustering readout module is introduced to derive subject-level representations and identify latent connectivity modules associated with brain disorders. Evaluations on multiple neuroimaging datasets demonstrate that EBT consistently outperforms representative graph neural networks, brain transformers, and conventional connectivity-based approaches. Interpretability analyses further reveal stable disease-associated functional connections and connectivity modules that align with known pathological network alterations. These findings establish an edge-centric perspective for rs-fMRI-based brain disorder diagnosis and provide a promising framework for discovering interpretable connectivity biomarkers. The source code is publicly available at: https://github.com/Zdy12/Edge-centric-Brain-Transformer.

## 2. 方法论

### 2.1 核心思想
- 以**功能连接（边）**而非脑区作为基本学习单元/token；通过线图（line graph）将连接-连接交互显式建模；用结构感知Transformer同时捕获局部解剖依赖与全局功能交互；用边级正交聚类读出生成被试级表示并发现潜在连接模块。
- 总体映射：X → E → E\* → G_L → Z → g_E → ŷ（原始fMRI信号 → 全部功能连接 → 判别性连接 → 线图 → 边表示 → 被试级表示 → 疾病概率）。

### 2.2 关键技术细节
- **边级时间共波动表示**：对每个被试的 ROI 信号矩阵 X∈R^{N×T} 做时间维标准化，边时间序列定义为两区域标准化信号逐元素乘积 e_ij(t)=x̃_i(t)·x̃_j(t)；边表示 E_ij∈R^T 保留动态共波动。静态FC可由其时间均值恢复（FC_ij = (1/T)Σ_t e_ij(t)），即边时间序列是静态FC的时间展开。
- **训练折内判别性边选择**：候选无向连接总数 M=N(N−1)/2。为避免信息泄漏，边选择**仅在每个训练折内独立进行**：对每条边做多组假设检验（一对ANOVA或Kruskal–Wallis）得到 p 值，按显著性排序，保留前 ρ 比例的边（ρ∈{0.2,0.3}）；选中的边索引固定用于验证/测试被试。
- **线图构造**：将所选功能网络 G=(V,E\*) 转换为线图 G_L=(V_L,E_L)，线图节点对应一条功能连接，两个边节点相连当且仅当其对应连接共享至少一个脑区（邻接矩阵 A_L）。
- **结构感知边Transformer**：
  - 初始边token：h⁰_ij = φ(E_ij ‖ p_i ‖ p_j)，即边时间序列 + 两端脑区可学习位置嵌入的拼接投影。
  - 每层先做**掩码边注意力（局部）**：注意力掩码按线图邻接构造（相连为0，不相连为−∞），限制信息仅在结构相关边token间传播，提供拓扑感知归纳偏置。
  - 再做**全局自注意力**：在掩码注意力输出上重新投影Q/K/V，捕获长程依赖。
  - 堆叠 L 层后加入**外层残差** Z = H^L + H⁰，保留边特有信息。
- **边级正交聚类读出（Edge-OCRead）**：设 P 个可学习聚类中心 W_c，用softmax内积计算软分配矩阵 C = softmax(ZW_c)∈R^{M\*×P}；按分配聚合 S = CᵀZ∈R^{P×d}；中心以正交基初始化，并引入**归一化正交正则项** L_orth = ‖CᵀC/‖CᵀC‖_F+ε − I_P/√P‖_F，惩罚模块间重叠与退化分配；最终展平得被试级表示 g_E = Flatten(S)∈R^{Pd}。
- **分类与优化**：MLP + softmax 输出类别概率，交叉熵损失 L_cls；总目标 L = L_cls + λL_orth。ADNI 为3分类，ADHD/ABIDE I/II 为2分类。

## 6. 主要结论与发现

- **性能**：EBT 在四个队列的组内评估中全部取得最优：
  - ADNI：ACC 76.4±4.9%，AUC 90.5±2.3%（较最强基线 BNT 提升 1.5%/1.2%/1.4%/1.6%/0.4%）；
  - ADHD：ACC 78.3±2.4%，F1 77.7±2.6%，AUC 84.5%（较 BNT 提升约 2.1%）；
  - ABIDE I：ACC 65.5±2.4%（较 CAGT 提升 1.2%），AUC 69.7%；
  - ABIDE II：ACC 73.1±4.5%，AUC 79.3%（较 BNT 提升 0.8%）。
- **外部验证**：ABIDE I→II 上 EBT 取得最高 ACC 61.8%、精确率 64.7%、F1 69.0%、AUC 68.0%；部分基线（SVM、Graph Transformer、SAN）呈现"高召回近乎随机准确率"的偏阳预测倾向，EBT 决策更均衡。
- **对比规律**：传统GNN与通用图Transformer并不稳定优于FC-based分类器，说明节点中心消息传递可能丢失连接级信息；脑特异性Transformer普遍更好；EBT 稳定超越节点中心脑Transformer，支持"疾病异常也编码在连接交互中"的假设。
- **消融结论**：移除任一组件均导致AUC下降；边级共波动表示的贡献最大；掩码（局部）与全局注意力提供互补信息；均值池化劣于 Edge-OCRead。
- **超参规律**：ρ 在 20%–30%、L=1–2、P=16、λ 在 10⁻³–10⁻² 时性能最稳定。
- **可解释性发现**：所选连接中经 BH-FDR 校正后仍有 21.7%（ADNI）、31.6%（ADHD）、30.1%（ABIDE I）、23.9%（ABIDE II）显著；显著连接分布于各疾病已知相关网络（ADNI：丘脑、辅助运动区、楔前叶、舌回等；ADHD：尾状核、岛叶、扣带回、小脑等；ABIDE：内侧/眶额皮层、岛叶、楔前叶、丘脑、小脑等）。Edge-OCRead 的边-类分配矩阵在 AD/MCI/CN 间呈现组依赖差异，表明疾病改变体现在连接的高阶组织方式而非孤立连接上。

## 7. 优点

- **范式创新**：把学习单元从脑区转为功能连接，配合线图把"边-边"交互转为显式图结构，理论上比节点中心方法更契合"分布式连接异常"的病理假设。
- **时序信息保留**：用边时间序列（逐元素乘积）替代单一相关系数，保留瞬态共波动，且与静态FC在数学上兼容（时间均值即FC）。
- **结构感知注意力设计**：掩码局部注意力（拓扑归纳偏置）+ 全局自注意力 + 外层残差，兼顾局部解剖约束与长程功能依赖，消融验证二者互补。
- **可解释读出**：Edge-OCRead 用正交正则化的软聚类替代简单池化，既生成被试级表示又产出潜在连接模块，并给出组间分配差异的可视化解释。
- **防泄漏设计**：边选择严格限定在训练折内，方法学上严谨。
- **实验体系完整**：4个独立队列、四类基线（含最新脑Transformer）、外部跨队列验证、7项消融、4项超参敏感性、3组可解释性分析，并开源代码。
- **可解释性结论有神经科学对照**：注意力导出区域与已知病理网络（默认模式、突显、额顶、丘脑皮层、皮层-纹状体等）一致，且作者谨慎声明为模型导出判别模式而非临床生物标志物。
