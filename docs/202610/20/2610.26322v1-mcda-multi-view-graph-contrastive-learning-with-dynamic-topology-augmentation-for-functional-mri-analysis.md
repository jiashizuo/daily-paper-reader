## 摘要
静息态功能磁共振成像（rs-fMRI）是诊断脑部疾病和揭示病理机制的重要无创工具。然而，现有图对比学习（GCL）方法往往未能充分利用跨训练轮次的增强历史以及不同增强视图之间的关系。本文提出一种用于fMRI分析的拓扑引导多视图图对比学习框架，并结合动态图拓扑增强（MCDA）。与传统GCL使用固定噪声或边丢弃不同，MCDA采用动态增强更新（DAU）模块，以迭代方式细化增强后的拓扑。具体而言，我们引入自感知和跨样本增强策略，以同时捕捉个体特异性功能特征和受试者间异质性。随后，我们设计了一种拓扑引导的多视图图对比学习方案，不仅探索原始网络与其增强视图之间的相互关系，还探索不同增强视图之间的相互关系，以最大限度地保留结构信息。我们刻画了得分层面的优化方向，并为对比目标建立了下界。该框架结合分类损失和对比损失用于脑部疾病诊断，并考察具有判别性的功能连接模式作为潜在生物标志物。在两个包含1,236名受试者的公开rs-fMRI数据集上的实验表明，MCDA优于最先进的方法。代码已公开于：\url{https://github.com/goodcodingagoodboy/MCDA}。

## Abstract
Resting-state fMRI (rs-fMRI) is a vital non-invasive tool for diagnosing brain disorders and uncovering pathological mechanisms. However, existing graph contrastive learning (GCL) methods often underexploit augmentation histories across training epochs and the relationships among different augmented views. In this paper, we introduce a topology-guided Multi-view graph Contrastive learning framework with Dynamic graph topology Augmentation (MCDA) for fMRI analysis. Unlike traditional GCL that uses fixed noise or edge-dropping, MCDA employs a Dynamic Augmentation Update (DAU) module that iteratively refines the augmented topology. Specifically, we incorporate self-aware and cross-sample augmentation strategies to simultaneously capture individual-specific functional signatures and inter-subject heterogeneity. We then design a topology-guided multi-view graph contrastive learning scheme that explores interrelationships not only between the original network and its augmented views, but also across different augmented views to maximize structural information preservation. We characterize the score-level optimization directions and establish a lower bound for the contrastive objective. The framework combines classification and contrastive losses for brain disorder diagnosis and examines discriminative functional connectivity patterns as potential biomarkers. Experiments on two public rs-fMRI datasets comprising 1,236 subjects demonstrate that MCDA outperforms the state-of-the-art methods. The code has been made publicly available at: \url{https://github.com/goodcodingagoodboy/MCDA}.

- **背景**：静息态功能磁共振成像（rs-fMRI）是无创诊断脑疾病（如重度抑郁 MDD、自闭症 ASD）的重要手段。将大脑建模为图结构（ROI 为节点、功能连接为边）后，图神经网络和图对比学习（GCL）被广泛用于提取判别性表征。
- **现有方法的三大不足**：
  1. **忽略跨训练轮次的增强历史**：现有 GCL 大多只依赖当前轮次生成的增强视图，采用固定噪声、边丢弃或窗口切片等静态增强策略，未利用增强视图在训练过程中的演化信息。
  2. **未建模多视图之间的关系**：多数方法只约束“原图—增强图”的一致性，忽略不同增强视图之间的相互关系，难以兼顾一致性与多样性。
  3. **简单增强可能破坏结构信息**：如窗口切片类增强难以捕捉复杂功能模式，影响判别力与鲁棒性。
- **整体含义**：论文提出 **MCDA**（拓扑引导的多视图图对比学习 + 动态图拓扑增强），旨在通过历史引导的增强细化与多视图对比约束，提升脑疾病诊断的准确性与鲁棒性，并为功能连接生物标志物提供可解释线索。

## 2. 方法论

### 2.1 核心思想
以“动态增强 + 多视图对比”为主线：每个受试者生成两条互补的增强分支（**自感知增强 SA** 与 **跨样本增强 CA**），通过**动态增强更新（DAU）** 模块利用跨 epoch 历史迭代细化增强拓扑，再以**拓扑引导的多视图对比损失**分别施加一致性约束（SA 与原图）与多样性约束（CA 与原图、SA 与 CA），最终融合三视图预测做分类。

### 2.2 关键技术细节

- **脑网络构建**：BOLD 信号构成无向时空图 $G \in \mathbb{R}^{T\times N}$，由 ROI 间 Pearson 相关得到功能连接矩阵 $A\in\mathbb{R}^{N\times N}$。实验取 $T=200$、$N=116$（AAL 图谱）。

- **自感知增强（SA）**：
  - 先用 **Z-pool** 融合最大池化与平均池化：$G_z = \text{MaxPool}(G)\oplus\text{AvgPool}(G)$；
  - 再经 **ST-GC 编码器**（空间图卷积 + 时间卷积）得到特征，按元素乘 sigmoid 调制：$G_{SA}=G_z\odot\sigma(\Phi(G_z,A))$。

- **跨样本增强（CA）**：
  - 将 $G$ 分别置换为 $\mathbb{R}^{N\times T\times B}$ 与 $\mathbb{R}^{T\times B\times N}$，对后两维做 Z-pool，实现批次-时间/批次-空间交互，引入其他受试者的时空扰动；
  - 经 ST-GC 编码与 sigmoid 调制后逆置换回原顺序，两分支等权平均得 $G_{CA}$。

- **动态增强更新（DAU）模块**（论文核心创新）：
  - 可学习投影 $P^r:\mathbb{R}^{TN}\to\mathbb{R}^{d}$（$d=128$）将增强图映射为描述子 $z_e^r$；
  - 对每个受试者、每个分支维护长度 $K$ 的滑动窗口 $Z_e^r=[z_{\ell_e}^r,\dots,z_e^r]$，$\ell_e=\max(1,e-K+1)$；
  - **共享参数 BiGRU**（3 层，每方向隐维 64，层间 dropout 0.3）分别处理两分支序列，取前向末端状态与后向起点状态拼接，经分支特定解码器 $D^r$ 输出 sigmoid 门控：
    $$a_e^r=\text{reshape}_{T\times N}\{\sigma(D^r[\vec h_e^r;\overleftarrow h_{\ell_e}^r])\}$$
  - 门控融合历史参考 $M_e^r$（上一 epoch 的预细化图）与当前图：
    $$G_e^r \leftarrow G_e^r + a_e^r\odot(M_e^r-G_e^r)$$
  - 首 epoch 为恒等更新；更新值始终介于当前图与历史参考之间，无需额外缩放超参。
  - **测试阶段**：保留最后 $K$ 个 epoch 的 checkpoint，对每个未见受试者依次生成描述子序列，由最终 checkpoint 的 DAU 与分类器完成预测，全程冻结参数、不访问测试标签。

- **拓扑引导多视图对比学习**：
  - 以余弦相似度 $\text{sim}(\cdot,\cdot)$ 度量三视图关系；
  - 三个约束项：
    - $L_{SA}$：**一致性**（负对数，鼓励 SA 与原图匹配）；
    - $L_{CA}$：**多样性**（正对数，抑制 CA 与原图过度匹配）；
    - $L_{SA,CA}$：**视图间多样性**（正对数，抑制两增强视图重叠）；
  - 组合：$L_{TMC}=\alpha L_{SA}+(1-\alpha)L_{CA}+\beta L_{SA,CA}$；
  - **分类损失**：三视图经共享分类头（4 个 1×1 卷积）得到概率并平均，计算 BCE：$L_{class}=-\sum_i[y_i\log p_i+(1-y_i)\log(1-p_i)]$；
  - **总目标**：$L=L_{class}+\lambda L_{TMC}$。

- **理论分析**（附录）：
  - 对相似度分数求偏导，证明 $L_{SA}$ 对匹配相似度梯度为负、$L_{CA}$ 与 $L_{SA,CA}$ 为正，即得分层面分别“拉近/推远”；
  - 利用余弦相似度有界性给出对比目标下界：$L_{TMC}\ge -(1-\alpha+\beta)\log[1+(B-1)e^{2/\tau}]$；
  - 给出单位归一化下的几何解释（相似度与平方距离的关系）。

- **实现配置**：$|R|=16$（4×4 邻域）、ST-GC 3 层、$K=5$、$d=128$、$m=64$、$\tau=0.5$、$\alpha=0.3$、$\beta=1.0$、$\lambda=0.5$；200 epoch，初始学习率 0.001，每 50 epoch 减半。

## 6. 主要结论与发现

- **分类性能全面领先**：
  - MDD（REST-MDD）：ACC 分别达 **70.3%（Site 20）、71.8%（Site 21）、73.4%（Site 25）**；较 BrainGNN 提升 6.7/6.6 个百分点，较 UCGL 在 Site 25 提升 10.1 个百分点（AUC +15.8）。
  - ASD（ABIDE）：ACC 达 **81.1%（NYU）、75.0%（UM）、80.2%（USM）**；NYU 上较 TSDA 提升 12.8 个百分点（AUC +13.6）。
- **消融结论**：去掉 DAU（MCDA-I）、去掉 $L_{SA,CA}$（MCDA-II）、去掉对比损失（MCDA-III）后性能均下降，验证三者各自有效；完整模型在全部 6 个站点上 ACC/AUC 最优。
- **结构对比**：双向 BiGRU + 门控融合的 DAU 优于单向 GRU 与 LSTM，说明双向历史建模与语义一致性约束的作用。
- **编码器对比**：ST-GC 明显优于 Ra-GConv、2D-CNN 与无编码器版本

，说明时空联合建模与拓扑感知卷积对增强图生成的重要性；2D-CNN 虽能提取局部时空模式，但难以保留 ROI 间的拓扑关系，Ra-GConv 的空间表达能力强于普通卷积但仍弱于 ST-GC，无编码器版本则退化为近似固定调制，进一步佐证“增强器本身需要具备结构建模能力”。

- **超参敏感性**：
  - $\alpha$ 控制一致性项与多样性项的相对权重，过大或过小均会使性能下降，约在 $0.3$ 附近取得较优折中，表明“保持增强视图与原图语义一致”与“避免增强视图同质化”需要平衡；
  - $\beta$ 增大时视图间多样性约束增强，初期有助于提升判别性，但过大可能削弱增强视图与原图之间的语义联系，导致分类性能回落；
  - $\lambda$ 在 $0.5$ 附近较稳定，说明对比正则以适度强度注入即可，过强会干扰分类目标；
  - 历史窗口 $K=5$ 表现最佳：$K=1$ 等价于无历史信息，$K$ 过大则可能引入较早轮次的陈旧增强状态，使门控更新滞后；
  - 批大小在 $40$–$45$ 附近较稳，过小会使跨样本增强的交互扰动不足，过大则可能稀释个体差异。

- **可解释性发现**：
  - 基于 CKA 的 ROI 对关联分析给出了对分类决策较重要的功能连接对，并经过 Freedman–Lane 置换检验与 BY 多重校正，降低了多重比较假阳性；
  - 显著 ROI 对主要涉及默认模式网络、前额叶—边缘系统及社会认知相关脑区等，与 MDD/ASD 的既有神经影像发现具有一定一致性；
  - 需注意，这类分析提供的是**关联性证据**而非因果机制，脑区重要性排序应结合更大样本与独立队列进一步验证；
  - BrainNet Viewer 可视化增强了结果的可读性，但当前解释仍停留在“哪些连接重要”，尚未回答“增强过程如何改变这些连接”的机制问题。

- **DAU 动态增强过程**：
  - 每 20 epoch 的可视化显示，增强图并非一次性随机扰动，而是随训练轮次逐步由当前图向历史参考平滑过渡；
  - 门控值在训练后期趋于稳定且呈结构化分布，说明模型学会了选择性地吸收历史增强信息，而非无差别融合；
  - 该现象与“历史引导细化”的设计动机一致，也为 DAU 优于单向 GRU/LSTM 提供了直观解释。

## 7. 讨论、局限与可推广性

- **方法优势**：
  - 将“增强历史”纳入图对比学习，突破了多数 GCL 仅使用当前轮增强视图的静态范式；
  - 通过 SA/CA 双分支与三项对比约束，同时处理一致性与多样性，避免增强视图塌缩；
  - DAU 的门控融合形式简单、无额外缩放超参，且测试阶段仅使用已训练 checkpoint，不访问测试标签，协议相对规范；
  - 在 MDD 与 ASD 两类疾病、六个独立站点上均取得较优结果，消融与结构对比较完整。

- **局限**：
  - 实验采用站点内五折交叉验证，未开展跨站点/跨数据集迁移或域适应实验，模型对站点异质性的泛化能力仍待检验；
  - 每折测试样本有限，五折配对检验的统计功效受限，部分提升的置信区间可能较宽；
  - 部分基线为作者复现，超参搜索预算与实现细节若不一致，可能影响比较公平性；
  - 超参主要在 Site 20 上选定后固定，虽避免测试集调参，但最优配置对其他站点的适应性未知；
  - 算力报告不完整，缺少训练时长、显存与推理成本，不利于实际部署评估；
  - 可解释性分析为事后关联分析，尚未与 DAU 的门控演化建立直接对应，临床可解释性仍有提升空间。

- **可推广性**：
  - “历史感知增强 + 多视图对比”不依赖特定疾病标签，可迁移到其他 rs-fMRI 分类任务及其他图级分类场景；
  - 若结合跨站点对齐、联邦学习或多模态融合，可能进一步缓解站点异质性与单模态信息不足的问题；
  - DAU 的滑动窗口与门控机制也可与其它增强策略组合，作为通用插件使用。

## 8. 总体评价与启发

- **总体评价**：论文问题定位清晰，核心创新点（DAU）与多视图对比约束相互支撑，实验覆盖两类疾病、多个站点、多类基线，消融较系统地验证了各模块贡献；主要不足在于泛化实验与算力/复现细节不够充分，解释性仍偏事后关联。
- **启发**：
  1. 对比学习中的“增强”不必是静态算子，可将增强过程本身建模为随训练演化的动态状态；
  2. 多视图学习需要同时显式约束一致性与多样性，否则容易退化为单一视图的重复；
  3. 脑网络分析中，分类性能与生物标志物解释应并行推进，事后关联分析需配合严格多重校正与独立验证；
  4. 对图对比学习而言，历史信息可作为“隐式课程”，帮助模型从早期扰动过渡到后期稳定表征。
