## 摘要
脑电图（EEG）功能连接通过多种度量进行量化，这些度量涵盖统计依赖性、频谱耦合、相位同步、信息传递、有向相互作用、跨频率耦合和网络拓扑。一个重要问题是，从一个连接度量可以推断出关于另一个连接度量的哪些信息。本文构建了一个数学框架，将连接度量视为从明确定义的可容许状态空间到可观测值的映射。对于源度量和目标度量，将与观测到的源值相容的目标值集合定义为交叉连接可达集。该表述区分了精确确定、利用附加信息的条件确定、有界推断、近似辨识以及不可辨识性。该框架被扩展到多通道连接矩阵、图度量和动态连接。它还纳入了滤波、参考、容积传导、源泄漏、逆建模、分段时长和估计器假设对可容许推断的影响。解析示例考察了协方差与相关性之间的关系、联合高斯性下互信息与相关性之间的关系、受限信号条件下相干性与锁相值之间的关系，以及在没有附加假设时相位滞后指数和加权相位滞后指数的普遍不可辨识性。通过明确假设和可达值，该框架为判断连接性结果就其他度量能够确立什么、不能确立什么提供了系统依据。

## Abstract
Electroencephalographic (EEG) functional connectivity is quantified using diverse measures of statistical dependence, spectral coupling, phase synchronization, information transfer, directed interactions, cross-frequency coupling, and network topology. An important question is what can be inferred about one connectivity measure from another. This paper develops a mathematical framework that treats connectivity measures as mappings from an explicitly defined admissible state space to observable values. For a source measure and a target measure, the set of target values compatible with an observed source value is defined as a cross-connectivity attainable set. This formulation distinguishes exact determination, conditional determination using additional information, bounded inference, approximate identification, and non-identifiability. The framework is extended to multichannel connectivity matrices, graph measures, and dynamic connectivity. It also incorporates the influence of filtering, referencing, volume conduction, source leakage, inverse modeling, epoch duration, and estimator assumptions on admissible inferences. Analytical examples examine relationships between covariance and correlation, mutual information and correlation under joint Gaussianity, coherence and phase-locking value under restrictive signal conditions, and the general non-identifiability of the phase-lag index and weighted phase-lag index without additional assumptions. By making assumptions and attainable values explicit, the framework provides a systematic basis for determining what connectivity results can and cannot establish about other measures.
