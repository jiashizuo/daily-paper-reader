## 摘要
功能磁共振成像（fMRI）通常通过功能连接（FC）来刻画大规模脑组织。然而，观测到的 FC 矩阵并非固定的脑图，而是由用于计算它的有限 BOLD 帧所决定的统计估计。传统的基于 FC 的方法通常用单个皮尔逊相关矩阵表示每次扫描，未能利用区域交互中具有帧分辨率的变化。为解决这一局限，我们提出 CoFlu-Brain，它将逐帧共波动观测组织为多个保留视图和丢弃视图，每个视图均汇总为一个 FC 矩阵。该模型学习在保留视图间可复现的连接结构，并预测相应丢弃视图的表示，同时采用来自 LeJEPA 的 SIGReg 以防止表示坍塌。我们在来自八个数据集组的 13,444 名被试上预训练 CoFlu-Brain，并通过冻结编码器的线性探测，在七个数据集上的七项分类任务和两项年龄预测任务中评估其表示。CoFlu-Brain 在人口统计学、发育和临床预测任务中展现出强迁移能力，在大多数任务上优于所评估的已发布模型。随机帧划分提升了整体迁移性能，而完整目标取得了最强的总体性能。代码已公开。

## Abstract
Functional magnetic resonance imaging (fMRI) commonly characterizes large-scale brain organization through functional connectivity (FC). However, an observed FC matrix is not a fixed brain graph but a statistical estimate determined by the finite BOLD frames used to compute it. Conventional FC-based approaches typically represent each scan with a single Pearson-correlation matrix, leaving frame-resolved variations in regional interactions unexploited. To address this limitation, we introduce CoFlu-Brain, which organizes framewise cofluctuation observations into multiple retained and dropped views, each summarized as an FC matrix. The model learns connectivity structure reproducible across retained views and predicts the representations of the corresponding dropped views, while adopting SIGReg from LeJEPA to prevent representation collapse. We pretrained CoFlu-Brain on 13,444 subjects from eight dataset groups and evaluated its representations via frozen-encoder linear probing on seven classification and two age-prediction tasks across seven datasets. CoFlu-Brain showed strong transfer across demographic, developmental, and clinical prediction tasks, outperforming the evaluated released models on most tasks. Random frame partitioning improved aggregate transfer, while the complete objective achieved the strongest overall performance. Code is available.

# CoFlu-Brain 论文总结

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **背景**：fMRI 研究通常通过功能连接（FC）刻画大规模脑功能组织。传统做法是把一次扫描的所有 BOLD 帧聚合成一个单一的 Pearson 相关矩阵，作为脑网络的输入。
- **核心问题**：作者指出，观测到的 FC 矩阵**并非固定的脑图**，而是由有限 BOLD 帧计算得到的**统计估计**——其数值会随纳入估计的帧集合而变化。不同帧组合会产生数值不同但统计上相关的多个 FC 估计。
- **现有方法的局限**：
  - 主流 FC 表征模型（BrainGFM、BrainMASS、LCM 等）通常只对单张 Pearson-FC 矩阵或图进行编码/重构/对齐，**丢弃了帧分辨率的区域交互变化信息**。
  - 时间序列类方法虽保留时序动态，但区域间连接只是隐式属性；体素级模型则依赖高维输入且不以连接为核心建模单元。
  - 动态 FC 方法关注连接状态的演化，而非**替代估计之间的可复现性**。
- **核心假设**：来自同一扫描段、由不同帧组合构成的共波动观测，可提供自监督信号——同一被试的共波动结构在保留视图间应**可复现地推断**，且保留视图应足以**预测对应非重叠丢弃视图的表征**。
- **整体含义**：将 FC 建模的学习单元从“单一扫描级估计”扩展为“多个相关的有限样本估计”，用有限样本结构定义哪些视图应当一致、哪些互补证据应被预测。

## 2. 论文提出的方法论

### 2.1 核心思想

- **CoFlu-Brain**：将逐帧共波动观测组织为多个**保留视图（retained）**和**丢弃视图（dropped）**，各自汇总为 FC 矩阵；学习跨保留视图可复现的连接结构，并预测对应丢弃视图的潜在表征；同时用 SIGReg 防止表征坍塌。

### 2.2 关键技术细节

- **逐帧共波动矩阵**：对选定帧集 A，先在各区域内独立标准化得到 $z^A_t$，定义逐帧共波动矩阵 $E^A_t = z^A_t (z^A_t)^\top$。
- **FC 视图构造**：将共波动观测汇总为 $R^A_{ij} = \frac{1}{|A|-1}\sum_{t\in A} E^A_{t,ij}$（$i \neq j$），仅对非对角元素做 Fisher 变换，对角置零。
- **保留/丢弃划分**：对每个分区 $v$，按保留比例 $r_v$ 无放回抽样得到保留帧集 $S_v$，其余为丢弃集 $D_v$，满足 $S_v \cap D_v = \varnothing$；不同分区之间可复用帧。由此得到 $C^{S_v} = \text{FisherZ}(R^{S_v})$、$C^{D_v} = \text{FisherZ}(R^{D_v})$。

### 2.3 模型架构

- **行级编码器** $\phi: \mathbb{R}^N \to \mathbb{R}^d$ 将每个 ROI 的带符号连接谱映射为 ROI token。
- **ViT 编码器** $F_\theta$ 对 ROI token 做上下文交互，再经均值池化得到扫描级表征 $f_\theta(C)$。
- **投影器** $g$ 和**预测器** $h$：$p_{vb} = g(f_\theta(C^{S_{vb}}))$，$q_{vb} = g(f_\theta(C^{D_{vb}}))$，$\hat{q}_{vb} = h(p_{vb})$。
- 保留与丢弃分支**共享全部编码器和投影器参数**，无需 stop-gradient 或动量编码器。预训练后丢弃投影器和预测器，仅保留编码器用于下游冻结探测。

### 2.4 损失函数

- **保留视图一致性**：$\mathcal{L}_{con} = \frac{1}{VBd_p}\sum_{v,b}\|p_{vb} - \bar{p}_b\|_2^2$，其中 $\bar{p}_b$ 为保留视图投影均值。
- **丢弃视图预测**：$\mathcal{L}_{pred} = \frac{1}{VB}\sum_{v,b}[1 - \cos(h(p_{vb}), q_{vb})]$。
- **非坍塌正则**：采用 LeJEPA 的 **SIGReg** 对保留与丢弃投影分布做正则。
- **完整目标**：$\mathcal{L} = \mathcal{L}_{pred} + \lambda_{con}\gamma(e)\mathcal{L}_{con} + \lambda_{reg}\mathcal{L}_{SIGReg}$，其中 $\gamma(e)$ 先保持全权重、随后线性衰减（主配置 $E_w=1, E_d=24$，第 25 轮归零）。

## 7. 优点

- **视角新颖**：将 FC 重新理解为受有限帧支撑的统计估计，用其有限样本结构定义自监督目标，区别于传统单矩阵建模范式。
- **方法优雅**：保留-丢弃视图对的设计同时包含“一致性”和“互补预测”两类信号，且无需 stop-gradient/动量编码器，共享参数、双向梯度。
- **正则设计有据**：引入 LeJEPA 的 SIGReg，并以诊断指标（视图余弦、协方差惩罚）实证其防坍塌作用。
- **规模与覆盖面**：预训练达 13,444 名被试、8 个数据集组，下游覆盖人口统计、发育、临床多类任务，且严格区分队列内/队列外。

- **可解释性分析**：Yeo-17 网络受限探测给出了与脑发育和 ADHD 文献一致的发现，增强结论的生物学可信度。
- **可复现性**：提供代码、配置文件、验证脚本与检查点，并声明 AI 使用情况与伦理合规。

## 8. 不足与局限

- **信息保留有限**：当前视图将逐帧共波动乘积聚合为子集级 FC 矩阵，**不保留单个共波动事件的时间、顺序或幅度**，无法建模瞬态动态。
- **验证维度受限**：仅做预测性评估，**缺乏生物学验证与因果分析**；未与体素级特征整合。
- **性能并非全面领先**：在 ABCD-Sex、ADNI-AD 等任务上并未超越所有基线（如 BrainMASS 在 ABCD-Sex 上更高），部分任务绝对性能仍接近随机水平（如 ABIDE-ASD ~0.56、ADHD200 诊断 ~0.59）。
- **算力披露不完整**：未说明 GPU 型号/数量及完整预训练总开销，仅报告消融相对时长。
- **对比公平性存疑**：基线单检查点 vs. CoFlu-Brain 三种子平均，可能高估优势；部分消融仅用单种子，稳健性证据有限。
- **数据处理不一致**：各队列沿用来源预处理流程（HCP minimal、ABCD-HCP、fMRIPrep 等），低层操作未统一重估，可能引入跨队列异质性。
- **超参未充分搜索**：分支数、保留比例、一致性权重等仅比较有限取值，最优配置未必达到全局最优。
- **应用限制**：依赖 Schaefer-400 图谱与固定 200 帧输入，短于 200 帧的序列被直接排除，可能影响短扫描或临床数据的适用性。
