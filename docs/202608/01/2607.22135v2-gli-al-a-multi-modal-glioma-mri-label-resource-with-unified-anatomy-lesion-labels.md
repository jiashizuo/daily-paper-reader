## 摘要
现有的BraTS-GLI数据集为成人胶质瘤MRI分割提供了广泛使用的基准，但其任务定义侧重于肿瘤亚区，并未系统性地表示共存的白质高信号（WMH）。在联合分割设置中，此类未标记的异常通过将病理区域视为正常组织而引入特定于任务的标签噪声。为解决这一局限性，我们引入了BraTS-GLI Anatomy-Lesion，这是一个从BraTS 2023-GLI训练队列构建的受控访问、仅标签的衍生资源。该资源提供了1,251套与原始四模态MRI病例对齐的统一八类解剖-病灶标签集，包括116例需要修复影像输入的图像修复标签。该队列组织为394例的纯净子集和857例的扩展子集，病例级别的元数据涵盖标签来源、图像修复要求、质量控制状态、访问条件、校验和以及发布边界。与原始BraTS-GLI标注相比，该资源通过将健康脑组织和先前未标记的共存异常纳入统一标签空间，大幅扩展了前景监督。使用MedNeXt和T1/FLAIR输入的验证研究表明，感知WMH的监督在域内GLI和外部WMH数据集上均保持健康组织分割性能，同时相对于噪声控制训练提高了对共存病变的敏感性。该资源旨在用于科学研究，支持联合解剖-病灶监督、标签噪声分析和可重复评估。数据可在https://www.synapse.org/Synapse:syn75210889/wiki/获取，代码可在https://github.com/xyx200/brats-gli-anatomy-lesion-code获取。数据资源DOI为https://doi.org/10.7303/SYN75210889。

## Abstract
Existing BraTS-GLI datasets provide a widely used benchmark for adult glioma MRI segmentation, but their task definition focuses on tumor subregions and does not systematically represent coexisting white matter hyperintensities (WMH). In joint segmentation settings, such unlabeled abnormalities introduce task-specific label noise by treating pathological regions as normal tissue. To address this limitation, we introduce BraTS-GLI Anatomy-Lesion, a controlled-access, labels-only derived resource built from the BraTS 2023-GLI training cohort. The resource provides 1,251 unified eight-class anatomy-lesion label sets aligned with the original four-modal MRI cases, including image-repair labels for 116 cases requiring repaired imaging inputs. The cohort is organized into a 394-case purified subset and an 857-case extended subset, with case-level metadata covering label source, image-repair requirements, quality-control status, access conditions, checksums, and release boundaries. Compared with the original BraTS-GLI annotations, the resource substantially expands foreground supervision by incorporating healthy brain tissues and previously unlabeled coexisting abnormalities within a unified label space. A validation study using MedNeXt and T1/FLAIR inputs suggests that WMH-aware supervision preserves healthy-tissue segmentation performance across both in-domain GLI and external WMH datasets, while improving sensitivity to coexisting lesions relative to noisy-control training. The resource is intended for scientific research and supports joint anatomy-lesion supervision, label-noise analysis, and reproducible evaluation. Data are available at https://www.synapse.org/Synapse:syn75210889/wiki/, and code is available at https://github.com/xyx200/brats-gli-anatomy-lesion-code. The data resource DOI is https://doi.org/10.7303/SYN75210889.

## 论文核心总结

### 1. 论文的核心问题与整体含义

**研究动机与背景：**
- 现有 BraTS-GLI 数据集是成人胶质瘤 MRI 分割的权威基准，但仅标注肿瘤亚区（NCR、ED、ET），忽视了脑内常见的共存异常——白质高信号（WMH）。
- 已有研究表明（Rudie et al.，2019），BraTS 2018 训练集中 68.8% 的病例含有至少 100mm³ 的 WMH，说明未标注 WMH 并非偶发情况。
- 在联合分割场景下，未标注的 WMH 会被隐式地当作正常组织参与训练，导致模型将病理区域错误分类为健康解剖结构，引入任务级标签噪声。
- 现有资源存在结构性缺口：解剖标注工具（如 FreeSurfer/SynthSeg）可生成健康组织标签但不含病灶；病灶数据集（如 BraTS、SOOP）标注单一类型病变但不含健康组织与共病信息，且均缺乏可审计的溯源记录。

**资源目标：**
- 构建 GLI-AL 资源，为 BraTS 2023-GLI 全部 1251 例四模态 MRI 提供统一的八类"解剖-病灶"标签，将健康脑组织、肿瘤病灶与共存异常纳入同一标签空间，并附带完整的病例级元数据（来源、QC 状态、校验和、发布边界等），支持联合分割训练、标签噪声分析和可复现评估。

### 2. 论文提出的方法论

**核心思想：**
将原本彼此分离的肿瘤亚区、共存 WMH 信息和健康脑组织结构整合到统一的八类标签空间中，同时保留案例分层和质量状态，使下游研究可在同一监督目标下同时建模健康组织和病灶。

**统一标签定义（整数编码）：**
- 0：背景
- 1：皮层灰质（GM）
- 2：基底节（BG）
- 3：白质（WM）
- 4：病灶（Lesion，涵盖肿瘤与共病）
- 5：脑室（Ven）
- 6：小脑（Cer）
- 7：脑干（BS）

**三步构建流程：**

1. **纯净子集构建（Purified subset）**

   - 对 233 例专家标注 WMH 阳性病例，使用 NiftySeg 对 WMH 区域进行原位填充修复（用周围正常组织信号替代），得到 116 例修复后病例。

### 3. 实验设计

**数据集与基准：**
- **域内验证（In-domain）：** BraTS 2023-GLI 训练集中留出 251 例作为测试集；模型在纯净子集上训练。
- **外部验证（Out-of-domain）：** MICCAI 2017 WMH 挑战赛数据集（170 张 T1/FLAIR 图像与病灶掩膜）。
  - 用 HD-BET 做颅骨剥离，ANTs 刚性配准到 SRI24 空间，将病灶标签同步变换；
  - 健康组织标签由 WMH-SynthSeg 生成并映射为与 GLI 相同的七类前景；外部数据不包含在 GLI 资源发布范围内。

**对比方法：**
- **Baseline：** 仅使用 394 例纯净子集训练。
- **Joint-Baseline：** 使用 394 例纯净子集 + 606 例随机选取的扩展子集病例（共 1000 例）训练，后者不附加共病标签，模拟含噪声训练。

**模型设置：**
- 两个实验均使用 MedNeXt-M：3×3×3 卷积核、五折交叉验证、AdamW、初始学习率 1×10⁻³、权重衰减 3×10⁻⁵、1000 epochs、batch size 2，输入为 T1 和 FLAIR。

**评估指标：**
- Dice 相似系数（DSC）：双空掩膜记为 1.0；HD95（95 百分位表面距离）：双空为 0.0，单侧空、全图填充或计算失败时赋最大惩罚值 374.0。指标先在病例内计算，再取病例级均值（标准差）。

- 域外数据集仅验证了 WMH 一种共病，GM 类指标受标签生成协议差异影响（TumorSynth vs WMH-SynthSeg 的灰质边界定义不一致），对比存在一定混杂因素。

### 6. 论文的主要结论与发现

- **域内 GLI 验证：** Baseline 与 Joint-Baseline 在健康组织（GM、BG、WM、Ven、Cer、BS）的 DSC 和 HD95 上接近，说明较小规模的高质量数据足以维持稳定的健康组织分割能力；但 Joint-Baseline 的 Lesion HD95 更大、标准差更高，表明其更容易漏掉远离主病灶且体积较小的 WMH。
- **外部 WMH 零样本验证：** 两种模型的健康组织分割表现仍相似，但其 Lesion 指标差异显著——Baseline 的 DSC 明显更高、HD95 更低，而 Joint-Baseline 对 WMH 病灶基本无响应。
- **核心结论：** 纯净子集提供了 WMH 感知的清洗训练参考，使研究者能区分数据质量与数据规模对共病灵敏度的影响；GLI-AL 资源从数据源头解决了 WMH 标签噪声问题，同时保持可审计性。
- **资源量化贡献：** 相比原始 BraTS-GLI 掩膜，新增前景标签共 15.14 亿体素（占发布前景的 92.65%），其中健康组织占绝大部分；病灶特异性新增为 220 万体素（857 例，占最终 Lesion 类的 1.8%），代表原本会被当作正常组织的共病约束。

### 7. 优点

- **数据设计层面：**
  - 统一的八类标签空间将健康组织与病灶放在同一监督目标中，消除了任务间标签定义不兼容的问题；
  - 纯净/扩展子集分层设计使研究者可按标签质量选择训练数据，支持标签噪声灵敏度分析；
  - 116 例图像修复标签提供了完整的复现入口，用户可自行重建修复后的输入图像；
  - 案例级元数据记录（标签来源、QC 状态、SHA-256 校验和、访问条件、发布边界）具备高度可审计性；
  - 病灶硬约束 + 熵权融合策略兼顾了病灶确定的先验知识与健康组织的多模态一致性；
  - 使用 DeepWMH 和 LST-AI 的交集降低单一工具假阳性，设计稳健。
- **实验设计层面：**
  - 引入了外部 WMH 数据集进行零样本验证，增强资源泛化性说服力；
  - 对照设计（高质小规模 vs 含噪大规模）能清晰刻画标签噪声带来的影响。

### 8. 不足与局限

- **标注来源的偏差风险：**
  - 纯净子集并非全部经过新的手工标注，包含专家阴性与模型筛选样本，模型筛选可能产生系统性偏差；
  - 扩展子集的共病约束来自自动工具的融合（DeepWMH 与 LST-AI 的交集），存在工具偏差、漏检以及对小病灶不敏感的风险；
  - 健康组织标签来自自动化工具 TumorSynth 与概率融合策略，不等同于手工全脑解剖标注；
  - 仅系统性处理了 WMH 这一共病，微出血、腔隙性梗死等其他共存异常尚未标注。
- **方法局限：**
  - 健康组织标签的模态间一致性依赖 IQR 离群检测 + 人工审查，该流程的可扩展性有限；
  - 修复图像只覆盖 116 例，修复质量依赖 NiftySeg 的正常组织插值假设。
- **实验覆盖不足：**
  - 验证仅用了 T1 和 FLAIR 两种模态，无法证明 T1ce 和 T2 在 GLI-AL 标签下的价值；
  - 没有验证 GLI-AL 在联合分割任务之外的适用性（如仅肿瘤分割、放射组学等）；
  - 外部验证数据的灰质边界定义与训练数据不一致，导致域外 GM 指标不可直接比较。
- **应用限制：**
  - 受控访问模式（需先获得 BraTS 访问权再申请衍生资源）增加了使用门槛；
  - 仅用于科学研究，不适用于临床诊断或个体风险评估；
  - 保护标签的临床关联价值有限，未含影像组学特征或预后信息。
