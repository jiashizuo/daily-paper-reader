## 摘要
运动想象（MI）脑机接口（BCI）已成为建立人脑与外部设备之间灵活通信通路的一种有前景的方法，特别是对于受中风或神经退行性疾病影响的个体。由于EEG记录包含大量噪声，并且与潜在的大脑活动之间表现出复杂且弱信息相关的关系，因此对运动想象脑电图（MI-EEG）的可靠解码仍然具有挑战性。尽管深度学习提供了一种直接从EEG信号中学习表示的有效手段，但其在MI-EEG特征学习中的应用仍然相对有限。本研究介绍了一种混合深度学习架构，该架构将卷积神经网络（CNN）与双向长短期记忆（bi-LSTM）网络相结合。CNN用于直接从原始MI-EEG记录中学习高级空间和时间表示，而bi-LSTM则对提取特征之间的时间依赖性和关系进行建模。使用公开可用的数据集和通过EEG采集系统获取的私有数据集对所提出的方法进行了评估。实验结果表明，CNN&bi-LSTM架构在二类和三类运动想象分类中均提供了稳健的性能，并在所评估的方法中展示出有前景的受试者无关解码能力。

## Abstract
Motor imagery (MI) brain--computer interfaces (BCIs) have emerged as a promising approach for establishing flexible communication pathways between the human brain and external devices , particularly for individuals affected by stroke or neurodegenerative disorders. Reliable decoding of motor-imagery electroencephalography (MI-EEG) remains challenging because EEG recordings contain substantial noise and exhibit complex, weakly informative relationships with the underlying brain activity. Although deep learning provides an effective means of learning representations directly from EEG signals, its application to MI-EEG feature learning remains comparatively limited. This study introduces a hybrid deep-learning architecture that integrates a convolutional neural network (CNN) with a bidirectional long short-term memory (bi-LSTM) network. The CNN is used to learn high-level spatial and temporal representations directly from raw MI-EEG recordings, whereas the bi-LSTM models temporal dependencies and relationships among the extracted features. The proposed approach is evaluated using both a publicly available dataset and a privately acquired dataset obtained with an EEG acquisition system. The experimental results indicate that the CNN\&bi-LSTM architecture provides robust performance for both two- and three-class motor-imagery classification and demonstrates promising subject-independent decoding capability across the evaluated methods.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：脑机接口（BCI）为大脑与外部环境之间提供了直接通信通路，尤其对中风或神经退行性疾病患者具有重要意义。运动想象脑电图（MI-EEG）因无需实际肢体运动即可区分想象动作的大脑模式而成为BCI的重要范式。
- **核心问题**：MI-EEG信号具有低信噪比、与潜在脑活动之间的关联复杂且信息微弱，导致可靠解码极具挑战性。传统方法（如LDA、SVM、朴素贝叶斯）在处理非线性、高噪声、强相关的EEG数据时存在明显局限。
- **研究缺口**：虽然深度学习已被证明能直接从EEG信号中学习表征，但其在MI-EEG特征学习中的应用仍相对有限。现有基于单一CNN或RNN的管线仍需大量人工特征工程和参数调优。
- **核心思想**：构建一个**混合深度学习架构（CNN&bi-LSTM）**，利用CNN从原始MI-EEG记录中直接学习高级时空表征，再利用双向LSTM（bi-LSTM）建模特征间的时序依赖关系，从而避免人工特征提取并提升分类性能。

## 2. 论文提出的方法论

### 2.1 核心思想

- 将特征的**空间/局部时域提取**（CNN）与**全局时序动态建模**（bi-LSTM）结合，构建端到端的MI-EEG解码框架。
- CNN通过卷积和池化操作自然地执行局部滤波和能量特征提取，且滤波器直接从数据中学习，无需预设信号处理特征。
- 双向LSTM同时利用序列中“过去”和“未来”的信息，比标准LSTM（仅利用过去信息）能更全面地建模EEG中的时序依赖。

### 2.2 数据预处理流程

1. **参考电极重设**：以中央区Cz电极为参考，通过公式 `Cz(Vm) = (I − VCz)·Vm` 进行重参考，其中VCz为仅在Cz列含1的M×M矩阵。
2. **电极选择**：选取P3、P4、C3、C4、O1、O2、Pz、Fz和Cz等MI-EEG关键电极。
3. **噪声去除**：采用基于小波的去噪方法以获取更干净的EEG信号。
4. **信号滤波**：对8–23 Hz频带（覆盖μ节律和β节律成分）进行带通滤波，不过正文中也有提到8-30Hz滤波的不一致之处。

### 2.3 CNN模块

- **空间卷积层**：使用**8个空间滤波器**对原始EEG通道进行卷积变换，卷积核大小为 **[36 × 1]**，每个特征图输出尺寸为 **(1 × 60)**。
- 卷积操作公式：`O2_m = f(Σ_{j≤36} Xi,j × k2_m + b2_m)`。
- 卷积后信号被重塑为 (L, C, 1) 以便进行批归一化（BN）。
- **批归一化（BN）**：将每个特征维度归一化至均值0、标准差1，公式为 `BN(Xi) = (Xi − E[Xi]) / √Var[Xi]`，用于加速优化并提升泛化能力。

### 2.4 双向LSTM模块

- bi-LSTM包含**前向层和后向层**，分别从两个时间方向处理序列，将上下文信息进行整合。
- 每个LSTM单元包含**输入门、遗忘门、输出门和记忆细胞**，核心公式包括：

  - `ct = zt ⊙ ct−1 + it ⊙ σ(Wc xt + Uc ct−1 + bc)`
  - `zt = σ(Wf xt + Uf ht−1 + bf)`（遗忘门）
  - `it = σ(Wi xt + Ui ht−1 + bi)`（输入门）
  - `ot = σ(Wo xt + Uo ht−1 + bo)`（输出门）
  - `hft = ot ⊙ tanh(ct)`

- 前向和后向隐藏序列合并后经输出激活函数生成输出：`yt = υ(Why hft + Wky hbt + by)`。
- **权重初始化**：采用LASSO回归系数初始化权重矩阵W，其余参数随机初始化，使网络从最小二乘回归的解出发进行优化。
- **损失函数**：使用**均方误差（MSE）**（而非交叉相关），理由是滤波后的MI-EEG信号包含大量静息状态片段。
- **训练策略**：采用**监督预训练**以处理多任务学习问题，在较低隐藏层中保持共享表示。
