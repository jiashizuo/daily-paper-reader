## 摘要
瘤内异质性（ITH）反映了肿瘤生物学的空间变异，是肿瘤行为、预后和治疗反应的重要决定因素。放射组学和深度学习已在基于多参数MRI（mp-MRI）的肿瘤分类中展现出潜力，但放射组学依赖手工特征，而大多数深度学习方法使用全肿瘤表征或手动定义的子区域，限制了对肿瘤异质性的可扩展建模。我们提出了一种异质性感知深度学习分类（HA-DLC）框架，该框架显式建模影像衍生的肿瘤子区域，用于病变类型诊断和分子状态预测。HA-DLC包括：（1）异质性子区域生成（HSG）模块，通过无监督聚类生成初始伪标签子区域，随后进行跨患者子区域对齐（CPSA），利用软分配将聚类衍生的区域映射到共享标签空间；（2）双流特征提取（DSFE）模块，将局部异质性感知特征与全局肿瘤表征相整合。在初始聚类掩膜的基础上，CPSA、分割、特征提取和分类通过软目标分割和分类目标进行端到端联合优化。我们在LLD-MMRI2023肝脏病变数据集和RSNA-ASNR-MICCAI 2021放射基因组脑肿瘤数据集上评估了HA-DLC。HA-DLC持续优于最先进的放射组学和深度学习基线，证明了跨患者子区域对齐和双流异质性建模在基于mp-MRI的肿瘤分类中的价值。

## Abstract
Intra-tumoural heterogeneity (ITH) reflects spatial variation in tumour biology and is an important determinant of tumour behaviour, prognosis, and treatment response. Radiomics and deep learning have shown promise for tumour classification from multiparametric MRI (mp-MRI), but radiomics relies on handcrafted features, while most deep learning methods use whole-tumour representations or manually defined sub-regions, limiting scalable modelling of tumour heterogeneity. We propose a Heterogeneity-Aware Deep Learning Classification (HA-DLC) framework that explicitly models imaging-derived tumour sub-regions for lesion-type diagnosis and molecular-status prediction. HA-DLC consists of: (1) a Heterogeneous Sub-region Generation (HSG) module that produces initial pseudo-labelled sub-regions via unsupervised clustering, followed by Cross-Patient Sub-region Alignment (CPSA), which maps cluster-derived regions to a shared label space using soft assignments; and (2) a Dual-Stream Feature Extraction (DSFE) module that integrates local heterogeneity-aware features with global tumour representations. Given the initial clustering masks, CPSA, segmentation, feature extraction, and classification are jointly optimized end-to-end using soft-target segmentation and classification objectives. We evaluate HA-DLC on the LLD-MMRI2023 liver lesion dataset and the RSNA-ASNR-MICCAI 2021 Radiogenomic Brain Tumour dataset. HA-DLC consistently outperforms state-of-the-art radiomics and deep learning baselines, demonstrating the value of cross-patient sub-region alignment and dual-stream heterogeneity modelling for tumour classification from mp-MRI.

- 传统组织活检（细针穿刺、核心针活检等）只能取样肿瘤的有限区域，存在采样误差，难以全面反映异质性；手术切除又不总是可行或临床适用。
- 放射组学方法依赖手工设计的特征，难以充分刻画肿瘤的复杂内在特性。
- 现有深度学习方法大多使用全肿瘤区域或人工勾画的子区域作为输入，存在三方面挑战：
  1. 全肿瘤表示会模糊空间上不同的影像特征，低估ITH；
  2. 基于子区域的方法依赖专家人工勾画，主观性强、费时费力、难以扩展；
  3. 无监督聚类虽可自动生成子区域，但每例患者独立聚类得到的标签具有任意性，跨患者不可对应，限制了学习一致性异质性表征的能力。
- 因此，论文提出一种**异质性感知深度学习分类框架（HA-DLC）**，通过无监督生成影像衍生子区域、跨患者对齐、双流特征提取，实现无需人工子区域标注的、可扩展的异质性感知肿瘤分类。

## 2. 提出的方法论

### 2.1 核心思想
- 将肿瘤分类任务分解为两个层面同时学习：
  - **子区域层面**：通过分割任务学习影像衍生的、跨患者一致性的瘤内异质性模式；
  - **肿瘤层面**：通过分类任务利用局部异质性特征和全局肿瘤特征进行最终诊断或分子状态预测。
- 关键创新在于：**无监督聚类 + 可学习的软对齐**，将患者特有的聚类标签映射到共享的子区域类别空间，从而在不依赖人工标注的前提下获得跨患者可比较的异质性表示。

### 2.2 三个主要模块

**（1）异构子区域生成模块（HSG，Heterogeneous Sub-region Generation）**
- 对每个mp-MRI序列，在肿瘤ROI内独立执行无监督聚类，生成患者特定、序列特定的子区域伪标签。
- 实现两种聚类算法：
  - 基于强度的k-means聚类（k为聚类数）；
  - 可微分特征聚类（DFC，Differentiable Feature Clustering），通过连续性损失系数μ控制空间连续性。

**（2）跨患者子区域对齐模块（CPSA，Cross-Patient Sub-region Alignment）**
- 目标：将每个患者特有的K个聚类标签，可学习地映射到M个共享子区域类别的概率分布。
- 每个MRI序列对应一个对齐网络，输入包括：对应影像体素、原始聚类标签图、来自GFE流的共享多尺度全局特征。
- 网络结构：两个改进的DenseNet编码器分别编码影像和标签图，与GFE全局特征拼接后，经过K个FC头生成K×M的对数几率矩阵。
- 软分配概率定义为：
  - \(A_{b,n,j,k} = \frac{\exp(Z_{b,n,j,k})}{\sum_{k'=1}^M \exp(Z_{b,n,j,k'})}\)
  - 其中j为患者特定聚类索引，k为共享类别索引。
- 对肿瘤体素v，原始聚类标签为j，其软对齐目标为：
  - \(\tilde{S}_{b,n,k,v} = A_{b,n,j,k}\)
- 背景标签固定不变，不参与软分配。
- 软对齐保留了每个聚类的体素成员和空间边界，仅改变其跨患者对应关系。

**（3）双流特征提取模块（DSFE，Dual-Stream Feature Extraction）**
- **HFE流（Heterogeneity Feature Extraction）**：
  - 每个MRI序列对应一个3D残差U-Net分割网络；
  - 在软对齐伪标签监督下预测子区域分割，并提取编码器多尺度局部异质性特征；
  - 编码器5个残差块，每个残差块的输出经1×1×1卷积、BN、ReLU、全局平均池化后拼接，形成局部异质性表征。
- **GFE流（Global Feature Extraction）**：
  - 使用UniFormer-Small-Plus作为全局骨干网络，捕获整个肿瘤的体积级上下文；
  - 全局特征经过全连接层形成紧凑嵌入，与各序列的局部特征拼接后，由最终分类层生成肿瘤级预测。

**损失函数**：
- 总目标：\(L = L_{cls} + L_{seg}\)
- 分类损失：\(L_{cls} = CE(y, \hat{y})\)
- 分割损失：\(L_{seg} = \frac{1}{N}\sum_{n=1}^{N} CE(\tilde{S}^{(n)}, \hat{S}^{(n)})\)
- 由于软目标仍可微，分割损失同时训练CPSA和分割网络，并反向传播到GFE流；分类损失监督两流特征和分类头。

### 2.3 训练流程
- 离线聚类生成伪标签 → CPSA在线生成软目标 → 分割网络和分类网络联合优化（端到端）。

## 3. 实验设计

### 3.1 数据集
- **LLD-MMRI2023（LLD-M）**：498例患者，8个MRI序列（T2W、DWI、同相位、反相位、增强前、动脉期、门静脉期、延迟期），任务为7类肝脏病变分类（4种良性：血管瘤、脓肿、囊肿、局灶性结节增生；3种恶性：胆管癌、转移瘤、肝细胞癌）。肿瘤mask由MedSAM半自动生成。
- **BraTS-RC（BraTS2021 Radiogenomic Classification）**：585例胶质母细胞瘤病例，4个MRI序列（T1Gd、T1w、T2、FLAIR），任务为MGMT启动子甲基化状态预测。排除无配准mask后剩577例。肿瘤mask来自BraTS2021挑战的专家标注，包括三个解剖亚区（增强肿瘤、坏死/非增强肿瘤核心、瘤周水肿）。

### 3.2 对比方法
- **BraTS-RC**：Kaggle第一名方案、Vision Graph Neural Network（ViG）、UniFormer、ResNet-50、DenseNet-121、EfficientNet-B7。
- **LLD-M**：同样对比上述通用分类网络（ViG、ResNet-50、EfficientNet-B7、DenseNet-121、UniFormer-Small-Plus）+ Kaggle排行榜结果。
- **放射组学基线**：使用PyRadiomics提取107个手工特征（形状、一阶强度、纹理），从全肿瘤或各子区域提取，训练XGBoost分类器。

### 3.3 评估指标
- **LLD-M**：宏平均F1与Cohen's kappa的平均值（F1–Kappa average），同时报告Accuracy。
- **BraTS-RC**：AUC为主要指标，同时报告Accuracy。

### 3.4 实验协议
- 5折交叉验证，报告各折平均值±标准差。
- HSG聚类参数：k-means k从3到9；DFC μ取2、0.5、0.001。每种参数在相同外折上评估，无嵌套内选（作为敏感性分析）。

## 6. 主要结论与发现

- HA-DLC在两个数据集上均取得最佳性能：
  - LLD-M：Accuracy 0.841，F1–Kappa平均0.819，较第二名分别高0.032和0.041；
  - BraTS-RC：Accuracy 0.660，AUC 0.686，较第二名分别高0.036和0.019；
- 对HSG聚类配置有一定鲁棒性：不同k-means/DFC参数下性能波动较小，最佳配置因数据集而异（LLD-M最佳为kmeans k=5，BraTS-RC最佳为DFC μ=0.5）；
- 影像衍生子区域比全肿瘤分割更有效：消融显示，子区域监督优于全肿瘤监督（在LLD-M：0.819 vs 0.802；BraTS-RC：0.686 vs 0.650）；
- 在BraTS-RC上，影像衍生子区域监督（AUC 0.686）优于专家定义解剖子区域监督（AUC 0.681），说明无需人工标注也能获得更强的异质性表征；
- CPSA对齐模块贡献显著：去除后LLD-M下降0.035，BraTS-RC下降0.068；
- GFE全局流补充了局部异质特征：单独HFE流时LLD-M下降0.050，BraTS-RC下降0.017；
- 可视化分析显示，HA-DLC发现的亚区具有跨患者的重复性模式，且与肿瘤类型（肝脏病变）和分子状态（MGMT甲基化）相关联，但生物学意义需进一步验证。

- **统计分析不足**：主要性能差异未提供置信区间或统计显著性检验（如配对检验），只能依据均值±标准差判断可靠性；
- **数据规模有限**：LLD-M只有498例、BraTS-RC 577例，肿瘤分类本身类别不平衡，模型在小样本情况下可能存在过拟合风险；
- **子区域标签生成依赖全肿瘤mask**：若肿瘤mask不准确，聚类和后续对齐会受影响，而论文未对mask误差的鲁棒性进行分析。
