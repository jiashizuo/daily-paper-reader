## 摘要
致痫区（EZ）是个体大脑中产生癫痫发作的区域，也是癫痫手术的目标。从立体脑电图（sEEG）记录中定位EZ有助于手术规划，但手动解读既耗时又侧重于发作记录。记录脑区之间静息态功能连接的图学习模型是一种有吸引力的替代方案，但其效果关键取决于模型所选用的网络拓扑。我们对基于图的模型进行了一项受控研究，以探讨图拓扑如何影响40名患者静息态sEEG的EZ定位。使用相同的简单可学习模型和留一患者评估，我们比较了稠密图、解剖和几何先验、预算稀疏化方法以及学习稀疏化方法，包括所提出的Region-Bridge-$c$拓扑。为了公平比较图构建方式，我们控制了每个节点的入边数量并改变图的稀疏度。在约30%的边保留率下，Region-Bridge-$c$达到了观测到的最高平均PR-AUC（0.371±0.015；ROC-AUC 0.743±0.010），同时使用的边比稠密图（PR-AUC 0.349±0.014）少约69%。Spatial-$k$具有竞争力，而随机剪枝需要接近稠密的边保留率。学习稀疏化受益于解剖节点元数据，但平均而言并未超越最佳固定先验。在所有拓扑中，最佳选择因患者而异。这些结果表明，图构建应被明确评估，而非视为固定的预处理。

## Abstract
The epileptogenic zone (EZ) is the brain region that generates seizures in an individual, and is the target of epilepsy surgery. Localizing the EZ from stereo-EEG (sEEG) recordings supports surgical planning, but manual interpretation is time-consuming and focuses on seizure recordings. Graphical learning models of resting-state functional connectivity among the recorded brain regions are an attractive alternative, but depend crucially on the network topology chosen for the model.   We present a controlled study of graph-based models to explore how graph topology affects EZ localization from resting-state sEEG in 40 patients. Using the same simple learnable model and leave-one-patient-out evaluation, we compare dense graphs, anatomy- and geometry-informed priors, budgeted sparsification methods, and learned sparsification, including the proposed Region-Bridge-$c$ topology. To compare graph constructions fairly, we control the number of incoming edges per node and vary graph sparsity.   At $\approx 30\%$ edge retention, Region-Bridge-$c$ achieves the highest observed mean PR-AUC ($0.371\pm0.015$; ROC-AUC $0.743\pm0.010$) while using $\approx 69\%$ fewer edges than Dense (PR-AUC $0.349\pm0.014$). Spatial-$k$ is competitive, whereas random pruning requires near-dense retention. Learned sparsification benefits from anatomical node metadata but, on average, does not surpass the best fixed prior. Across all topologies, the best choice varies by patient. These results suggest that graph construction should be evaluated explicitly rather than treated as fixed preprocessing.

### 1. 核心问题与整体含义

- **背景**：癫痫影响全球约5000万人，约30%为药物难治性癫痫。对于适合手术的患者，精准定位致痫区（Epileptogenic Zone, EZ）是手术成功的关键。立体脑电图（sEEG）虽能记录皮层深部电活动，但临床解读高度依赖专家经验且耗时，通常聚焦于短暂的发作期（ictal）信号。
- **动机**：静息态（interictal）功能连接包含潜在的致痫网络异常信息，可作为自动化定位EZ的替代信号。基于图的学习模型（如GNN）自然适用于此类功能连接数据，但其性能高度依赖图拓扑的构建方式。然而，此前尚无对照研究系统性评估不同图构建策略对sEEG-based EZ定位的影响。
- **核心问题**：在图模型用于静息态sEEG的EZ定位时，不同的图拓扑选择（稠密、先验、稀疏化、学习式）在公平的匹配预算条件下，对定位性能有何影响？是否存在一种结构先验能够在显著降低边数的同时保持甚至提升性能？

### 2. 方法论

#### 2.1 核心思想
论文将EZ定位建模为**节点级二分类问题**：sEEG电极为节点，电极对间的功能连接特征向量为边属性，目标为预测每个电极是否属于EZ。所有图拓扑共享同一个简单可学习的"双流"骨干模型，仅改变边的掩码（mask）或权重，从而隔离图拓扑本身的效应。

#### 2.2 关键技术细节

- **数据预处理**：约5分钟静息态sEEG，分段为0.5秒窗口（约600个），利用PySPI v1.1.1计算每对电极间的185种连接特征，跨窗口平均后得到`(n_p, n_p, 185)`张量；采用稳健z-score（中位数+MAD）按患者独立归一化。
- **特征选择**：无监督地基于Spearman相关聚类（δ ≤ 0.25）去除冗余特征，每簇选取一个代表，最终保留63个特征，涵盖相位、相干、相关、距离、协方差/精度以及有向/信息论度量等。该选择不涉及EZ标签，且经留一法验证具有高度稳定性（Jaccard均值0.98）。
- **骨干模型（Backbone）**：
  - **节点流**：基于39个标准化后的MICCAI解剖标签进行可学习嵌入查找，得到16维节点嵌入。
  - **边流**：63维边特征经MLP（ϕ_ege，输出32维）映射为边嵌入，按拓扑定义的权重做加权平均聚合到目标节点。
  - **融合**：边聚合向量与节点嵌入拼接，经层归一化后送入分类MLP输出二类logits。
- **图拓扑**：
  - **固定先验**：Dense（全连接）、Intra-Lead（同电极杆内）、Lead-Chain（同电极杆相邻触点）、Intra-Region（共享相同Region20粗解剖标签）。
  - **预算受控拓扑**：Random-k（随机保留k条入边）、Spatial-k（距离最近的k个空间邻居）、Region-Bridge-c（保留区域内所有边+按空间距离添加c比例的跨区域桥接边）、Learned-edges-k（学习式）。
  - **学习式稀疏化**：通过MLP打分器对每条入边打分，使用α-entmax（α=1.5）软稀疏化，推理时投影为硬top-k图，并引入辅助预算合规损失（L_aux）促进软权重逼近目标入度。

- **训练设定**：AdamW优化器，最多250轮，早停（patience=30）；损失函数为主目标焦点损失（focal loss，γ=1.0）+ λ_aux·L_aux（仅学习式拓扑，λ_aux=0.02）。超参数通过Spatial-k锚定拓扑的网格搜索固定，避免逐拓扑调参导致的不公平。

### 3. 实验设计

- **数据集**：40例药物难治性癫痫患者（21男/19女，平均年龄13.3岁），均为术后预后良好（ILAE 1-3）且至少有一个EZ标记触点。总计5282个触点，其中635个（12.0%）为EZ，类别不平衡比7.3:1。数据来自单中心（Cincinnati Children’s Hospital），包含约5分钟清醒静息态sEEG（采样率2048Hz）。
- **Benchmark / 评估协议**：**留一患者交叉验证（LOPO）**，每折将剩余39例按80%:20%划分训练/验证集；每折重复5个随机种子。评估指标以PR-AUC为主（随机基线≈0.12），辅以ROC-AUC、MCC、敏感性、特异性（阈值基于验证集Youden's J确定）。
- **对比方法**：
  - 固定结构先验：Dense、Intra-Lead、Lead-Chain、Intra-Region。
  - 预算匹配：Random-k、Spatial-k、Region-Bridge-c、Learned-edges-k、Learned-Region20-k（以及消融用的其他学习变体）。
  - 所有预算方法在**匹配的≈30%边保留率**下比较，且系统扫描20个目标保留率（r ∈ {0.05, ..., 1.00}）。
- **消融实验**：基于Dense拓扑，进行Edge-only、Node-only、边属性打乱、节点元数据打乱共4组对照消融。

### 6. 主要结论与发现

1. **图拓扑显著影响性能**：在相同骨干下，不同拓扑的平均PR-AUC跨度达0.065（0.306–0.371）。
2. **Region-Bridge-c最优**：在≈30%边保留率下取得最高PR-AUC（0.371±0.015）和ROC-AUC（0.743±0.010），比Dense图少约69%边。在保留率扫描中于48.5%保留率处达到峰值0.384。
3. **Spatial-k有竞争力**（PR-AUC 0.363），显著优于同预算下的Random-k（0.321），说明"保留哪些边"比"保留多少边"更重要。
4. **学习式稀疏化未超越最优固定先验**：Learned-Region20-k（0.354）优于Learned-edges-k（0.339），表明解剖元数据有帮助，但平均来看仍低于Region-Bridge-c。
5. **患者异质性显著**：没有任何单一拓扑在所有患者上占优；Region-Bridge-c在24/40患者中优于Dense，但Wilcoxon检验不显著（p=0.383），患者间最佳拓扑差异中位数为0.16 PR-AUC。
6. **消融结果**：边属性与节点元数据都携带信号，打乱任一来源均显著退化（PR-AUC降至0.16及以下）。

### 7. 优点

- **受控比较框架**：通过匹配每节点入边预算、固定骨干、统一超参，建立了公平的拓扑对比范式，有效隔离了边密度混淆。
- **提出有效且可解释的先验**：Region-Bridge-c（区域密集+空间桥接）简单实用、计算开销低且性能优异，具有临床可解释性。
- **全面的拓扑覆盖**：从稠密图到解剖/几何先验、随机基线、学习式稀疏化，维度覆盖完整。
- **系统的稀疏度敏感性分析**：20级保留率扫描揭示了各拓扑的"最佳工作点"，避免了单一稀疏度比较的误导。
- **严谨的统计报告**：5种子均值±标准差、Bootstrap置信区间、非参数检验，统计报告较规范。
- **诚实的局限性声明**：明确承认未做外部验证、性能最大化不是目标、硬top-k可能限制表达力等。

### 8. 不足与局限

- **单中心、小样本**：40例患者均来自同一医疗中心，未在外部多中心队列验证；LOPO仅验证了内部泛化性。
- **标签依赖临床判读**：EZ标签基于临床视觉分析，存在固有判读差异；虽限ILAE 1-3可缓解但无法消除。
- **静态图局限**：窗口平均连接掩盖了与EZ相关的瞬态动态，动态功能连接可能捕获更多信息。
- **解剖配准误差**：基于MNI空间距离和粗粒度Region20标签构建先验，电极定位误差会影响结构掩码和学习元数据。
- **排名依赖特定设定**：结果基于Spatial-k锚定的超参数、单一骨干架构和匹配保留率策略；更强的架构或逐拓扑调参可能改变排名。
- **无原则性的r选择规则**：虽然做了保留率扫描，但如何为个体患者确定最优保留率未给出规则。
- **学习式方法受限**：硬top-k投影限制了表达力；全局训练的评分器在40例小数据下易过拟合，未充分发挥学习式优势。
- **未与临床基线比较**：未与临床专家的人工判读或其他非图模型方法对比，无法评估其绝对临床实用性。
- **代码和数据不可共享**：受患者保密协议限制，影响可复现性。
