## 摘要
脑电图（EEG）分析不仅限于为记录分配预定义标签，还需要将自然语言指令、信号处理、定量证据和科学解释连接起来的工作流程。我们将这种能力称为“全面EEG理解”。然而，现有评估主要针对孤立的解码任务或特定系统演示，使得大型语言模型（LLM）的能力未得到充分量化。我们引入了BrainBench，一个统一的基准，用于全面的、基于指令的EEG理解。它包含四个子集——基础分析、睡眠评估、神经认知评估和生理整合——覆盖了17个数据集、\numcases{}个任务和超过\numinstances{}个真实数据实例。给定一条指令和可选的生理信号的EEG记录，系统必须执行分析并生成有科学依据的报告，并在需要时生成产物。输出通过数值、分类、集合、序列、语义和产物验证进行评估。我们评估了\nummodels{}个代表性LLM，在两种范式下进行了超过10万次执行：使用CodeAct的自主代码执行和使用BrainAgent的结构化代理分析。结果在不同模型、子集、难度级别和执行范式之间存在显著差异，表明EEG能力取决于模型及其操作化方式。BrainBench为推进基于LLM的EEG理解提供了一个可复现的测试平台。代码和基准将很快发布，评估结果将持续更新。

## Abstract
Electroencephalography (EEG) analysis extends beyond assigning predefined labels to recordings; it requires workflows connecting natural-language instructions, signal processing, quantitative evidence, and scientific interpretation. We term this capability \emph{comprehensive EEG understanding}. Existing evaluations, however, primarily target isolated decoding tasks or system-specific demonstrations, leaving the competence of large language models (LLMs) insufficiently quantified. We introduce \benchmarkname{}, a unified benchmark for comprehensive, instruction-conditioned EEG understanding. It comprises four subsets---Foundational Analysis, Sleep Assessment, Neurocognitive Assessment, and Physiological Integration---covering 17 datasets, \numcases{} tasks, and over \numinstances{} real-data instances. Given an instruction and EEG recordings with optional physiological signals, a system must perform the analysis and produce a scientifically grounded report and, when required, artifacts. Outputs are assessed through numerical, categorical, set, sequence, semantic, and artifact validation. We evaluate \nummodels{} representative LLMs across more than 100K executions under two paradigms: autonomous code execution with CodeAct and structured agentic analysis with BrainAgent. Results vary substantially across models, subsets, difficulty levels, and execution paradigms, showing that EEG competence depends on the model and its operationalization. \benchmarkname{} provides a reproducible testbed for advancing LLM-based EEG understanding. The code and benchmark will be released soon, with evaluation results continuously updated.

- **研究背景**：

  - LLM与智能体（agent）凭借语言理解、推理和代码生成能力，为EEG分析提供了从专用管道转向交互式通用流程的契机（如CELM、BrainAgent、BrainPilot等系统的涌现）。

### 2. 论文提出的方法论

#### 2.1 核心思想

- 将EEG理解形式化为 **“指令条件下的分析执行”（instruction-conditioned analytical execution）**：
  - 给定自然语言指令 $I_i$ 与输入文件 $D_i$，目标系统 $\mathcal{M}$ 生成自由形式的分析报告 $R_i$ 及所需产物 $A_i$；
  - 统一评估函数 $E$ 基于任务定义的验证标准计算实例得分 $s_i$。

#### 2.2 BrainBench的三级层次结构：子集（Subset）→ 任务（Task）→ 实例（Instance）

| 层级 | 说明 |
|---|---|
| **子集（Subset）** | 定义评估范围，包含4个互补子集 |
| **任务（Task）** | 可复用的分析目标+预期输出+验证要求；按难度分为Easy/Medium/Hard三级 |
| **实例（Instance）** | 任务与具体数据上下文绑定，变化记录、被试、参数或指令 |

#### 2.3 四个子集

- **基础分析（Foundational Analysis）**：40个任务、950个实例；涵盖记录检查、预处理、特征提取、时空比较、连通性分析、伪迹生成、基于证据的解释等通用EEG能力。
- **睡眠评估（Sleep Assessment）**：43个任务、1,025个实例；覆盖睡眠结构量化、分期与频谱解释、睡眠事件检测、多模态生理分析、临床全夜指标计算等。
- **神经认知评估（Neurocognitive Assessment）**：50个任务、1,030个实例；涵盖情绪状态、认知负荷和疲劳的状态识别、特征比较、时序与个体内分析、多模态证据整合等。
- **生理整合（Physiological Integration）**：39个任务、1,120个实例；评估EEG与EOG/ECG/fNIRS等信号的时序对齐、跨模态耦合与融合、质量评估、数据修复、缺失模态重建等。

#### 2.4 多单元验证（Multi-Unit Validation）

- **Parser Agent**：仅作为提取器，将自由文本报告转换为结构化JSON字段，不评估科学性、不纠正错误、不推断缺失项。
- **六种验证单元**：
  - *数值验证*：标量值与容差比较，$v_{num} = \mathbb{1}[|\hat{y} - y| \le \tau]$；
  - *分类验证*：规范化后精确匹配；
  - *集合验证*：精确匹配或元素级部分得分；
  - *序列验证*：位置匹配、精确顺序或加权偏序匹配（考虑元素覆盖与顺序一致性）；
  - *语义验证*：任务特定Semantic Judge评估结论的正确性、相关性、指令一致性及幻觉；
  - *产物验证*：检查生成文件的合法性与字段级指标（形状、通道数、时长、采样率等）。
- **得分聚合**：实例得分 $s_i = 100 \times \frac{\sum_m w_{im} v_{im}}{\sum_m w_{im}}$；子集得分 $S_S = \frac{\sum_{i \in S} d_i s_i}{\sum_{i \in S} d_i}$（$d_i \in \{1.0, 1.5, 2.0\}$ 为难度系数）。

#### 2.5 双范式执行协议

- **CodeAct**：LLM自主规划并生成/执行Python代码，提供开放环境；使用可持久化内核、多轮交互（最多20轮）。
- **BrainAgent**：结构化EEG多智能体框架；监督者将请求分解给专业智能体，通过能力导向的工具集（非任务特定）执行，并采用迭代、状态感知的规划机制与层级化共享状态。
- **黑盒评估**：目标系统仅能看到指令和输入文件；Ground-Truth、验证配置和评分实现完全隐藏。

### 6. 论文的主要结论与发现

- **发现1**：当前LLM具备实质性但不完整的EEG理解能力。结构化智能体执行（BrainAgent）在FA上对13个模型中的10个、SA上对12个模型有提升；平均总体得分BrainAgent 68.78 vs CodeAct 62.83。但最佳得分仍低于80，提升空间明显。
- **发现2**：性能随任务难度系统性下降。BrainAgent在SA上从Easy的91.0降至Hard的35.8；结构化的优势在最难任务上收窄（FA：16.6→4.1→2.4；SA：5.0→13.2→3.3），说明工作流结构无法完全弥补长程推理的局限。
- **发现3**：结构化工作流主要增强**执行落地型能力**——数值验证与产物验证的改进最一致，而分类、集合、序列、语义等单元的模式差异高度依赖模型与子集。
- **发现4**：BrainAgent整体上降低了任务内跨实例变异性（MPAD更低），表明结构化工具与受控流程提高了EEG理解在共享目标下跨记录/环境的迁移一致性。
- **范式互补性**：结构化执行提升可靠性、降低对模型的敏感性；自主编码保留灵活性、token效率更高但性能方差更大。二者不可互换，需按应用场景权衡。

### 7. 优点

- **评测范式的创新**：从“固定标签解码”跃迁到“指令-分析-结论”的端到端能力评估，更贴近真实EEG分析工作流。
- **多维度、多粒度的验证架构**：六种验证单元覆盖数值精确性、离散决策、结构化输出、科学解释与可交付产物，兼顾严格性与灵活性。
- **双范式对照设计**：在同一指令/数据/验证协议下隔离执行范式变量，可清晰区分“模型能力”与“操作化方式”的贡献。
- **难度分层与跨实例稳定性分析**：不仅报告平均分，还量化了任务内变异性，为泛化能力提供了更精细的证据。
- **严谨的工程化与可复现性**：黑盒协议、容器隔离、失败重试策略明确；Parser与Semantic Judge经过独立审计，报告了评估管线自身的不确定性。
- **可扩展性**：基准设计支持新增数据集、任务、验证维度与模型，评估结果可持续更新。

### 8. 不足与局限

- **结果覆盖不完整**：当前完整榜单仅涵盖基础分析与睡眠评估两个子集，神经认知与生理整合的评估结果尚待展示，影响了四种能力的整体可比性。
- **单次执行、无随机性处理**：未讨论重复运行下的得分方差，温度的随机性可能导致个别实例得分不稳定。
- **语义验证的可靠性瓶颈**：Semantic Judge审计一致性为95.54%，虽较高但仍是最大评估不确定性来源；未进行大规模人类标注比对，绝对准确性未知。
- **评估成本与效率失衡**：BrainAgent显著更高的token消耗未配以成本/收益的量化分析，可能影响实际部署决策参考。
- **模型族覆盖仍有空白**：虽覆盖13个模型，但结果呈现集中于少数模型家族的对比（如Qwen与GPT系列），尚未覆盖更多开源或领域特定模型。
- **数据偏差风险**：每个数据集仅取前5名被试，且仅作格式统一、不做信号质量筛选，特定数据集的异常记录可能引入系统性偏差；EEG本身的高个体差异也可能影响跨被试泛化结论的稳健性。
- **黑盒只能评估最终报告**：中间推理过程仅记录不评分，无法诊断模型失败的具体认知环节（是规划、工具选择还是解释环节出错）。
