## 摘要
基于机器学习的脑组织微结构估计在计算效率上优于传统拟合方法。然而，机器学习仍存在重要局限性，妨碍了其临床实用性。具体而言，当前模型通常缺乏跨扩散MRI采集协议的泛化能力，每当b向量或b值改变时就需要重新训练。此外，近期为解决协议泛化问题而开发的机器学习方法缺乏旋转等变性。特别适合dMRI参数估计的是一种几何深度学习模型——球面卷积神经网络（SCNN），它保证了旋转等变性和b向量泛化。然而，该架构目前未考虑b值。因此，获得一个兼具协议泛化与旋转等变性的模型仍是开放挑战。本文通过超网络将显式b值依赖纳入SCNN架构，直接解决了这一问题。以NODDI作为示例前向模型，展示了这一新方法在脑组织微结构估计中的应用。为评估b值泛化性能，原始和新提出的SCNN架构在合成数据上训练，并在不同b值组合的合成数据和真实数据上测试。结果表明，所提方法在合成数据上降低了RMSE和偏差，在真实数据上与常规NODDI拟合的一致性更高，表明对未见b值的鲁棒性增强且重新训练需求减少。通过将b值泛化与b向量泛化及旋转等变性相结合，所提框架增强了深度学习在临床扩散MRI参数估计中的适用性。代码见 https://github.com/aerdnairo/arXiv\_generalisedSCNN。

## Abstract
Brain tissue microstructure estimation with machine learning provides higher computational efficiency than conventional fitting. However, machine learning still presents important limitations that hamper its clinical utility. Specifically, current models typically lack generalisation across diffusion MRI acquisition protocols and require retraining whenever b-vectors or b-values change. Moreover, the recent machine learning methods that were developed to address protocol generalisation lack rotational equivariance. Particularly suitable for dMRI parameter estimation is a geometric deep learning model known as spherical convolutional neural network (SCNN), which guarantees rotational equivariance and b-vector generalisation. However, this architecture currently does not account for b-values. Therefore, obtaining a model that combines protocol generalisation and rotational equivariance remains an open challenge. In this paper, we directly address this issue by incorporating explicit b-value dependence into an SCNN architecture via a hypernetwork. This new approach is illustrated using NODDI as an example forward model for estimating brain tissue microstructure. To evaluate b-value generalisation, the original and newly proposed SCNN architectures are trained on synthetic data and tested on both synthetic and real data across different b-value pairs. Results demonstrate that the proposed method achieves reduced RMSE and bias on synthetic data, as well as higher agreement with conventional NODDI fitting on real data, indicating improved robustness to unseen b-values and a reduced need for retraining. By combining generalisation across b-values with generalisation across b-vectors and rotational equivariance, the proposed framework enhances the applicability of deep learning to clinical diffusion MRI parameter estimation. Code available at https://github.com/aerdnairo/arXiv\_generalisedSCNN.

- **研究背景**：扩散加权磁共振成像（dMRI）可以通过扩散梯度（b-vector）和扩散强度（b-value）等采集协议参数来探测脑组织的微结构信息。传统方法基于前向模型（如 NODDI）对每个体素进行迭代拟合，计算成本极高，难以满足临床需求。
- **机器学习方法的痛点**：基于机器学习的方法（如 MLP、SCNN 等）虽能显著提升计算效率，但存在两大关键问题：
  1. **协议泛化能力不足**：模型通常在特定 b-value 和 b-vector 方案下训练，当采集协议改变时就需要重新训练；
  2. **缺乏旋转等变性**：新近提出的协议感知方法（如 DiffNet、aqDL）虽能处理 b-value 和 b-vector，但不具备旋转等变性，对脑部不同朝向的泛化能力有限。
- **本文目标**：提出一种同时具备 **b-value 泛化、b-vector 泛化和旋转等变性** 的深度学习模型，弥补现有方法的空白，提升机器学习在临床 dMRI 参数估计中的实用价值。

## 二、方法论

### 1. 核心思想
- 以**球面卷积神经网络（SCNN）**为基础框架，利用其天然具备的旋转等变性和 b-vector 泛化能力；
- 引入**超网络（Hypernetwork）**，以 b-value 作为输入，动态生成 SCNN 前几层的权重，从而将 b-value 依赖显式注入模型；
- 通过这一组合，模型在保持 SCNN 原有优势的同时，获得 b-value 泛化能力，实现"一次训练、多协议使用"。

### 2. 关键技术细节
- **SCNN 基础架构**：
  - 6 层球面卷积层，通道数为 [2, 16, 32, 64, 32, 16, 1]；
  - 通过全局池化获取旋转不变标量表示，后接全连接层（112 → 128 → 128 → 3），输出 NODDI 的三个参数：NDI、ODI、FWF。
- **超网络（hSCNN）**：
  - 超网络为一个小型 MLP：输入大小为 2（即两个 b-value），隐藏层大小为 8，输出大小为 1152，对应目标卷积层的权重参数；
  - 仅将超网络应用于第一个球面卷积层，以控制模型复杂度并避免过参数化；
  - hSCNN 总参数量为 80,715，比原 SCNN 的 78,387 仅增加约 2,300 个参数。
- **输入表示**：每个体素的 dMRI 信号先转换为每个 shell（b-value）对应的球谐系数（SH coefficients），拼接后形成 45 × 2 的矩阵作为 SCNN 输入。
- **训练目标**：最小化模型预测与真实微结构参数之间的均方误差（MSE）。

### 3. 算法流程（文字说明）
1. 使用 NODDI 前向模型合成训练数据，生成微结构参数（NDI、ODI、FWF）对应的无噪声信号；
2. 在信号中加入 Rician 噪声（SNR = 15），模拟真实测量环境；
3. 将多协议（不同 b-value 对）下的信号数据转换为球谐系数表示；
4. 训练 hSCNN：输入为球谐系数矩阵和对应的 b-value 对，超网络根据 b-value 生成第一个卷积层的权重，完整网络通过反向传播联合优化；
5. 训练完成后，对任意新协议的数据，仅需输入相应的 b-value 即可获得参数估计，无需重新训练。

## 三、实验设计

### 1. 数据集与场景
- **合成数据**：
  - 训练集：936,000 个体素组合；验证集：104,000 个；测试集：500 个通过网格采样生成的参数组合；
  - 共三组数据：
    - `1k2k`：b-value = 1000、2000 s/mm²；
    - `1k3k`：b-value = 1000、3000 s/mm²；
    - `var`：b-value 在 [700, 1200] 和 [2000, 3000] 范围内均匀随机采样；
  - 每个 b-value shell 使用 60 个静电优化梯度方向。
- **真实数据**：
  - 来自 Human Connectome Project（HCP）的两名受试者（100206、100307）；
  - 数据含三个壳层（b = 1000、2000、3000 s/mm²），每层 90 个梯度方向，18 个 b=0 图像；
  - 由于模型训练只用两个壳层，推理时将数据分为两个子集：(1000, 2000) 和 (1000, 3000)；
  - 伪真值（pseudo ground truth）由完整三壳层数据经传统 NODDI 拟合获得。

### 2. 对比方法
- **SCNN\_1k2k**：仅在固定协议 1k2k 上训练的原始 SCNN（性能上界参考）；
- **SCNN\_1k3k**：仅在固定协议 1k3k 上训练的原始 SCNN；
- **SCNN\_var**：在多协议（变 b-value）数据上训练的原始 SCNN（无超网络）；
- **hSCNN\_var**（本文方法）：在多协议数据上训练的带超网络的 SCNN。

### 3. 评价指标

## 六、主要结论与发现

- **hSCNN\_var 在各类协议下均达到或接近专用模型（SCNN\_1k2k 或 SCNN\_1k3k）的性能**，证明超网络成功引入了 b-value 泛化能力；
- **SCNN\_var（不加超网络）即使使用多协议训练，泛化性能仍较差**，说明仅靠数据增强无法解决跨 b-value 泛化问题，显式的 b-value 建模是必要的；
- 差异主要体现在 NDI 和 FWF 上（对信号缩放更敏感），ODI 的差距相对较小；
- 在真实数据上，hSCNN\_var 与 NODDI 拟合结果的一致性最高，尤其在避免过估计和欠估计方面表现突出；
- **结论**：所提框架首次同时实现了 b-value 泛化、b-vector 泛化和旋转等变性，显著减少了临床场景中因协议变化而重新训练的需求，为深度学习在临床 dMRI 参数估计中的落地提供了可行路径。

## 七、优点

1. **方法创新性强**：首次将超网络与 SCNN 结合，填补了"协议泛化 + 旋转等变"同时兼备的空白；
2. **设计简洁高效**：仅用一个小型 MLP 超网络控制第一层权重，参数量增加极少（<3%）却带来显著的泛化提升；

## 八、不足与局限

1. **固定平行扩散率**：在数据模拟和 NODDI 拟合中均使用固定的平行扩散率（1.7×10⁻³ mm²/s），未区分灰质和白质的差异，可能引入偏差；
