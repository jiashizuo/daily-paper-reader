## 摘要
功能性磁共振成像（fMRI）是研究大脑的广泛使用的技术。近年来，利用图神经网络（GNN）分析大脑功能连接的方法在脑疾病（如阿尔茨海默病，AD）的分类中显示出巨大潜力。然而，这些方法通常假设所有受试者具有预设数量的功能模块，忽略了受试者间的变异性。此外，发现的模块很少被直接用于指导学习到的连接模式。为了解决这些问题，我们提出了一种元概率池化图神经网络（MPP-GNN）。我们将模型的任务构建为耦合的双层优化，该优化分层执行自适应图划分以发现受试者特定的模块，然后将发现的脑模块作为显式先验来指导边细化和表示学习。我们在两个公开数据集上验证了MPP-GNN用于AD分类的性能，与现有基准相比，在两个数据集上都取得了最高的AUC。此外，我们的分析表明，MPP-GNN与Yeo脑图谱定义的典型功能网络组织显著对齐，并揭示了AD的网络级去分化模式。

## Abstract
Functional magnetic resonance imaging (fMRI) is a widely used technique for studying the brain. Recent methods that utilize graph neural networks (GNNs) for analysis of brain functional connectivity have shown great potential for the classification of brain disorders, such as Alzheimer's disease (AD). However, these methods often assume a preset number of functional modules across all subjects, which overlooks inter-subject variability. In addition, the discovered modules are rarely used to directly guide the learned connectivity patterns. Here, to address these issues, we propose a Meta Probabilistic Pooling GNN (MPP-GNN). We frame the model's task as a coupled, bilevel optimization that performs adaptive graph partitioning hierarchically to discover subject-specific modules and then uses the discovered brain modules as an explicit prior to guide edge refinement and representation learning. We validate MPP-GNN on two public datasets for AD classification, achieving the highest AUC in comparison to established baselines for both datasets. Furthermore, our analysis demonstrates that MPP-GNN shows significant alignment with the canonical functional-network organization defined by the Yeo brain atlas and reveals a network-level dedifferentiation pattern for AD.

## 1. 核心问题与研究动机

- **背景**：fMRI 是研究大脑功能连接的常用非侵入性手段。阿尔茨海默病（AD）具有漫长的临床前窗口期，早期检测对干预至关重要。基于脑区 ROI 构建功能连接（FC）矩阵，再利用图神经网络（GNN）进行疾病分类，是近年来的研究热点。
- **核心问题**：现有 GNN 方法存在三大挑战：
  1. **FC 矩阵噪声大**：BOLD 信号受生理伪影、扫描时长等因素干扰，导致同一受试者内和跨受试者间存在较大变异；
  2. **忽视大脑模块化的个体差异**：许多方法预设固定数量的功能模块（如固定聚类数目），与大脑组织的高度异质性矛盾；
  3. **可解释性不足**：常见的 post-hoc 解释方法（如显著性图、替代解释）在不同算法间缺乏一致性，透明性有限。
- **核心洞察**：上述挑战密切相关——社区结构可以引导边缘细化（区分社区内/社区间连接），细化后的边和表示又能反过来改进分区策略。因此需要在统一框架中联合解决，而非将其视为独立的预处理或后处理步骤。

## 2. 方法论

### 2.1 总体框架：耦合双层优化（Bilevel Optimization）

- **外层目标**：学习最优的图分区策略（由 Affinity Propagation 聚类决定），最大化模型在验证集上的 AUC；
- **内层目标**：在给定分区结构下，联合优化边权重细化与节点表示学习，最小化训练损失。
- **优化策略**：采用 **SBO（Smoothing-Based Variational Optimization）** 解决离散聚类分配阻断梯度流的问题。将分区诱导元权重建模为多元高斯分布：
  - `W_meta ~ N(μ, σ²_meta I)`
  - 外层通过基于 AUC 分数的加权更新迭代优化 `μ` 和 `σ_meta`，直至收敛或达到最大 meta-epoch 数（实验中为 50，每次 8 个样本）。

### 2.2 AP-HPM：基于亲和传播的层次化池化模块

- **相似度矩阵构建**：第一层相似度矩阵结合元特征距离（`D_Z`）、节点度差异（`D_deg`）和最短路径距离（`D_sp`）：
  ```
  S(1) = exp( -D_Z - λ_deg·D_deg - λ_sp·D_sp )
  ```
  其中 `λ_deg = λ_sp = 0.1`，拓扑特征固定，元特征随外层优化进化。
- **亲和传播（AP）聚类**：AP 算法无需预设聚类数量，自适应地决定每个受试者的模块数，克服了固定聚类容量的局限。
- **层次化粗化**：逐层对节点特征取均值池化（式 9），对社区间边取均值构建粗化图（式 10），并递归池化相似度矩阵（式 11），形成从 ROI → 网络 → 系统的多分辨率层次结构。

### 2.3 PERM：概率边细化模块

- **全局逻辑边门控**：对每条边 (i, j)，以三类具有明确结构意义的特征作为输入，估计边保留概率：
  ```
  P(l) = σ( λ1·S(l) + λ2·C(l) + λ3·R(l) + λ4 )
  ```
  其中 `S(l)` 为元特征/拓扑相似度、`C(l)` 为社区共属指示（+1 同社区 / -1 跨社区）、`R(l)` 为当前层节点特征的余弦相似度。
- **随机伯努利掩码**：通过松弛伯努利采样（温度参数 τ）将概率转为近离散掩码，保留梯度流，同时起到结构数据增强和软稀疏化的作用。
- **可解释性**：标量参数 `λ1~λ4` 直接量化各因素对边保留的贡献，无需 post-hoc 归因。

### 2.4 损失函数

- 最终损失为：`L = L_cls + λ_edge·L_edge`
- `L_edge` 为二分熵正则项，鼓励边保留概率远离 0.5、趋近二元决策，增强解释清晰度；
- `L_cls` 采用 Focal Loss（UK Biobank γ=0.6，ADNI γ=0.25）以缓解类别不平衡。

## 6. 主要结论与发现

1. **性能优势**：MPP-GNN 在两个公共数据集上取得最优 AUC，在 ADNI 上全面领先，验证了受试者自适应社区发现与边细化的联合框架的有效性。
2. **神经科学一致性**：
   - AP-HPM 学习到的社区分区与 Yeo 图谱（Yeo-17/Yeo-7）显著对齐（NMI 高于置换零分布，p < 0.001；共识分区优于 99.7% 的个体分区）；

## 7. 方法亮点

- **受试者自适应分区**：AP 算法不需要预设聚类数，真正实现了个体化的模块发现，契合大脑组织的异质性；
- **耦合双层优化**：将社区发现与表示学习在统一框架内联合优化，而非分离的预处理/后处理步骤，符合任务驱动的原则；
- **社区结构作为显式先验指导边细化**：通过 `C(l)` 共属指示直接将模块信息注入边保留概率，实现结构性归纳偏置；
- **天然可解释性**：边门控的参数化具有明确语义（每个系数对应一个解释性因素），无需 post-hoc 归因，避免了解释不一致问题；
- **可复现性验证**：跨折/跨数据集的稳定性检验、置换检验、共识分析等多层次验证手段严谨；
- **随机掩码的双重功能**：软稀疏化 + 结构数据增强，兼有去噪与正则化效果。

## 8. 不足与局限
