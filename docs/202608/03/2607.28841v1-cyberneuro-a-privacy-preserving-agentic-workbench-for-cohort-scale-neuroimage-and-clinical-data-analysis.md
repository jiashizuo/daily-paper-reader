## 摘要
尽管神经影像方法学取得了巨大成功，但使大规模、高维数据集为AI/ML应用做好准备仍是一个关键的操作瓶颈。传统工作流程需要在元数据整理、流水线执行、后处理质量控制以及数据管理方面投入大量人力，这一负担不成比例地将人力和计算基础设施有限的实验室排除在外。为应对这一现实障碍，亟需可扩展且成本效益高的计算平台，以普及先进神经影像分析，并加速心理健康与临床转化方面的发现。借助多智能体大语言模型的突破，我们推出了CyberNeuro，一个带有定制本地LLM模型（“WandaMind”）的智能体工作台，用于自动化神经影像与健康数据分析。CyberNeuro由四个专用智能体（规划器、验证器、调度器和报告器）驱动，通过安全的MCP桥接和固定执行层进行通信，使研究人员能够使用自然语言执行复杂工作流程，同时保持临床级数据隐私。在公开的NeuroBench套件上，CyberNeuro将保留领域准确率从基线模型的40%提升至69%。除自动指标外，该平台还集成了人在回路验证面板，以确保严格的生物医学质量控制。在相同的端到端10批次队列工作流程套件中，与Neuroclaw相比，本地WandaMind配置以估计的聚合令牌数量完成了所有任务，WandaMind和云提供商的令牌使用量分别约为10.6%和61.7%。该平台及其生产就绪模块可在https://wanda-cyberbench.com获取。

## Abstract
Despite tremendous success in neuroimaging methodology, making large-scale, high-dimensional datasets ready for AI/ML applications remains a critical operational bottleneck. Conventional workflows require extensive manual effort across metadata curation, pipeline execution, post-processing quality control, and data management, a burden that disproportionately excludes laboratories with limited manpower and computational infrastructure. To address this real-world barrier, there is an urgent need for scalable, cost-effective computational platforms that democratize advanced neuroimaging analytics and accelerate discoveries in mental health and clinical translation. Capitalizing on multi-agent LLM breakthroughs, we introduce CyberNeuro, an agentic workbench with a tailored local LLM-model ('WandaMind') for automated neuroimaging and health-data analysis. Driven by four dedicated agents (Planner, Validator, Dispatcher, and Reporter) communicating via a secure MCP bridge and a pinned execution layer, CyberNeuro enables researchers to execute complex workflows using natural language while maintaining clinical-grade data privacy. On the public NeuroBench suite, CyberNeuro increases held-out domain accuracy from 40% to 69% over the baseline model. Beyond automated metrics, the platform integrates a human-in-the-loop verification panel to ensure rigorous biomedical quality control. Across the same end-to-end 10-batch cohort workflow suite, the local WandaMind configuration completed all tasks with an estimated aggregate token count of about 10.6% using WandaMind and 61.7% using cloud providers of token usage, compared to Neuroclaw, respectively. The platform and its production-ready modules are available at https://wanda-cyberbench.com.

## 2. 论文提出的方法论

**核心思想：** 将 LLM 驱动的弹性规划与确定性工具执行、多层验证分离，构建"LLM 路由、工具确定性执行、验证层判定结果"的混合编排架构，在严格本地部署边界内实现端到端自动化。

**系统架构（三层结构）：**

- **交互层（Interaction Layer）**：集自然语言对话请求、技能中心（Skill Hub，管理 30+ 神经影像处理与可视化技能）、交互式协同可视化面板于一体。
- **编排层（Orchestration Layer）**：由领域专用 7B 本地模型 WandaMind 驱动，通过 MCP（Model Context Protocol）桥接四个专用智能体：
  - **Planner（规划器）**：LLM 驱动，将自然语言请求解析为任务 DAG（有向无环图），节点包含技能、参数、输入输出、权限等。
  - **Validator（验证器）**：确定性组件，在三个时点做验证——**执行前契约/策略/运行时验证**、**执行后产物验证**（退出码、文件存在性、可解析性、领域不变量），防止"零退出码但无真实派生产物"被误报为成功（分类为 `failed_artifact_validation`）。
  - **Dispatcher（调度器）**：仅执行已验证的节点，强制运行时与权限决策，记录日志与资源使用。
  - **Reporter（报告器）**：汇总验证通过的产物、日志与收据（receipt），对接可视化/QC 面板。
- **技能演化（Skill Evolution）**：Meta-skill 机制将技能草稿通过多级验证门（schema→安装→执行→产物→人工）蒸馏为冻结的已验证技能包。
- **记忆模块（Memory Pill）**：记录用户偏好、历史收据、修正记录，支持跨会话的个性化学习。

**WandaMind 模型细节：**

- 基座模型：Qwen2.5-7B-Instruct，采用 **QLoRA**（4-bit NF4 量化基座权重冻结，仅训练低秩适配器）。
- 配置：秩 r=32，缩放 α=64（α/r=2.0），dropout=0.05，可训练参数 **80.7M（仅占全模型的 1.06%）**，训练 3 个 epoch。
- **响应专属监督（response-only supervision）**：系统指令、工具描述、用户消息不参与损失计算，仅对助手响应和工具调用序列计算损失。
- 训练语料筛选：315 条教师生成轨迹 + 306 条规则扩展 + 101 条针对性案例 → 过滤后 722 条核心轨迹；经 schema 验证剔除 41 条；用 Jaccard 相似度 ≥ 0.55 与 QC-62 去污。
- **三轮迭代训练**：① 监督初始化 → ② 行为增强（导致过度主动）→ ③ 对抗性加固（修复"应克制却行动"的边界问题），最终在行动/拒绝/搜索之间建立正确的决策边界。
- 部署：LoRA 适配器合并后转 GGUF 并 Q4_K_M 量化。
- 数据增强细节：质控标签基于定量指标（Euler number、NCC、NMI、dseg 组织分割指标），教会模型将量化证据与调用/升级/弃权决策关联。

**安全设计：**

- **工作区隔离**：固定目录布局（inputs/、outputs/、temporary/、pipelines/、generated-skills/、memory/），路径规范化检查，拒绝目录穿越、符号链接逃逸和未声明的覆写。

## 6. 论文的主要结论与发现

**四个研究问题的回答：**

1. **RQ1（域适应）**：WandaMind 在 QC-62 上达到 **69.4%**（Base 7B 为 40.3%，Local 27B 为 48.4%）。但提升**完全来自决策质量**（弃权召回 0→100%，误行动 100→0%），而非工具选择（与基线持平）或参数有效性（反而降 6.3 分）。结论：域适应带来的是**有界动作空间内的决策硬化（decision hardening）**，而非通用能力增益——IFEval 下降 5.2 分即为代价。
2. **RQ2（DICOM→BIDS）**：CyberNeuro 以**零人工干预**完成全部 10 个队列，NeuroClaw 需 24 次干预；所有输出通过 BIDS 验证器（零错误）；token 消耗：WandaMind 1,127.5/NIfTI（NeuroClaw 的 **10.6%**）、云后端 6,569.8/NIfTI（61.7%）；运行时间减少 19.8-22.5%（归因于消除转换-整理交接和干预停滞，而非计算加速）。总 token 差距为 29.1 倍。
3. **RQ3（可视化/QC）**：单应用完成所有任务，应用数减少 66.7-75%，应用切换减少 100%，显式操作减少 90.0-94.4%，中位完成时间减少 >99.94%。运行产物自带 QC 图像（90 张）和 HTML 报告（14 份，无外部依赖）。
4. **RQ4（隐私）**：进程级断网条件下 4 个任务组全部成功、零发送字节，负面控制被阻止。结论限于"加固版本在测试配置和时间窗口内观察到零出站流量"，不构成空气隔离合规证明。

**核心主张**：CyberNeuro 将临床队列处理训练时间从 1-2 个月压缩至约 1 周，提供确定性可复现性和全面溯源追踪。

## 7. 优点

- **本地优先的隐私架构**：默认零出站网络，适用于 IRB 限制和机构数据使用协议场景，通过实际网络捕获和断网测试验证（而非只是声称）。
- **LLM 规划与确定性验证分离**：防止 LLM 的"口头成功"被当作科学计算发生的证据；故障注入实验有力证明了产物验证层的必要性。
- **资源效率极高**：7B 本地模型 + 仅 1.06% 参数微调即达到超越 27B 模型的任务表现；token 消耗比 NeuroClaw 减少 89.4%。
- **全面的溯源与可复现性**：每次运行生成 17 字段 JSON 收据（含输入/输出哈希、容器摘要、验证结果、网络模式等），支持回放与审计。
- **人在回路的质控设计**：面板内编辑创建派生产物和溯源节点，原始结果不被静默修改；图形定制可通过自然语言完成且代码、参数、输出全部留痕。
- **诚实的方法论边界**：作者明确区分"观察到零出站"与"正式隐私证明"、区分时间节省来源（非计算加速）、报告 28 流水线中仅 12 个通过等，叙述客观。

## 8. 不足与局限

- **技能覆盖不足**：当前仅 30+ 技能，远少于 NeuroClaw 的 85 个技能和更广的数据集覆盖。作者认为这是设计起点差异的代价，但客观上限制了开箱即用范围。
- **本地模型能力上限**：7B 本地模型在长上下文推理上弱于前沿云模型，限制单次可规划的请求复杂度；IFEval 下降 5.2 分表明域适应带来一定的通用能力代价。
- **QC-62 规模与统计效力有限**：62 个案例的样本量较小，个别类别仅个位数

- **QC-62 规模与统计效力有限**：62 个案例的样本量较小，个别类别仅个位数（如质量判断类仅 11 例），某些子类结论（如质量判断从 0/11 提升到 7/11）的可推广性存疑；统计检验未做多重比较校正，存在偶然显著的风险。
- **可视化/QC 实验重复次数偏少**：每任务仅 K=3 次重复，且未报告方差或显著性检验，难以排除随机波动；对比的传统 3–4 应用工作流由作者团队手工操作，可能存在操作者熟练度带来的偏差。
- **对比基线不够透明与完整**：Local 27B 未明确具体模型版本；未与当前最前沿通用大模型（如 GPT-4o、Claude 系列）在相同任务上做直接对比，系统级对比也仅针对 NeuroClaw，削弱了“超越 27B 模型”这一结论的绝对性。
- **训练资源与成本信息缺失**：未报告训练所用 GPU 型号、数量、时长与能耗，Q4_K_M 量化的具体推理内存占用也未量化，影响可复现性与部署成本评估。
- **隐私结论仍有边界**：作者虽坦诚区分“观察到零出站”与“正式隐私证明”，但在真实机构环境中，进程级归因不可用、容器内网络行为、DNS 解析等外联通道的完全杜绝尚未被形式化验证；该结论严格限定于特定加固配置与时间窗口。
- **验证层对“形式有效但科学错误”的检测能力有限**：产物验证主要依赖退出码、文件存在性、可解析性和有限领域不变量，无法发现配准方向错误、伪影残留等需要语义判断的问题；这部分仍依赖人工 QC 和模型对定量指标的理解，验证层并未真正闭环。
- **技能生态的长期维护成本未讨论**：30+ 技能的冻结、版本管理、回归测试与人工审批流程会随技能数量增长而带来新的工程负担；大规模队列的并行调度、资源竞争与失败重试策略也未展开。

## 9. 总体评价与适用场景

CyberNeuro 的核心贡献在于**将“大模型驱动的智能体”从演示性质的聊天工具，推进到了具备工程级验证、溯源与隐私约束的生产系统**。它的设计哲学——LLM 负责语义理解和任务分解，确定性组件负责校验和执行，二者之间用明确的验证门隔离——为神经影像分析自动化提供了一个可借鉴的架构范式。其可贵之处在于没有夸大能力：论文清楚地说明了本地 7B 模型在工具选择上并未超越基线、域适应在通用指令遵循上有代价、隐私结论不构成合规证明，这种诚实使结论更可信。

适用场景上，该系统最适合**中大规模多中心队列的标准化预处理**（如 DICOM→BIDS）、**受严格数据治理约束的临床研究**、以及**需要完整溯源与回放能力的可复现分析流水线**。对于需要开放域推理、复杂科学假设探索或极高泛化能力的场景，当前的技能覆盖和 7B 模型上限仍是明显约束。总体而言，这是一篇工程完成度高、评估设计严谨、边界陈述客观的系统论文，其价值不仅在于结果数字，更在于为“可信赖的本地化科学智能体”建立了可复现的构建与评测基线。
