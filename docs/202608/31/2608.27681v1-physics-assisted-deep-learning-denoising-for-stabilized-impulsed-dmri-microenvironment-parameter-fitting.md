## 摘要
扩散加权MRI（dMRI）是量化细胞微环境参数的有力工具。本研究提出了一种基于物理辅助深度学习（DL）的去噪框架，旨在增强dMRI信号质量并提高后续生物物理模型拟合的稳健性。使用IMPULSED-dMRI信号模型生成了由无噪声和受Rician噪声污染的dMRI信号配对组成的数据集。评估了三种去噪架构：卷积神经网络（CNN）、多层感知器（MLP）和长短期记忆（LSTM）网络。然后将去噪后的信号进行拟合，以估计细胞直径$d$、细胞内体积分数$V_{\mathrm{in}}$和细胞外表观扩散系数$D_\mathrm{ex}$。基于DL的处理显著改善了dMRI信号去噪。MLP和LSTM取得了相似的性能，其中LSTM总体上略好，两者均优于CNN。在随后的模型拟合步骤中，LSTM使参数MAE适度降低。主要优势是拟合稳定性，总体拟合失败率从57.6%降至17.7%。所提出的框架改善了dMRI信号质量，并稳定了后续基于IMPULSED的微环境参数拟合。

## Abstract
Diffusion-weighted MRI (dMRI) is a powerful tool for quantifying cellular microenvironment parameters. This study proposes a physics-assisted deep learning (DL)-based denoising framework designed to enhance dMRI signal quality and improve the robustness of subsequent biophysical model fitting. A dataset of paired noise-free and Rician-noise-corrupted dMRI signals was generated using the IMPULSED-dMRI signal model. Three denoising architectures were evaluated: Convolutional Neural Networks (CNN), Multilayer Perceptron (MLP), and Long Short-Term Memory (LSTM) networks. Denoised signals were then fitted to estimate cell diameter $d$, intracellular volume fraction $V_{\mathrm{in}}$, and extracellular apparent diffusion coefficient $D_\mathrm{ex}$. DL-based processing substantially improved dMRI signal denoising. The MLP and LSTM achieved similar performance, with the LSTM slightly better overall, and both outperformed the CNN. In the subsequent model fitting step, the LSTM produced modest reductions in parameter MAE. The dominant benefit was fitting stabilization, with the overall fitting failure rate reduced from 57.6\% to 17.7\%. The proposed framework improves dMRI signal quality and stabilizes subsequent IMPULSED-based microenvironmental parameter fitting.

### 1. 核心问题与整体含义（研究动机与背景）

扩散加权 MRI（dMRI）是一种非侵入性量化细胞微环境参数（如细胞直径、细胞内体积分数等）的有力工具，在肿瘤治疗反应监测中具有重要意义。然而，dMRI 信号固有信噪比（SNR）较低，尤其在高 b 值区域信号衰减严重，噪声干扰会显著降低后续生物物理模型拟合的准确性和稳定性。这一问题在临床 1.5T MRI 系统中尤为突出，因为该场强下净磁化矢量较低，SNR 受限。

针对直接参数映射型深度学习方法存在的可解释性差、易过拟合等问题，本文提出了一种**物理辅助的深度学习去噪框架**：先用深度学习模型去除 dMRI 信号中的噪声，再基于去噪后的信号进行 IMPULSED 生物物理模型拟合，从而在保持物理模型可解释性的同时提升拟合稳健性。

### 2. 方法论：核心思想、关键技术细节与公式

**核心思想**：将"噪声抑制"与"参数估计"两步解耦。深度网络只负责信号去噪，参数估计仍由符合物理规律的 IMPULSED 模型完成，既减少任务复杂度，又保持生物物理可解释性。

**关键技术细节**：

- **信号模型**：采用双室 IMPULSED 模型（包含 PGSE 和 OGSE 两种脉冲序列）生成信号：
  - 总信号：$S(b) = V_{\mathrm{in}} \cdot S_{\mathrm{in}}(b) + (1 - V_{\mathrm{in}}) \cdot S_{\mathrm{ex}}(b)$
  - 细胞内/外信号分别由式(2)-(4)给出，涉及五个微环境参数：$d$、$D_{\mathrm{in}}$、$V_{\mathrm{in}}$、$D_{\mathrm{ex}}$、$\beta_{\mathrm{ex}}$
- **数据生成**：随机采样 100,000 组参数（$d$ = 4–28 μm，$D_{\mathrm{in}}$ = 0.2–3.38 μm²/ms，$V_{\mathrm{in}}$ = 0–100%，$D_{\mathrm{ex}}$ = 0.2–3.38 μm²/ms，$\beta_{\mathrm{ex}}$ = 0–10 μm²），代入方程生成无噪声信号，再添加 Rician 噪声（$\sigma$ = 0.01–0.12，对应 SNR ≈ 8–100）生成配对噪声信号
- **模型输入**：将 PGSE、OGSEn1、OGSEn2 三个序列共 36 个 b 值信号点拼接为一维向量
- **三种去噪架构**：
  - **CNN**：5 层一维卷积（通道数 64→128→256→128→64，核大小 5），批归一化 + ReLU，末端接全连接层
  - **MLP**：4 层全连接（128→64→32→36），ReLU 激活
  - **LSTM**：2 层 LSTM（128→16 通道），取最后隐状态接全连接层
- **训练策略**：L1 损失函数；Adam 优化器，学习率 0.001，batch size 128，最多 500 epochs，以验证集损失最小化选择最终模型
- **拟合设置**：固定 $D_{\mathrm{in}}$ = 1.56 μm²/ms 和 $\beta_{\mathrm{ex}}$ = 0 μm²，使用 Trust Region Reflective 算法拟合 $d$、$V_{\mathrm{in}}$、$D_{\mathrm{ex}}$，参数边界约束在生理合理范围内
- **失败率定义**：任一参数达到边界值则记为拟合失败

### 6. 主要结论与发现

1. **去噪效果**：LSTM 将信号 MAE 从 5.97% 降至 1.58%，MLP 达到 1.60%，CNN 为 1.99%。MLP 与 LSTM 性能接近，二者均优于 CNN。
2. **参数估计精度**：去噪后参数 MAE 适度改善——$d$ 从 5.34 μm 降至 4.02 μm，$V_{\mathrm{in}}$ 从 15.00% 降至 11.96%，$D_{\mathrm{ex}}$ 从 0.77 降至 0.63 μm²/ms。
3. **拟合稳健性（主要收益）**：总体拟合失败率从 57.6% 大幅降至 17.7%；体外实验中，LSTM 将所有参数特异性失败率从 3.2%–20.0% 降至 0%。
4. **体外验证**：LSTM 对 HeLa 细胞 $d$ 的估计与参考值仅差 0.2 μm（0.8%），MC38 系差异也较小；模型能分辨不同离心力导致的 $V_{\mathrm{in}}$ 变化（4.4%–7.2%），表明对微环境变化敏感。
5. **SNR 依赖性**：去噪优势在低 SNR（<30）区域最为显著，SNR > 60 时各方法性能趋于收敛。

### 7. 优点

- **物理辅助数据生成**：直接基于 IMPULSED 生物物理方程生成训练数据，实现"信号-参数"的数学可解释关联，避免了纯数据驱动方法缺乏物理约束的问题。
- **两步法设计**：去噪与拟合解耦，降低了任务复杂度，既有 DL 的噪声抑制能力，又保留传统模型拟合的可解释性。
- **合理的模型对比**：在同一框架下系统比较了 CNN、MLP、LSTM 三种架构，为后续研究提供了架构选择的参考。
- **全面的鲁棒性评估**：覆盖了从 SNR 8 到 100 的宽噪声范围，对低 SNR 区域采用更密集采样，能更真实地评估临床低 SNR 场景。
- **体外实验验证**：在临床 1.5T 扫描仪上验证了方法对真实 MRI 数据的有效性，且通过离心力对比实验证明模型对微环境变化具有敏感性。
- **拟合失败率作为关键指标**：将拟合稳定性作为核心评估维度，比仅关注平均误差更贴近临床实际需求。

### 8. 不足与局限

- **忽略空间信息**：当前是一维模型，逐体素独立处理信号，未利用像素间的空间相关性；在异质性组织中，体素平均可能掩盖特定肿瘤特征。
- **针对特定协议**：模型针对固定的 b 值分布和脉冲序列参数训练，改变采集协议、扫描仪硬件或重建方法后可能需要重新训练，泛化性有限。
- **体外实验仅使用单细胞群**：临床肿瘤微环境包含肿瘤、免疫、基质和血管等多种细胞，混合细胞群中的有效性尚未验证。
- **体外去噪优势偏乐观**：体外实验的拟合稳定性可能受益于受控实验条件和良好图像质量，应谨慎外推至体内场景。
- **噪声模型简化**：合成 Rician 噪声与实际临床噪声分布可能存在差异，虽体外初步验证成功，但需在更多样化的真实数据上进一步验证。
- **MLP 与 LSTM 差异较小**：两者性能接近，使得 LSTM 略优的结论缺乏决定性证据，架构优势的解释属于推测而非明确结论。
