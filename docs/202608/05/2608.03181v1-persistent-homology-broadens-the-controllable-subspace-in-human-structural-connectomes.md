## 摘要
应用于结构连接组的网络控制理论通常根据结构连接强度对大脑区域作为候选驱动节点进行排序，并通过标量控制能量评估性能。我们测试了这种框架是否捕捉了关于驱动节点选择如何塑造脑网络控制的最相关信息。我们引入了一种基于每个节点参与的持续拓扑环的替代标准——这是一种衡量介观尺度整合的指标，捕捉了超越局部连接的特征——并将其与基于度的标准选择在70个人类结构连接组的三种分区尺度上进行了比较。拓扑和度信息驱动的驱动节点集实现了几乎相同的标量控制能量，差异约为0.2%。然而，可控子空间的几何结构差异显著：拓扑信息驱动的集合将可控性分布在状态空间的更多维度上，并产生条件更好的可控性矩阵。这种几何优势在移除高度枢纽节点后仍然保留，并且具有功能特征：由于这两个标准将驱动节点放置在不同的皮层区域，每个标准最有效地达到不同类别的目标状态。因此，节点排序标准的选择决定了哪些脑状态转换在能量上更受青睐，即使平均控制成本不变。结果揭示了控制成本与控制几何之间的分离，并表明持续拓扑捕捉了标量能量摘要所遗漏的关于脑网络控制的信息。

## Abstract
Network control theory applied to structural connectomes typically ranks brain regions as candidate driver nodes by their structural connectivity strength, and evaluates performance through scalar control energy. We test whether this framing captures the most relevant information about how driver-node selection shapes brain network control. We introduce an alternative criterion based on the persistent topological cycles in which each node participates---a measure of mesoscale integration that captures features beyond local connectivity---and compare it to standard degree-based selection across 70 human structural connectomes at three parcellation scales. Topology- and degree-informed driver sets achieve nearly identical scalar control energy, differing by approximately 0.2%. The geometry of the controllable subspace, however, differs substantially: topology-informed sets distribute controllability across more dimensions of state space and produce better-conditioned controllability matrices. This geometric advantage is preserved when high-degree hub nodes are removed, and it carries a functional signature: because the two criteria place driver nodes in different cortical territory, each most efficiently reaches a different class of target state. The choice of node-ranking criterion therefore shapes which brain-state transitions are energetically favored even when average control cost is unchanged. The results reveal a dissociation between control cost and control geometry, and demonstrate that persistent topology captures information about brain network control that scalar energy summaries miss.

## 二、论文提出的方法论：核心思想与关键技术细节

### 1. 核心思想
将驱动节点选择从“能量最小化”转向“几何广度最大化”：优于仅优化平均控制能量的是，选择能更均匀、更广泛地覆盖状态空间方向的驱动集。基于持续同调的循环参与度正好提供了这样一种超越局部度、与介观回路结构相关的排序信号。

### 2. 关键技术与公式流程

- **数据预处理**（每个受试者、每个分区尺度）：
  - 原始结构矩阵 Araw 对称化：Asym = (Araw + Arawᵀ)/2，对角线置零；
  - 权重变换：log(1 + w)；
  - 归一化：A0 = log(1+Asym) / max(log(1+Asym))，元素在 [0,1] 区间；
  - 群体参考矩阵：Ā0 = (1/S) Σ A0^(s)。

- **线性控制模型**：
  - 状态方程：ẋ(t) = A x(t) + B u(t)；
  - A = A0 − (λmax(A0) + c) I，其中 c = 0.1 为稳定化裕度，确保系统稳定；
  - B 按所选驱动节点对应的标准基向量构造（每个驱动节点一个输入）。

- **可控性 Gramian**：
  - 连续 Lyapunov 方程：A W + W Aᵀ + B Bᵀ = 0；
  - 正则化：Wε = W + εI（ε = 10⁻⁵），特征值下限设为 ε。

- **标量控制能量**：Eavg = trace(Wε⁻¹) = Σ λᵢ⁻¹，分析时取 log₁₀。

- **节点排序标准**：
  - 度强度（degree strength）：sᵢ = Σⱼ (A0)ᵢⱼ；
  - 循环参与度（cycle participation）：将 A0 转为距离矩阵 Dᵢⱼ = 1 − (A0)ᵢⱼ（若有边），无边为 1，对角为 0；对 Vietoris–Rips 滤流计算 H1 持续同调（使用 Ripser，启用 cocycle 提取）；对每个有限 H1 特征 f，持久性 = d_f − b_f；节点参与度 = 对包含该节点的 cocycle support 的所有特征求和；最后在受试者内 min-max 归一化。

- **控制几何指标**（对 Gramian 特征谱的三个互补度量）：
  - **有效秩**：r_eff = exp(−Σ pᵢ ln pᵢ)，其中 pᵢ = λᵢ / Σⱼ λⱼ，衡量可控性在特征方向上的分布广度；
  - **参与比**：PR = (Σ λᵢ)² / Σ λᵢ²，另一种谱展宽度量；
  - **条件数**：κ(Wε) = λmax/λmin，取 log，衡量可控子空间的各向异性/病态程度。

- **目标态最小能量转移**：对给定目标态 x*，E_target(x*) = x*ᵀ Wε⁻¹ x*。

- **排序对齐与相对能量**：ΔE = log₁₀ E_topology − log₁₀ E_degree（正值表示拓扑排序劣势），并与受试者内 Spearman 秩相关（度排序 vs 循环参与度排序）进行关联。

- **集级控制景观分析**：对固定规模的驱动集（k ∈ {1,2,3,5}），枚举所有集合（可行时）或抽样 5,000 个集合，计算 log₁₀ Eavg 的方差和四分位距（IQR），以刻画能量景观的退化和宽度。

- **枢纽破坏分析**：按度排序移除 top 5、10、15 个节点，在剩余节点中按完整网络的排序选择驱动集，在完整与受损网络中评价同一组驱动节点的 Gramian 指标，计算指标下降量。

- **目标态构造**：从“集中式”到“分布式”排列：
  - 集中端点：四个双侧解剖学标志（V1/距状皮层、M1/中央前回、后扣带回/楔前叶、外侧前额叶），加上所有皮质单节点目标；

## 六、论文的主要结论与发现

1. **拓扑与度排序的空间重叠但非等同**：循环参与度与度强度 Spearman 相关约 0.61–0.75（各尺度），但存在显著离散性；两类排序在皮层分布上强调不同区域——度排序偏向转模态/联合皮层，循环参与度偏向单模态/视觉皮层（与主皮层梯度的负相关支持此解读）。
2. **标量能量的近等价性**：拓扑与度驱动集在平均控制能量上差异仅约 0.2%（对数尺度约 10⁻³），在 68 区域甚至统计上不显著，在 114、219 区域有微小但可检测的劣于度的趋势。
3. **能量景观随尺度增加而退化**：从 68 到 219 区域，候选驱动集的平均能量方差和 IQR 单调下降；在 219 区域节点身份几乎不再影响标量能量。在匹配比例（约 5% 网络）条件下仍复现（96.17% → 99.74% → >99.99% 集合落在最优能量 5% 内）。
4. **拓扑驱动集具有更广的控制几何**：在有效秩（+0.80~+0.98）、参与比（+0.90~+1.11）和 log 条件数（−0.50~−0.64）上均显著优于度驱动集，且在所有尺度方向一致（70 名受试者几乎全部为正向差异）。
5. **枢纽损伤后有韧性**：移除 top 5/10/15 度枢纽后，度驱动集的有效秩损失 0.24–0.32，而拓扑驱动集损失约 −0.05~−0.11；在 36 个比较中 32 个（有效秩）和 26 个（参与比）显著更优。两种方法在能量退化上无差异。
6. **目标态特异性优势**：循环参与度驱动集在 V1 和枕叶模块目标上更节能（最高约 −10%），度驱动集在 M1、联合皮层模块、后扣带回/楔前叶目标上更节能；均匀皮层激活在精细尺度上偏向循环参与度，梯度目标则无净优势。
7. **核心理论贡献**：控制成本与控制几何的分离首次在结构连接组的驱动节点选择层面得到系统证明；持续拓扑提供了标量能量总结遗漏的关于脑网络控制组织的信息。

- **统计严谨性**：受试者级配对比较、非参数检验、多家族 Holm 校正、FDR 校正等，统计报告翔实；稳健性分析覆盖正则化、稳定化、有限时域、代表元选择等多个关键自由度。
- **机制指向明确**：目标态实验将几何差异与皮层功能地形联系起来，形成“驱动节点放置→可控方向分布→特定目标态能量优势”的完整逻辑链。
- **对实际应用的启发**：枢纽损伤模拟与神经退行/局灶损伤文献对应，揭示了基于度排序驱动集在病变下的脆弱性，为脑刺激靶向和恢复策略提供了新视角。

## 八、不足与局限

- **线性模型的强假设**：使用线性时不变系统 + 稳定化结构邻接矩阵作为状态转移算子，可能无法完全捕捉真实神经动力学的非线性（尽管论文引用文献支持宏观线性近似，但该假设仍有待更严格检验）。
- **结构连接重建的可靠性问题**：扩散纤维追踪存在假阳性流线、距离依赖偏差、算法间变异性等已知局限；矩阵被强制对称化处理，丢失了通路方向性信息，可能影响拓扑环检测的真实性。
- **持续同调代表元的非规范性**：cocycle representatives 依赖具体算法与索引约定，循环参与度有一定实现依赖性；论文承认该问题并做了多种代表元约定的稳健性检查，但不同约定下效果幅度差异明显（cocycles 优势最大，测地线循环优势最小），说明该指标对代表元选择的敏感性仍需更深入的理论解释。
- **损伤模拟过于理想化**：枢纽移除是简单节点删除，而真实病变（卒中、神经退行）通常空间受限、影响白质而非灰质节点、并引发网络重构，而非单纯删除。论文明确将结果定性为“proof of principle”，但向临床情境的推广仍需谨慎。
- **未进行活体验证**：功能层面的预测（如视觉状态转换能力差异）缺乏 HCP 任务 fMRI 或静息态流形几何的直接实证支持，仅停留在模型预测层面。
- **关于标量能量景观退化的机制解释不足**：论文指出了能量景观在精细尺度下的压缩现象，但未给出该现象的正式数学推导或理论解释。
- **计算可扩展性问题**：Ripser 持续同调在更大图（更高分区尺度）上的计算复杂度、内存占用和耗时未加讨论，限制了方法在高分辨率连接组上的直接应用。
- **因果机制未被建立**：论文的拓扑-几何关系是关联性的，未提供从 Vietoris–Rips 滤流结构到 Lyapunov Gramian 特征谱的正式理论桥梁，作者也承认这一点是未来工作方向。
