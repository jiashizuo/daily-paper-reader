## 摘要
从大脑信号中解码视觉信息，能够探究神经表征，并实现神经康复和梦境解码。最近的脑到图像检索方法已取得有前景的性能，通常通过对每张图像平均多达80次神经试次来实现，这需要重复呈现刺激，从而增加了延迟、成本和用户负担。当只有一次或少数几次重复可用时，检索准确率急剧下降。这种下降通常归因于查询噪声，因为平均抑制了噪声并增强了信号稳定性。然而，我们发现了一种非传递性对齐模式：低重复查询信号和图像表征各自与高重复中心对齐，但彼此之间并不直接对齐。这一模式表明，查询噪声只是问题的一部分，而候选集的布局也会影响检索。因此，我们提出了一种基于神经锚点的检索（NEAR）框架，将高重复中心视为锚点，并从两侧接近它：一个去噪器将噪声查询拉向真实锚点，一个小型网络从每个候选者的图像预测其伪锚点，并将图像拉向该伪锚点。在跨越脑电图（EEG）、脑磁图（MEG）和功能性磁共振成像（fMRI）的四个数据集上，NEAR在少重复情形下持续改善了检索性能。在THINGS-EEG2上，当分别平均一次和四次重复时，它将200路Top-1准确率分别提高了5.7和9.3个百分点。通过锚定神经和视觉表征，NEAR减少了对重复采集的依赖，使神经检索更加接近实际应用。

## Abstract
Decoding visual information from brain signals probes neural representations and enables neuro-rehabilitation and dream decoding. Recent brain-to-image retrieval approaches have achieved promising performance, typically by averaging many (up to 80) neural trials per image, requiring repeated stimulus presentation that increases latency, cost, and user burden. When only one or a few repetitions are available, the retrieval accuracy drops sharply. This drop is commonly attributed to query noise because averaging suppresses noise and increases signal stability. However, we find a non-transitive alignment pattern: the low-repetition query signal and the image representation each align with the high-repetition center, but not directly with each other. This pattern shows that query noise is only part of the problem and that gallery placement also affects retrieval. We therefore propose a neural-anchor-based retrieval (NEAR) framework that treats the high-repetition center as an anchor and approaches it from both sides: a denoiser pulls the noisy query toward the true anchor, and a small network predicts each candidate's pseudo anchor from its image and pulls the image toward it. Across four datasets spanning EEG, MEG and fMRI, NEAR consistently improved retrieval in the few-repetition regime. On THINGS-EEG2, it improved 200-way Top-1 accuracy by 5.7 and 9.3 percentage points respectively, when averaging one and four repetitions. By anchoring neural and visual representations, NEAR reduces reliance on repeated acquisition and brings neural retrieval closer to real-world deployment.

## 2. 方法论与技术细节

### 2.1 核心思想

提出 **NEAR（Neural-Anchor-Based Retrieval，基于神经锚点的检索）** 框架：将高重复稳定神经表征 ¯q_c 作为共同锚点，从查询和候选图像两侧同时向锚点靠拢，以改善少重复检索。

### 2.2 适配器与关键公式

- **问题设定**：k次平均后的查询为 q_c^(k) = f_θ((1/k)Σx_{c,i})，稳定锚点 ¯q_c 由高重复参考集估计得到。
- **受控目标交换分析**：比较三条路径的准确率——少重复查询→图像（直接）、少重复查询→稳定锚点、稳定锚点→图像。发现少重复查询能较准地检索到稳定锚点，但直接检索图像却不稳定，形成“非传递”现象。
- **两两检索条件分解**（式2）：正确图像c对竞争者j的得分优势可分解为
  (q_c^(k))^T(v_c−v_j) = ¯q_c^T(v_c−v_j) + (ε_c^(k))^T(v_c−v_j)
  第一项为稳定画廊余量（gallery margin），第二项为查询误差的干扰。
- **充分条件**（式3）：若查询误差范数 ∥ε_c^(k)∥₂ < ρ_c = min_j γ_cj/∥v_c−v_j∥₂（ρ_c为画廊容差），则可保证正确排序。
- **Query Anchoring（查询锚定）**：使用 Noise2Noise 自监督去噪器（损失 L_N2N = ∥a_ϕ(x_{c,a})−x_{c,b}∥²，用独立噪声的两次重复互相预测），再与神经编码器联合用对称对比损失 L_con 训练；对低SNR数据集（如Alljoined）改用固定小波阈值去噪，目标与流程保持一致。
- **Gallery Anchoring（画廊锚定）**：冻结神经和视觉编码器，训练图像到神经的预测器 g_ψ（默认MLP，2,048隐藏单元），损失为余弦回归 L_G = 1−cos(h_c, ¯q_c)，为每个候选图像预测伪锚点 h_j。
- **推理打分**（式6）：
  s_β(˜q_c^(k), j) = (1−β)·cos(˜q_c^(k), v_j) + β·cos(˜q_c^(k), h_j)
  默认 β=0.75；β=0退化为标准视觉画廊检索。
- **训练顺序**：先训练Query Anchoring并冻结，再训练Gallery Anchoring；可接受任意重复次数。

## 6. 主要结论与发现

- **非传递模式是少量重复性能下降的关键原因**：少重复查询与图像各自都能匹配稳定神经中心，但彼此不能直接可靠对齐；该模式证明画廊放置和查询噪声同样重要。
- **NEAR框架显著改善少重复检索**：在THINGS-EEG2上，200路Top-1在k=1和k=4时分别提升5.7（14.0→19.8）和9.3（43.2→52.5）个百分点；10名被试全部受益。
- **两分支互补**：Query Anchoring在极低重复时贡献最大（此时查询误差大）；Gallery Anchoring在查询渐稳后贡献更大（通过提升稳定画廊余量），二者结合覆盖整个重复数谱系。
- **画廊侧错误具有跨模态普遍性**：Gallery Anchoring在EEG、MEG、fMRI上一致有效，且对四种不同查询估计器均有增益；NSD上CLIP和FARE两种视觉目标的Top-1分别从27.5%提升至39.4%（k=1）和从56.8%提升至74.3%（k=3）。
- **机制验证**：增加画廊容差 ρ_c 可纠正51.0%原本在稳定锚点处仍然错误的排序，签名余量均值从0.008提升至0.050，12个参与者–种子组合全部上升，证实伪锚点通过改善画廊排序起作用。

## 7. 优点与亮点

- **问题诊断深入**：通过目标交换实验暴露非传递模式，打破“少重复下降=查询噪声”的简单归因，并给出统一的理论解释（两两检索条件分解与画廊容差充分条件）。
- **对称化思路新颖**：不是仅做查询去噪，而是同时修正查询端与画廊端，使两侧共同收敛到同一神经锚点，方法论具有普适性。
- **公式推导严谨**：式(2)–(3)结合Cauchy-Schwarz给出了可判定的充分条件，将经验观察置于可验证的理论框架中。
- **实现简洁、兼容性好**：去噪器可用Noise2Noise也可用小波阈值；画廊预测器可用MLP、岭回归或InfoNCE，且预测器复杂度不高也能保持大部分增益；与xDAWN、DSS等经典估计器兼容。
- **实验设计规范、控制严谨**：三种子均值±标准差、固定β、每次只改变一个组件、对关键发现做了负对照验证，结论可靠性较高。
- **实际价值突出**：明确以ITR峰值k=2的少重复区间为优化目标，直接回应了重复采集成本高的应用痛点。

## 8. 不足与局限

- **对配对训练数据的依赖**：NEAR需要脑–图像配对数据来训练锚定组件；在缺乏配对数据的新领域难以直接应用。
- **被试特异性问题**：伪锚点为参与者特异，跨被试、跨会话的迁移和适配没有充分讨论与验证。
- **完整NEAR在非EEG模态未验证**：MEG和fMRI上仅验证了Gallery Anchoring分支，Query Anchoring与完整NEAR的跨模态表现仍然是开放问题。
- **计算资源未披露**：缺少GPU型号/数量/训练时长等，难以评估训练部署成本，影响可复现性和实际落地参考。
- **低SNR增益有限**：Alljoined上虽然一致提升，但绝对增益偏小，对极低信噪比场景的改善幅度有限。
- **超参数固定可能非最优**：β在所有数据集和重复水平上固定为0.75，没有验证自适应调优是否能进一步改善；不同模态最优β可能不同。
- **生理信号种类有限**：数据集虽涵盖EEG/MEG/fMRI，但缺乏对侵入性信号（如ECoG）或近红外（fNIRS）等其他模态的考察。
- **少重复准确率仍不理想**：即使在改进后，k=1、k=4的绝对准确率距离高重复基线仍有明显差距，“少重复=高可用”的目标还远未达成。
