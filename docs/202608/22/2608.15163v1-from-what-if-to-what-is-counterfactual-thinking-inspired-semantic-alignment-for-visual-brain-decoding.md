## 摘要
视觉脑解码通过fMRI等神经测量重建人感知的视觉内容，为研究大脑如何表示视觉信息提供了一种计算方法。近年来的多模态表示和扩散先验提高了重建的真实感。然而，视觉上合理的重建可能包含不正确的对象、属性或关系，因为强大的生成先验可以补全解码表示未充分指定的内容。传统的重建指标主要评估最终图像，因此可能掩盖此类语义错误。我们提出了ConceptAlign，一种用于视觉脑解码的反事实语义对齐框架。ConceptAlign汇集解码的视觉标记并将它们投影到冻结的文本嵌入空间中，将表示与真实标注对齐，同时将其与保留场景的近似错误替代方案区分开来。这些替代方案由LLM离线生成，修改一个关键对象、属性或关系，同时保留场景。基于边界的目标学习观察刺激与合理但不正确解释之间的细粒度语义边界，在推理过程中无需调用LLM。我们引入了一个系统的三级语义评估框架，涵盖基础判别性、反事实描述判别和表示几何。在自然场景数据集上的实验表明，ConceptAlign相比MindEye2主干提高了重建度量、反事实语义判别和表示对齐。匹配的负样本消融、独立的LLM和人工编写的替代方案以及人类评估支持了监督的有效性和鲁棒性，在细粒度冲突、有限数据解码和跨主体结构方面表现出有利的模式。

## Abstract
Visual brain decoding reconstructs visual content perceived by a person from neural measurements such as fMRI, providing a computational approach to studying how visual information is represented in the brain. Recent multimodal representations and diffusion priors have improved reconstruction realism. However, visually plausible reconstructions may contain incorrect objects, attributes, or relations because a strong generative prior can complete content not sufficiently specified by the decoded representation. Conventional reconstruction metrics mainly assess the final image and may therefore obscure such semantic errors. We propose ConceptAlign, a counterfactual semantic alignment framework for visual brain decoding. ConceptAlign pools decoded visual tokens and projects them into a frozen text-embedding space, aligning the representation with the ground-truth caption while separating it from scene-preserving near-miss alternatives. Generated offline by an LLM, these alternatives modify one critical object, attribute, or relation while retaining the scene. A margin-based objective learns fine-grained semantic boundaries between the observed stimulus and plausible but incorrect interpretations without requiring LLM calls during inference. We introduce a systematic three-level semantic evaluation framework covering foundational discriminability, counterfactual description discrimination, and representational geometry. Experiments on the Natural Scenes Dataset show that ConceptAlign improves reconstruction measures, counterfactual semantic discrimination, and representational alignment over the MindEye2 backbone. Matched negative-source ablations, independent LLM and human-written alternatives, and human evaluation support the effectiveness and robustness of the supervision, with favorable patterns in fine-grained conflicts, limited-data decoding, and cross-subject structure.

## 1. 论文的核心问题与整体含义

- **背景与动机**：视觉脑解码旨在通过 fMRI 等神经测量重建人正在感知的视觉内容。近年来，扩散模型与 CLIP 等多模态预训练表示显著提升了重建图像的视觉真实感与语义连贯性，代表性方法包括 MindEye2、MindBridge、NeuroPictor 等。
- **核心问题**：视觉上逼真的重建结果可能仍然包含**错误的物体、属性或关系**。由于生成先验过强，重建系统可以在解码表示未充分指定内容时自动“脑补”出连贯但语义错误的细节，导致重建图像在视觉上看似合理、却在语义层面偏离真实刺激。
- **传统指标的缺陷**：现有评估主要关注最终重建图像的质量（如 PixCorr、SSIM、CLIP 相似度等），而这些指标无法暴露生成先验引入的语义错误，甚至可能掩盖它们。
- **核心立意**：借鉴认知科学中“反事实思维”（counterfactual thinking）的概念——即人类通过将当前观察与“可能但错误”的替代解释作比较来理解场景——作者提出：视觉脑解码器不仅需要匹配“实际是什么”（What-Is），还应学会拒绝“假设会怎样”（What-If）的近似错误描述。

## 2. 论文提出的方法论

### 整体框架：ConceptAlign
- 以 **MindEye2** 作为骨干模型（subject-specific ridge regression + 共享视觉 token 生成器 + 扩散先验 + 低层重建分支）。
- 在骨干之上新增一个**反事实语义对齐分支**，不替换原有的检索、扩散先验和低层重建目标。

### 核心思想
- 将解码得到的视觉 token 池化后，通过一个轻量可学习投影器映射到**冻结的文本嵌入空间**。
- 在文本空间中，使解码表示与**正确描述（ground-truth caption）** 对齐，同时与**“场景保留但语义错误”的近似负样本**拉开距离，从而学习细粒度的语义边界。

### 关键技术细节

**（1）反事实负样本的离线构造**
- 从每张图的 COCO 标注出发，使用 LLM 离线生成候选反事实描述。
- 每次只修改一个关键语义要素：物体身份、属性（颜色/材质/数量/大小/年龄）或关系（空间/动作关系），且必须保留整体场景不变。
- 通过固定过滤规则（长度比、词集 Jaccard 重叠、禁止显式否定词）筛选，再按与正样本的余弦相似度在固定区间 `[0.15, 0.85]` 内选取 Top-K 作为最终负样本。
- 平均正负样本余弦相似度约为 **82.00% ± 5.00%**，确保是“近似错误”而非容易被区分的无关负样本。

**（2）损失函数**

*全局语义对齐损失（L_align）*：批内对比学习，拉近解码表示与其对应正样本描述，拉远与其他描述。

*反事实边界学习损失（L_reason）*：margin-ranking loss——
```
L_reason = (1/|B|) Σ max(0, m − sim(t̂, t+) + sim(t̂, t−))
```
要求解码表示与正样本的相似度至少比与反事实负样本高出边界 m（实验中 m=0.1 最优）。

*总损失*：
```
L_total = λclip·Lclip + λprior·Lprior + λblur·Lblur + λtext·(Lalign + γ·Lreason)
```

**（3）训练流程**
- 先以原始 MindEye2 目标预训练骨干。
- 微调时先固定重建分支、训练 ConceptAlign 建立文本空间映射；再引入反事实负样本，联合优化可训练部分。
- **推理时无需调用 LLM**，不增加推理开销。

**（4）三级语义评估框架（自提出）**
- **L1 基础判别性**：双向检索 Top-K、2AFC 二选一准确率。
- **L2 反事实描述判别（CCD-hard）**：测试解码表示能否在正确描述与场景保留的近似错误替代描述之间做出正确选择。
- **L3 表征几何（RSA）**：通过表征相似性分析比较解码表示与被试/刺激的成对几何结构。

## 6. 论文的主要结论与发现

- **重建质量提升有限但积极**：在 Subject 01 上，ConceptAlign 相比 MindEye2 将 PixCorr 从 37.4% 提升至 39.3%、SSIM 从 43.9% 提升至 44.5%、AlexNet-5 从 99.1% 提升至 99.3%、Inception 从 96.15% 提升至 96.3%、SwAV 从 33.8% 降至 32.0%（越低越好），而 AlexNet-2 与 CLIP 基本持平或略降。表明额外语义约束与重建质量兼容。
- **语义判别显著增强**：CCD-H 从 62.3% 提升至 63.7%（4 被试平均），2AFC-B2I 保持 98.4% 的高位。

- **有限数据下更有效**：在 1 或 2 个 session 的训练数据下，ConceptAlign 与基线差异最明显，说明反事实监督在数据稀缺时尤为有价值；40 sessions 全量数据下差距缩小。
- **负样本源影响显著**：随机与 CLIP-nearest 负样本虽然也有正样本对齐，但无法提供细粒度语义边界；反事实负样本在 2AFC-B2I、RSA、PixCorr 和 AlexNet 特征上一致胜出。

## 7. 优点

- **问题切入精准**：直指视觉脑解码中“视觉真实 ≠ 语义正确”这一尚未被充分重视的核心矛盾，并以认知科学中的反事实思维为设计灵感，动机自然且有理论支撑。
- **方法简洁有效**：不改变骨干结构、不增加推理成本（LLM 仅离线使用），仅通过训练中加入语义对齐分支即获得一致收益，实用性高。
- **负样本设计巧妙**：场景保留的“近缺失”负样本（仅改一个关键语义要素）恰好针对生成先验“脑补”错误的弱点，相比随机负样本或 CLIP 最近邻负样本更有语义针对性。

- **数据效率分析有洞察**：发现反事实监督在小数据场景下收益最大，具有实际指导意义。

## 8. 不足与局限

- **改进幅度整体有限**：主要指标（CCD-H +1.35pp、2AFC 持平）提升幅度不大，部分指标（AlexNet-2、CLIP）甚至略有下降，说明反事实监督是一种微调式的改进，而非范式级别的突破。
- **检索结果存在不一致性**：补充材料中多被试检索结果显示 ConceptAlign 在某些被试/方向上（如 S05、S07 的 F@1/F@5/B@1/B@5）明显低于 MindEye2，但正文未充分讨论这一负面发现，存在选择性报告的风险。
- **数据覆盖有限**：仅在 NSD 单一数据集上验证，未覆盖其他脑解码基准或不同刺激模态（如视频、想象场景等），泛化性有待验证。
- **负样本构造依赖 COCO 标注**：909/8,946 的受控样本比例说明大多数训练样本没有文本监督，监督信号覆盖不完整；对无人工标注的数据集，方法需要额外的标注成本。
- **伪影源于负样本质量**：LLM 生成的负样本质量虽经人工审计，但“场景保留”仍有一定主观性（审计一致率约 75%~83%），低质量负样本可能引入错误的语义边界。
- **未完全消除生成幻觉**：方法只是在表示层面增加了语义判别压力，并未直接控制扩散生成过程；论文也承认定性示例仅展示差异而非统计频率。
- **跨被试分析缺少与更多基线的比较**：IS-RSA 仅与 MindEye2 自身对比，未与其他重建方法或随机基线做对照。
- **未提供完整代码或可复现细节的在线资源链接**，复现成本较高。
