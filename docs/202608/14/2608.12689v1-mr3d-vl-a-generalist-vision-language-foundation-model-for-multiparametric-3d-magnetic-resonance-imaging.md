## 摘要
多参数磁共振成像（mpMRI）是脑肿瘤诊断与治疗的基石，然而当前的AI模型面临关键局限：缺乏自然语言交互与可解释性，阻碍了临床上所需的时空信息整合与跨模态推理。主要挑战源于不同模态间显著的物理意义差异、扫描间隔导致的空间错位，以及在胶质瘤分级等任务中进行复杂多特征解读的需求。尽管视觉语言模型（VLM）在跨模态理解方面展现出潜力，现有方法主要聚焦于2D图像建模，忽视了3D体素空间的直接感知。尽管已有3D VLM被提出用于3D CT成像中的报告生成与特征对齐，但mpMRI应用要求跨多种成像模态的协同推理——这一需求目前尚无解决方案能够满足。为此，我们提出Mr3D-VL，一个专为多参数3D MRI设计的视觉语言基础模型。该模型拥有40亿参数，采用无监督预训练的共享3D编码器和4D旋转位置嵌入，实现双模态-空间整合。其跨模态投影层采用多分辨率特征植入策略，以增强跨分辨率的特征感知。实验结果表明，在文本生成任务中，该模型相较于现有的4B/7B/30B领域专用及通用模型均有显著提升，报告生成的BERTScore达到0.856，问答准确率为0.713，多项选择准确率为0.912。

## Abstract
Multi-parametric magnetic resonance imaging (mpMRI) is a cornerstone for brain tumor diagnosis and treatment, yet current AI models face critical limitations: their lack of natural language interaction and interpretability impedes spatial information integration and cross-modal reasoning required clinically. Key challenges arise from significant physical meaning differences across modalities, spatial misalignment due to scan intervals, and the need for complex multi-feature interpretation in tasks like glioma grading. While visual-language models (VLMs) show promise in cross-modal understanding, existing methods focus mainly on 2D image modeling, neglecting direct perception of 3D volumetric space. Although 3D VLMs have been proposed for report generation and feature alignment in 3D CT imaging, mpMRI applications demand collaborative inference across multiple imaging modalities-a requirement unmet by current solutions. To address this, we introduce Mr3D-VL, a dedicated visual-language foundation model for multi-parametric 3D MRI. With 4 billion parameters, it employs an unsupervised pre-trained shared 3D encoder and 4D rotational positional embedding for dual modality-spatial integration. Its cross-modal projection layer uses a multi-resolution feature implantation strategy to enhance feature perception across resolutions. Experimental results show significant improvements over existing 4B/7B/30B domain-specific and general-purpose models in text generation tasks, achieving a BERTScore of 0.856 for report generation, with question-answering accuracy at 0.713 and multiple-choice accuracy at 0.912.

### 一、核心问题与研究动机

- **背景**：多参数磁共振成像（mpMRI）是脑肿瘤诊疗的基石，临床诊断正从单纯病灶检测转向需要自然语言交互、可解释空间信息表示的智能化分析。
- **核心痛点**：
  - 现有 AI 模型缺乏自然语言交互与可解释性，无法直接回答医生关于肿瘤空间特征、模态间关联及临床意义的查询；
  - 不同 MRI 模态（T1、T2、DWI、FLAIR等）物理含义差异大，需要理解各模态的临床价值；
  - 不同模态扫描时间不同，患者运动导致空间错位；
  - 胶质瘤分级等任务需要综合 T2-FLAIR 错配征、ADC 值、rCBV 灌注参数等多模态特征的复杂跨模态推理。
- **现有方法局限**：
  - 多数 VLM 聚焦 2D 图像；部分 3D VLM（如 Hulumed）仅针对 CT，无法处理多模态协同诊断；
  - mpLLM 使用特征池化融合多模态特征，存在信息丢失和无法解决空间错位的问题；
  - 将 3D 数据切为 2D 切片的方式破坏体素空间关系、导致 token 数量激增。

### 二、方法论与关键技术

**整体架构**：通用视觉语言框架，由 3D 视觉编码器（MedNext）、MLP/Transformer 跨模态投影层、大语言模型（Qwen3-4B-Instruct）三模块构成，共 40 亿参数。

**四大核心创新**：

1. **共享 3D 编码器 + 无监督预训练**
   - 采用 MedNext（ConvNeXt3D + UpKern + 复合缩放）作为所有模态共用的编码器；
   - 通过 Dino-v2 架构做无监督预训练，无需任何文本标注或图像-文本配对，降低对稀缺医学标注的依赖；
   - 模态无关设计避免了 mpLLM 中按模态分配独立专家导致的编码器解耦和信息碎片化。

2. **4D 旋转位置编码（4D-RoPE/M3RoPE）**
   - 将位置嵌入分解为时间、深度、高度、宽度四个维度；
   - 文本 token 的四维 ID 相同，等效于传统 1D RoPE；3D 体数据 token 则在深度/高度/宽度上分配唯一位置 ID；
   - 保持 3D 体数据的原生空间关系，避免 2D 切片堆叠带来的 token 爆炸和空间信息破坏。

3. **多分辨率视觉 Token 植入策略**
   - 从视觉编码器的金字塔特征提取架构中同步提取低、中、高分辨率特征图；
   - 投影模块中的 ViT 通过跳跃连接逐级融合（受 U-Net 解码器启发），再在不同的 LLM 层中渐进式植入各分辨率 token；
   - 既保留全局解剖结构信息，又保留局部病理细节，适配医学影像中不同尺度病灶的识别需求。

4. **LLM 驱动的数据生成流水线**
   - 解构影像报告，按模态、解剖区域、分割/检测结果、空间认知四个维度重组生成数据；
   - 利用 LLM 重写文本以增强逻辑连贯性和语义丰富度，并融入外部医学知识；
   - 引入标签（如 bounding box 标记）实现病灶与组织的空间锚定，自动生成开放式/闭合式问答对。

**训练流程**：
- 预训练分三阶段：S0（仅训练投影层，单模态简短文本）、S1（全参数解冻，单模态）、S2（全参数，混合模态），各阶段约 10 亿 token；
- 后训练为 SFT，面向报告生成、开放式问答、多项选择三类任务，约 30 万样本。

### 三、实验设计与基准

**数据集**：内部收集的非公开脑 mpMRI 数据集，共 103,605 例、460,541 张图像，平均每例 4.4 个模态，覆盖 8 种常用 MRI 模态；预处理后以 [32, 192, 192] 尺寸输入模型。按病例划分测试集，确保测试数据在训练中完全不可见。

**任务与基准**：
- **报告生成任务**：以影像报告为题，评估模型生成完整结构化报告能力；
- **开放式问答（VQA）**：1 万测试样本，生成式回答 + 外部 LLM 裁判判定正确性；
- **多项选择问答**：1 万测试样本，确定性判定准确率。

**对比模型**：
- 通用 VLM：Qwen3.5-4B / 27B / 35B；
- 医学 VLM：Hulu-Med-7B、Lingshu-7B；
- 对于不支持 3D 的模型，将 3D 体数据切片为 2D 序列进行多图评估。

**评价指标**：BLEU-4、ROUGE-L、BERTScore、METEOR、CIDEr、RadGraph-F1。

**主要结果**：
