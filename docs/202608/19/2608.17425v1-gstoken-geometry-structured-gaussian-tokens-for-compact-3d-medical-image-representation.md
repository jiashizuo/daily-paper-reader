## 摘要
多模态MRI的有效分割对于提高脑肿瘤识别中神经网络的准确性至关重要。现有方法通常通过固定块编码或学习的注意力池化（如TokenLearner）将三维体积压缩为标记序列。然而，这些压缩方案丢弃了显式的空间形状信息；所得标记不传达病变形态或空间范围的概念。同时，端到端评估将分词器的信息保留与下游解码器的重建能力纠缠在一起，且不同方法间缺乏统一的能力约束，使得性能差异难以归因。在本文中，我们首次将高斯标记引入多模态脑肿瘤分割：每个标记不仅携带语义特征，还携带学习到的三维中心、各向异性尺度和方向，以可忽略的参数成本赋予表示显式的几何支持。我们进一步提出了一种冻结标记效用评估协议：训练好的分词器被冻结，其输出被转换为固定容量的序列化契约，一个共享的轻量级Transformer探针在严格匹配的条件下独立测量每个分词器保留的信息。多种子配对统计检验表明，在冻结探针下，GSToken在容量匹配的自适应基线上持续且显著地优于对手，在所有肿瘤子区域、表面和距离指标上均具有一致优势。这些结果表明，在标记中显式编码空间几何显著提高了体积表示的信息密度，为紧凑三维医学图像表示和下游读取提供了新的设计原则。

## Abstract
Effective segmentation of multi-modal MRI is central to improving neural network accuracy in brain tumor recognition. Existing methods typically compress 3D volumes into token sequences via fixed patch encoding or learned attention pooling (e.g., TokenLearner). However, these compression schemes discard explicit spatial shape information; the resulting tokens convey no notion of lesion morphology or spatial extent. Meanwhile, end-to-end evaluation entangles a tokenizer's information retention with the reconstruction capacity of the downstream decoder, and the lack of a unified capacity contract across methods makes performance differences difficult to attribute. In this paper, we introduce Gaussian tokens to multi-modal brain tumor segmentation for the first time: each token carries not only a semantic feature but also a learned 3D center, anisotropic scale, and orientation, endowing the representation with explicit geometric support at negligible parameter cost. We further propose a frozen-token utility evaluation protocol: the trained tokenizer is frozen, its output is cast into a fixed-capacity serialized contract, and a shared lightweight Transformer probe independently measures each tokenizer's retained information under strictly matched conditions. Multi-seed paired statistical testing shows that GSToken consistently and substantially outperforms capacity-matched adaptive baselines under frozen probing, with uniform advantages across all tumor sub-regions, surface, and distance metrics. These results demonstrate that explicitly encoding spatial geometry within tokens significantly improves the information density of volumetric representations, offering a new design principle for compact 3D medical image representation and downstream reading.

- 三维 MRI 是脑肿瘤诊断与治疗计划的重要依据，但体素级 Transformer 分割模型需要将密集三维体积压缩为 token 序列，直接体素化会导致序列过长而无法计算。
- 现有 token 化方法主要有两类：  
  - **固定网格 patch token**（如 ViT、TransUNet、UNETR）：简单均匀，但几何结构与病灶形态脱节，小尺寸或各向异性结构（如增强肿瘤边界）容易被稀释。  
  - **学习式自适应 token**（如 TokenLearner、Perceiver）：通过注意力池化提升灵活性，但生成 token 不携带显式三维空间位置、范围或方向，缺乏空间支撑。
- 更深层的问题是**评估协议缺陷**：端到端评价将 tokenizer 的信息保留能力与下游解码器的重建能力混在一起，且不同方法间没有统一容量契约，导致性能差异难以归因。
- 3D Gaussian Splatting（3DGS）在场景建模中展现出强大的显式空间表达能力，但尚未被用作面向分割任务的通用 token 表示。本文首次将高斯 token 引入多模态脑肿瘤分割，并设计严格的容量匹配评估协议来隔离 tokenizer 本身的效用。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：每个 token 不仅包含语义特征，还携带显式的三维空间几何属性（中心、各向异性尺度、旋转方向），从而在固定 token 预算下保留更多与病灶形态和空间范围相关的信息。
- **Gaussian token 表示**：  
  每个 token 定义为五元组 \(g_i = (\mu_i, s_i, R_i, \alpha_i, t_i)\)，其中：  
  - \(\mu_i \in [-1,1]^3\)：高斯中心；  
  - \(s_i \in \mathbb{R}^3_+\)：各向异性尺度；  
  - \(R_i \in SO(3)\)：旋转矩阵（由四元数归一化得到，不额外存储）；  
  - \(\alpha_i \in (0,1]\)：重要性调制因子；  
  - \(t_i \in \mathbb{R}^C\)：内容特征。
- **空间支撑定义**：位置 \(v\) 与 token \(i\) 的兼容性由各向异性高斯对数权重决定：  
  \[
  \ell_{iv} = -\frac{1}{2} \left\| R_i^\top (x_v - \mu_i) \oslash s_i \right\|_2^2
  \]
  也等价于马氏距离形式中的指数项。
- **聚集与喷射（Gather-Splat）**：  
  - **聚集**：对每个 token 在其空间支撑范围内对密集特征场加权平均，得到特征 \(z_i\)：  
    \[
    z_i = \sum_v \frac{\exp(\ell_{iv})}{\sum_u \exp(\ell_{iu})} F_v
    \]
  - **喷射**：将 token 特征按空间权重反写回密集场：  
    \[
    \hat{F}_v = \sum_i \frac{\exp(\ell_{iv} + \log(\alpha_i + \epsilon))}{\sum_j \exp(\ell_{jv} + \log(\alpha_j + \epsilon))} t_i
    \]
- **整体架构**（GSToken Block）：
  1. 三维卷积编码器将输入（4 模态 MRI）映射为密集特征场 \(F\)。
  2. **粗锚点**按固定规则网格分布，保证全局覆盖；**细锚点**由轻量 proposal head 根据空间重要性图生成，实现自适应候选分配。
  3. 对每个锚点，通过 cross-attention 从密集特征场获取上下文特征，并预测高斯几何参数（中心、尺度、旋转）。
  4. 按高斯几何聚集 token 内容，经 L 层 token Transformer 交互，得到内容特征。
  5. **区域感知核心集选择**（Region-Aware Coreset Selection）：保留全部粗 token，从候选细 token 中选出互补性最好的 \(K_f\) 个，形成固定预算的最终 token 集。
  6. 最终 token 通过高斯喷射重建密集特征场，再由三维解码器输出 WT/TC/ET 分割。
- **冻结 token 评估协议（Frozen-Token Utility Evaluation）**：  
  - tokenizer 训练后冻结；  
  - 其输出序列化为固定容量的 token 包（字段包括内容特征、中心、尺度、旋转、重要性、活跃掩码等）；  
  - 使用一个共享的轻量级 Transformer reader（仅读取 token 包，不访问原始图像或编码器特征）从零开始训练，独立测量各 tokenizer 的信息保留量；  
  - 严格匹配 token 数量、特征宽度、序列化载荷、reader 架构和数据划分，使比较公平。

- **数据集**：BraTS 2021 训练集（1,251 例有标签数据）。

- **预处理**：各模态非零体素 z-score 归一化，共同脑边界框裁剪，重采样至 128³，分割掩膜最近邻插值。

## 7. 优点

- **新颖性**：首次将 3DGS 风格的高斯几何引入医学图像 token 表示，将空间形态信息直接嵌入 token 本身。

- **几何表达能力强**：各向异性高斯支持连续、方向感知的空间区域聚集，比固定 patch 或纯注意力池化更贴合病变形态。

- **统计严谨**：多种子配对差异、bootstrap 置信区间、统一病例标识符，保证了结论的可靠性。
