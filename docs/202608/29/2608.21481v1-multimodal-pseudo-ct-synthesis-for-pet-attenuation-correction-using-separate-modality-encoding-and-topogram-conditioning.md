## 摘要
我们参加了BIC-MAC挑战赛，使用多模态3D patch-based U-Net从NAC-PET、MRI和2D定位像生成伪CT。通过使用独立的PET和MR编码器、多尺度特征融合以及瓶颈处的基于FiLM的定位像条件化，我们获得了一个整合互补跨模态信息同时减少对模态间精确体素级对应关系依赖的模型。我们的最终提交可在：https://github.com/rrr-uom-projects/BIC-MAC-MICCAI2026 找到。

## Abstract
We participated in the BIC-MAC Challenge with a multimodal 3D patch-based U-Net for pseudo-CT generation from NAC-PET, MRI, and 2D topograms. By using separate PET and MR encoders, multi-scale feature fusion, and FiLM-based topogram conditioning at the bottleneck, we obtain a model that integrates complementary cross-modal information while reducing reliance on precise voxel-wise correspondence between modalities. Our final submission can be found: https://github.com/rrr-uom-projects/BIC-MAC-MICCAI2026

## 1. 核心问题与整体含义（研究动机与背景）

本论文聚焦于 PET（正电子发射断层成像）成像中的**衰减校正**问题，核心挑战是：传统 PET 衰减校正依赖 CT 图像，但 CT 扫描会给患者带来额外的电离辐射。BIC-MAC Challenge 旨在探索在没有 CT 的情况下，利用其他可用模态（NAC-PET、MRI、2D 定位像/Topogram）生成伪 CT，并用于 PET 重建，从而在保证 PET 定量准确性的同时消除 CT 辐射暴露。

论文的核心科研问题是：**如何有效融合多模态信息（含 2D 投影与 3D 体积的异构组合），生成高质量伪 CT 以支持 PET 衰减校正**。

本研究的方法学意义在于：提出了一种能处理模态间不完全对齐、融合互补信息、并利用 2D 投影条件化 3D 生成任务的深度学习架构。其临床意义在于：为无 CT 条件下的 PET 衰减校正提供了可行方案，有助于降低患者辐射剂量、拓展 PET 在 CT 不可用场景下的应用。

## 2. 方法论

### 2.1 核心思想

作者提出一种**多模态 3D 补丁级 U-Net**架构，核心思路是：

- 为 NAC-PET 与 MRI 设置**独立编码器**（而非提前通道拼接），以应对模态间未精细对齐的问题；
- 在编码器各尺度上通过**多尺度特征融合**整合两类体积信息的互补特征；
- 将 2D Topogram 视为全局解剖与体形信息的提供者，使用**FiLM（特征级线性调制）**在 U-Net 瓶颈处进行条件化注入，而非与 3D 特征做空间拼接（因为 2D 投影与 3D patch 无逐体素空间对应关系）。

### 2.2 网络结构

- **编码器**：PET 与两序列（in-phase和out-phase）MRI 经独立 3D 编码器，跨 4 个尺度提取特征；基础通道宽度为 32，编码器特征宽度为 32–64–128–256；
- **融合模块**：每个尺度上，PET 和 MR 特征图进行通道拼接 → 用 1×1×1 卷积投影回单模态通道宽度 → 经 squeeze-and-excitation（SE）门控[1]重加权。SE 门包含全局平均池化、通道缩减瓶颈（缩减比 4）和 sigmoid 激活，以自适应地逐通道、逐尺度重加权融合表示；
- **跳连与瓶颈**：融合特征经跳连传递至解码器，并馈入共享瓶颈（512 通道）；
- **Topogram 处理**：2D Topogram 缩放到 224×224，使用预训练 ResNet-18[2] 提取 256 维特征。首个输入卷积从 3 通道 RGB 调整为 1 通道——通过对 3 个通道的权重取平均实现适配；
- **FiLM 条件化**：Topogram 特征经投影层学习逐通道缩放参数 γ 与平移参数 β，作用于瓶颈特征 b，更新公式为 **b′ = b(1 + γ) + β**。投影层采用**零初始化**，使训练开始时 γ = β = 0，即条件化表现为恒等映射，Topogram 分支的影响随训练逐步增 强；
- **解码器**：使用 resize 卷积（三线性上采样 + 卷积）替代转置卷积，以避免棋盘伪影[4]；每个上采样特征图与对应融合编码特征串联后经卷积块处理；最终 1×1×1 卷积加 sigmoid，使输出映射到 [0,1]。

### 2.3 实现细节

- 卷积块：两个 3×3×3 卷积 + 实例归一化 + LeakyReLU（负斜率 0.01）；
- 下采样：2×最大池化；
- 损失函数：在预测掩膜内评估 L1 损失；
- 优化器：AdamW（lr=1e-4，权重衰减 1e-5），余弦退火，250 个 epoch；
- 补丁采样：64×64×64，仅对预测掩膜内前景进行正样本采样，批次大小 1；
- 归一化：NAC-PET 和两个 MRI 按 0.5–99.5 强度百分位缩放到 [0,1]；CT 值裁剪至 [-1000, 2000] HU 后线性映射至 [0,1]；
- 使用自动混合精度与梯度裁剪（范数 1.0）。

## 3. 实验设计

### 3.1 数据集与基准

- 采用 **BIC-MAC Challenge** 数据集，共 **75 例有真实 CT 的受试者**，其中 71 例用于训练、4 例用于内部验证；
- 输入模态：NAC-PET、两序列 MRI（in-phase 和 out-phase）、2D Topogram；
- 输出：伪 CT；随后用于 PET 重建及衰减校正评估。

### 3.3 对比/消融评估

作者对多种替代方案进行了组合对比：

- 仿射与强度**数据增强**（对 PET/MR 联合应用以保持空间对应）；
- **注意力机制融合**替代 SE 融合；
- 替代卷积模块；
- 加权损失函数；
- **学习刚体配准网络**以对齐 MR–CT 空间；
- 配准与未配准图像**同步训练**；
- 区域特异性 MRI 掩膜。

结论：这些设计均未在内部验证上带来 CT 或 PET 重建指标改善，且**最优增强配置的全身 CT MAE 和器官偏置上反而始终差于无增强模型**。因此最终提交模型为无增强、无配距的基本配置。

## 6. 主要结论与发现

- 提出的分离编码 + 多尺度 SE 融合 + FiLM 条件化的多模态 U-Net 在 BIC-MAC 验证集上取得了可接受的伪 CT 生成质量和 PET 衰减校正性能（CT μ-map MAE 0.005454，PET 全身 SUV MAE 0.0379，器官偏置 2.45%）；
- 独立编码器设计能**有效降低对模态间精确体素配准的依赖**，从而在模态未对齐情况下仍能利用跨模态互补信息；
- 2D Topogram 的全局条件化（FiLM）而非空间拼接，是针对异构输入的可行设计；
- 数据增强在本任务中未带来收益，甚至可能有害（未增强模型表现更好）；
- 本方案可作为无 CT 环境下 PET 衰减校正的实用候选方案。
