## 摘要
结构MRI（sMRI）与动态功能网络连接（dFNC）的多模态融合能够揭示大脑结构与变化的功能状态之间的关系。当相同的结构潜在表示与多个状态耦合时，分别对每个状态应用独立向量分析（IVA）可能产生不相关的结构分解，而强制使用相同的分解则可能抑制特定状态之间的关系。此外，并非每个受试者都表现出每种动态状态。我们提出了掩蔽结构残差IVA（MSR-IVA），这是一种状态感知框架，它将共享结构表示与状态特定的残差自适应相结合，并对不完整的状态表达进行掩蔽。在阿尔茨海默病神经影像学倡议队列中，相对于独立的成对IVA基线，MSR-IVA将匹配源耦合提高了6.5%，并将不匹配依赖降低了15.7%。在同时表达两种状态的受试者中，MSR-IVA的跨状态结构源平均绝对相关性为0.9177，而无共享时的则为0.2978，这表明受控的结构共享能够在保留源对应关系的同时允许状态特定的自适应。

## Abstract
Multimodal fusion of structural MRI (sMRI) and dynamic functional network connectivity (dFNC) can reveal how brain structure relates to changing functional states. When the same structural latent representation is coupled with multiple states, applying independent vector analysis (IVA) separately to each state can produce unrelated structural decompositions, while forcing identical decompositions may suppress state-specific relationships. In addition, not every subject expresses every dynamic state. We propose masked structural residual IVA (MSR-IVA), a state-aware framework that combines a shared structural representation with state-specific residual adaptations and masks for incomplete state expression. On an Alzheimer's Disease Neuroimaging Initiative cohort, MSR-IVA improved matched source coupling by 6.5% and reduced unmatched dependence by 15.7% relative to the independent pairwise IVA baseline. Among subjects expressing both states, mean absolute cross-state structural source correlation was 0.9177 for MSR-IVA versus 0.2978 for no sharing, demonstrating controlled structural sharing that preserves source correspondence while allowing state-specific adaptation.

## 1. 核心问题与整体含义

- **背景**：多模态神经影像融合（如结构MRI与静息态fMRI）可揭示大脑结构与功能之间的关联，而动态功能网络连接（dFNC）进一步刻画了随时间变化的功能状态。将这些信息整合有助于理解脑结构如何支持不同功能状态，尤其在阿尔茨海默病（AD）中，结构与功能网络的异常均已被广泛报道。
- **核心问题**：当同一结构模态（sMRI）需要与多个动态功能状态（dFNC）分别融合时，存在两难——
  1. 若对各状态独立运行IVA，各状态得到的结构分解互不关联，丢失跨状态对应关系；
  2. 若强制所有状态共用完全相同的一组结构分解，则可能抑制状态特异的脑结构–功能关系。
  3. 此外，并非每个受试者在扫描期间都表现出每种动态状态（即状态表达不完整），若仅保留“两状态均表达”的受试者做完整案例分析，会丢失大量有效样本。
- **整体含义**：该论文旨在构建一种“状态感知”的多模态融合框架，在共享结构表征与状态特异适应之间取得平衡，同时有效处理缺失状态表达问题，从而更充分地利用脑影像数据。

## 2. 方法论

- **核心思想**：提出掩蔽结构残差独立向量分析（MSR-IVA），将结构解混矩阵分解为**共享分量**与**状态特异残差**之和，并通过**状态掩码**保证只对具有有效观测的状态目标进行优化。
- **模型结构**：
  - 对状态 r ∈ {1, 2}，结构解混矩阵为：Wgr = Wg0 + ΔWgr，其中 Wg0 为跨状态共享的结构变换，ΔWgr 为状态 r 的特异残差调整；每个dFNC状态保留自身的功能解混矩阵 Wfr。
- **目标函数**（公式3）：
  \[
  L_{MSR} = \frac{1}{2}\sum_{r=1}^{2}\left[\frac{1}{K}\sum_{k=1}^{K}\ell_K(Z_k^{(r)}) - \frac{1}{K}\left(\rho_g V(W_{g0} + \Delta W_{gr}) + \rho_f V(W_{fr})\right)\right] + \frac{\alpha}{2K}\sum_{r=1}^{2}\|\Delta W_{gr}\|_F^2
  \]
  - 第一项为Kotz源先验负对数密度（建模SCV内相关性）；
  - 第二项为矩形矩阵的log体积正则项（防止秩塌缩）；
  - 第三项为残差L2惩罚，α控制结构共享强度：α较小允许较大状态特异残差，α增大则趋近于硬共享。
- **状态掩码机制**：每个状态 r 有二进制掩码向量 m(r) ∈ {0,1}^N，仅对掩码为1的受试者参与该状态的源矩阵计算，从而自然支持不完整状态表达，无需丢弃有效样本。
- **两种参考极限**：
  - 无共享模型（MSR-IVA, α=0）：各状态结构矩阵完全独立；
  - 硬共享模型（HSMSR-IVA）：移除状态残差，两者强制相同结构分解。
- **SCV排列检验**：使用10000次随机置乱（derangement）生成不匹配SCV相关性的零分布，计算SCV级经验p值和FWER校正值，验证匹配耦合并非偶然。

## 3. 实验设计

- **数据集**：阿尔茨海默病神经影像学倡议（ADNI）队列，匹配T1加权sMRI与重复时间3秒的rs-fMRI。
  - 队列规模：573名受试者（296 CN、160 MCI、117 dementia）。
  - 状态1由363人表达，状态2由219人表达，仅124人同时表达两种状态。
  - 对比完整案例分析（仅124人）与掩码方案（保留状态内全部有效样本，分别是363人和219人）。
- **特征构建**：
  - sMRI：NeuroMark 3.0结构模板约束组ICA（MOO-ICAR），得66个灰质载荷特征；
  - dFNC：NeuroMark功能pipeline + 滑动窗口（窗口长21个时间点）→ 53个网络两两连接 → 1378个连接特征/窗口，88个窗口/扫描；k-means得到三状态解，本研究聚焦状态1与状态2。
- **对比方法**：
  - **IP-IVA**：独立成对IVA基线（按MISA框架，两状态分别独立优化）；
  - **无共享模型**：MSR-IVA的α=0极限，各状态结构完全独立；
  - **HSMSR-IVA**：硬共享模型，两状态完全相同结构分解；
  - **MSR-IVA**：所提出的软共享模型（代表α∈{0.01, 0.05, 0.1, 0.5, 1, 2, 5, 10, 25}的可调中间态）。
- **训练配置**：K=20个SCV、Adam优化器（学习率10^-4）、500 epochs、QR分解随机正交行初始化、训练过程行归一化、保留最低损失检查点；Kotz参数λ=1、β=0.5、η=1，log体积权重ρg=ρf=1。
- **主对比选用α=0.1**，并在5个随机种子（42–46）上重复实验。

## 6. 主要结论与发现

1. **软共享可行且有效**：MSR-IVA的跨状态结构源相似性为0.9177（无共享为0.2978、硬共享为1.0000），说明在保持源对应关系的同时允许非完全相同的状态特异结构表征是可行的。
2. **融合质量提升**：相对IP-IVA基线，MSR-IVA将匹配源耦合（within-SCV）提高6.5%，将不匹配源依赖（cross-SCV）降低15.7%（五个随机种子平均）。
3. **源对应关系稳固**：SCV标签置换检验显示两个状态下的全局经验p≈1.0×10^-4，所有20个SCV均通过FWER校正（p_FWER=1/10001），表明对角线上的高耦合并非偶然匹配。
4. **掩码策略有效保留样本**：相比仅保留124名共同表达受试者的完整案例分析，掩码公式化保留了363名（状态1）与219名（状态2）受试者的有效观测，显著增加了可用数据量。

## 7. 优点

- **问题定义清晰且切合实际**：同时解决了多状态融合中“结构共享 vs. 状态特异”的矛盾以及状态缺失表达的数据利用问题，这两点在实际临床数据中都很常见。
- **方法设计优雅**：通过一个残差项（Wgr = Wg0 + ΔWgr）加一个标量系数α，即可在“完全独立”和“完全共享”之间连续插值，具备较强的可解释性和可调性。
- **掩码机制简洁有效**：不需要丢弃有效受试者，充分利用了全部可用观测，明显优于传统的完整案例分析。

- **可复现性强**：提供了公开代码仓库（github.com/dasjar/MSRIVA），有利于后续研究复用和复现。
