## 摘要
对多被试时空数据中的共享结构和特定于被试的结构进行建模仍然具有挑战性，尤其是在神经影像学中，空间和时间模式在不同被试间表现出丰富的变异性。现有的矩阵和张量分解提供了可解释的因子分解，但依赖于固定的多线性结构或耦合方案，这可能限制它们在捕捉复杂变异性方面的灵活性。在这项工作中，我们引入了一个时空变分张量分解（ST-VTD）框架，该框架将张量分解生成模型与结构化先验相结合，以联合表示空间图谱和时间动态。空间因子受LL1分解启发进行正则化以促进低秩结构，而时间因子则使用基于长短期记忆（LSTM）的学习先验进行建模，从而实现了灵活自适应的动态。通过展开优化算法的迭代步骤，采用摊销变分公式进行后验推断，产生了一个可解释且参数高效的架构。所提出的推断框架采用了基于组独立成分分析的暖启动策略，我们发现这能改善优化性能。在逼真的合成功能磁共振成像（fMRI）数据集上的实验表明，与代表性的经典和概率分解基准相比，所提出的方法显著改善了潜在因子的恢复。

## Abstract
Modeling shared and subject-specific structure in multisubject spatiotemporal data remains challenging, particularly in neuroimaging, where both spatial and temporal patterns exhibit rich variability across subjects. Existing matrix and tensor decompositions provide interpretable factorizations, but rely on fixed multilinear structures or coupling schemes that may limit their flexibility in capturing complex variability. In this work, we introduce a spatiotemporal variational tensor decomposition (ST-VTD) framework that combines a tensor factorization generative model with structured priors to jointly represent spatial maps and temporal dynamics. Spatial factors are regularized to promote a low-rank structure inspired by the LL1 decomposition, while temporal factors are modeled using a learned Long short-term memory (LSTM)-based prior, enabling flexible and adaptive dynamics. Posterior inference is performed using an amortized variational formulation by unrolling iterations of an optimization algorithm, leading to an interpretable and parameter-efficient architecture. The proposed inference framework employs a warm-start strategy based on group independent component analysis, which we found to improve optimization performance. Experiments on a realistic synthetic functional MRI (fMRI) dataset demonstrate that the proposed approach significantly improves latent factor recovery compared with representative classical and probabilistic decomposition benchmarks.

### 2. 方法论

- **核心思想**：
  - 采用张量分解生成模型：每个被试的观测张量 \(\mathbf{X}^{(n)}\) 表示为 \(K\) 个空间图谱 \(\mathbf{Z}_k^{(n)}\)（大小为 \(V_x\times V_y\)）与时间因子 \(\mathbf{c}_k^{(n)}\)（长度为 \(T\)）的外积之和，加高斯噪声。
  - 空间先验：受LL1分解启发，每个空间图谱 \(\mathbf{Z}_k\) 的均值使用低秩结构 \(\mathbf{U}_k\mathbf{V}_k^\top\)（\(\mathbf{U}_k\in\mathbb{R}^{V_x\times L}\)，\(\mathbf{V}_k\in\mathbb{R}^{V_y\times L}\)），并假设围绕该均值的独立同分布高斯噪声。这减少了参数数量，同时保留局部空间结构。
  - 时间先验：使用LSTM网络生成时间因子的均值 \(w(t,\theta_k)\)，并带有方差参数。LSTM能捕捉非线性、长程时间依赖，且共享参数跨被试。
- **关键技术细节**：
  - **变分后验**：采用均场近似，将后验分解为空间和时间因子的独立高斯分布，其均值和方差由数据 \(\mathbf{X}\) 决定。后验均值由**算法展开（algorithm unrolling）** 获得——具体使用LPALM（Linearized Proximal Alternating Least-squares Minimization）算法迭代更新空间和时间因子（共 \(I=50\) 次迭代），每次迭代中空间因子通过截断SVD进行低秩投影 \(\mathbf{P}_{LR}\)。后验对数方差由轻量级MLP从均值计算。
  - **优化目标**：最大化证据下界（ELBO），包含三项：数据重建似然、空间KL散度、时间KL散度。使用重参数技巧和随机梯度上升优化，并引入KL退火（linear warm-up over 50 steps）以防止后验坍缩。
  - **暖启动**：初始值 \((\mathbf{C}^{(0)},\mathbf{Z}^{(0)})\) 采用GICA结果加上少量可学习偏移（共享跨被试），显著提升非凸优化的性能。
- **公式/算法流程**（文字说明）：
  1. 对每个被试，观测 \(\mathbf{X}^{(n)}\)。
  2. 初始化解码器状态为GICA初始化。
  3. 执行 \(I\) 次LPALM迭代，交替更新 \(\mathbf{C}\) 和 \(\mathbf{Z}\)（包含低秩投影）。
  4. 经过迭代后，用MLP计算后验方差。
  5. 从后验分布采样，计算ELBO损失（含KL退火项）。
  6. 使用Adam优化器更新生成模型参数（空间先验参数 \(\mathbf{U}_k,\mathbf{V}_k\)、时间先验的LSTM参数 \(\theta_k\)、方差）和变分后验参数（偏移量、MLP权重）。

### 3. 实验设计

- **数据集**：**合成fMRI数据**，基于Neuromark atlas中的10个空间图谱，引入真实的被试间变异（小幅旋转、幅度变化、时间相移、空间变形等），生成 \(N=100\) 被试，\(T=150\) 时间点，空间分辨率 \(30\times 30\)，噪声标准差 \(\sigma=0.1\)。
- **Benchmark与对比方法**：
  - **GICA**（Group ICA）：经典组水平ICA，FastICA估计共享空间图，经最小二乘得到被试特异时间序列。

  - **BCPF**（Bayesian CP Factorization）：每被试独立分解，固定秩 \(K=10\)，无自动秩减。
  - **PARAFAC2**：共享空间因子，允许时间因子跨被试变化，使用AO-ADMM算法，秩 \(K=10\)。
