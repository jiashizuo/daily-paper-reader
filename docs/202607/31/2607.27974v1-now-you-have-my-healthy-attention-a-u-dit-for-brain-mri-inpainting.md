## 摘要
ASNR-MICCAI BraTS局部合成（修复）任务要求对T1加权MRI中掩膜区域内的健康脑组织进行解剖学上合理的补全，为下游分析提供无肿瘤的解剖参考。由于该任务通过失真度量（SSIM、PSNR、MSE）评分，我们构建了一个确定性回归模型，并专注于赋予其针对修复任务定制的归纳偏置。我们的网络遵循U-DiT原理，在降采样的令牌网格上执行自注意力：一个体积编码器-解码器通过带有三维旋转位置嵌入的降采样全局自注意力块引入长距离上下文，而卷积和跳跃连接保留高频细节。两个想法推动了我们的结果。首先，我们约束注意力，使被遮挡（“空洞”）的令牌仅关注同一体积中已知健康的令牌，并对每个查询的对侧同源区域施加学习偏置，迫使补全从观察到的解剖结构中推断，而不是从其他未知区域推断。其次，我们添加一个对侧对称输入，提供镜像的健康半球作为患者特定的先验；由于大脑近似双侧对称且病变通常为单侧，该先验在匹配的结构相似性下改善了失真度量。在官方BraTS-2026验证排行榜上，我们的提交在219个病例中达到了平均健康区域SSIM为0.864，PSNR为24.7 dB，MSE为4.6×10^{-3}。我们进一步分析了失真最优回归固有的残差平滑性，并讨论了其对解剖真实性的影响。

## Abstract
The ASNR-MICCAI BraTS Local Synthesis (Inpainting) task asks for the anatomically plausible completion of healthy brain tissue within a masked region of a T1-weighted MRI, providing a tumor-free anatomical reference for downstream analysis. As the task is scored by distortion metrics (SSIM, PSNR, MSE), we build a deterministic regression model and focus on giving it inductive biases tailored to inpainting. Our network follows the U-DiT principle of performing self-attention on a downsampled token grid: a volumetric encoder-decoder imports long-range context through a downsampled global self-attention block with three-dimensional rotary position embeddings, while convolutions and skip connections preserve high-frequency detail. Two ideas drive our results. First, we constrain the attention so that occluded ("void") tokens attend only to known-healthy tokens of the same volume, with a learned bias toward each query's contralateral homologue, forcing the completion to be inferred from observed anatomy rather than from other unknown regions. Second, we add a contralateral-symmetry input that supplies the mirrored healthy hemisphere as a patient-specific prior; since the brain is approximately bilaterally symmetric and lesions are typically unilateral, this prior improves the distortion metrics at matched structural similarity. On the official BraTS-2026 validation leaderboard our submission reaches a mean healthy-region SSIM of $0.864$, PSNR of $24.7$\,dB and MSE of $4.6{\times}10^{-3}$ over $219$ cases. We further analyse the residual smoothness inherent to distortion-optimal regression and discuss its implications for anatomical realism.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **问题定义**：该论文面向 ASNR-MICCAI BraTS Local Synthesis (Inpainting) 任务，即对 T1 加权脑部 MRI 中掩膜覆盖的病灶区域进行健康脑组织的解剖学合理补全，从而为下游分析（如配准、图谱构建、分割）提供无肿瘤干扰的“健康参考”。
- **核心挑战**：临床上患者特异性健康基线几乎不存在（首次扫描时病灶已出现），这会给下游流程引入“病理偏置”。
- **任务评估方式**：官方仅以失真类指标（SSIM、PSNR、MSE）在掩膜健康子区域上评分，因此作者选择构建**确定性回归模型**，而非扩散生成模型，以直接优化这些指标。
- **研究思路**：作者认为在修复任务中，模型应具备两个关键归纳偏置：① 修复过程只能依赖已观察到的健康组织，而非其他未知（待预测）区域；② 大脑近似双侧对称、病灶通常单侧，因此对侧健康半球可作为患者特异性先验。

## 2. 论文提出的方法论

- **总体架构**：采用类 U-DiT 的 3D 卷积编码器-解码器（基础宽度 64，四级分辨率，GroupNorm/SiLU，带跳跃连接），仅在瓶颈处插入一个**下采样全局自注意力块**，用于捕获长距离上下文；卷积与跳跃连接保留高频细节。
- **下采样注意力机制**：
  - 用 space-to-channel（即 3D pixel-unshuffle）将每个 2×2×2 体素块折入通道维，使 token 网格分辨率为原来的 1/2，注意力计算量降低为原来的 1/64。
  - 注意力采用多 head 余弦相似度 + 可学习 per-head 温度 + 3D 旋转位置嵌入（RoPE）。
  - 输出投影零初始化，使该块在初始化时等价于恒等映射，网络相当于其纯卷积版本。
- **健康限定注意力（Healthy-only attention）**：
  - 将掩膜平均池化到粗 token 网格，若某 token 的 void 占比 > 0.5，则将其 key bias 设为 −∞，使 void token 从可 attend 的 key 集合中排除。
  - 这样 void 中的 query 只能关注同卷中已知健康 token，避免了在未知区域上的“不动点”式推理。
  - 该机制参数免费，且对任何带有粗注意力阶段的修复网络均可复用。
- **对侧加权（Contralateral weighting）**：
  - 在注意力 logits 上增加一个零初始化的学习偏置项：对每个 query，按其估计的矢状面（mid-sagittal plane）反射位置，给对侧解剖同源区更高权重。
  - 偏置项由镜像有效性图门控，镜像源在脑外或本身是 void 时自动抑制。
- **对侧对称输入（Contralateral-symmetry input）**：
  - 额外输入两个通道：镜像 voided 体积（关于估计的矢状面镜像）及其逐体素有效性图。
  - 矢状面按强度加权质心估计，镜像通道对同侧缺失组织提供患者特异模板；两个通道的 stem 权重零初始化，可从无该输入对应模型热启动。
- **训练目标与策略**：
  - 损失 = 掩膜 MAE + 掩膜 SSIM 项 + 轻量高频惩罚项。
  - 采用随机掩膜增强（从掩膜库中随机采样真实掩膜并随机裁剪），避免网络记忆单个空洞。
  - 使用 AdamW 优化器、EMA 权重、学习率 warmup + 余弦退火。
- **推理**：使用镜像测试时增强（TTA），将预测与其矢状面翻转结果平均；已知组织区域原始体素被逐字保留，仅合成 void 区域。

## 6. 论文的主要结论与发现

- 在官方 BraTS-2026 验证集上，所提交模型达到平均健康区域 SSIM 0.864、PSNR 24.71 dB、MSE 4.57×10⁻³。
- 健康限定注意力是单一最有效的改进（参数免费、可迁移到任何有粗注意力阶段的修复网络）；对侧对称输入提供互补增益，尤其在 PSNR/MSE 上提升但 SSIM 几乎不变，符合其作为低频解剖模板的角色。
- 对称先验以“输入条件”形式提供比以“后处理 TTA”形式提供更有效（二者同时使用时增益依然存在）。
- 对侧加权注意力在轴位/冠状位视图上明显聚焦于对侧同源脑区，验证了对侧同源组织是预测 void 区域的首要依据。
- 回归最优模型存在固有平滑性：失真最优解是条件均值，会压制高频细节；wavelet 变体虽在视觉上恢复更多解剖结构，却在所有失真指标上更低，揭示了“感知真实感”与“失真分数”的分歧，这为后续引入残差生成式细化提供了动机。

## 7. 优点

- **任务特化的归因偏置设计**：将“只依赖已知健康组织”和“对侧对称”这两个医学先验以显式、可解释的结构注入网络，而非依赖数据隐式学习，契合任务本质。
